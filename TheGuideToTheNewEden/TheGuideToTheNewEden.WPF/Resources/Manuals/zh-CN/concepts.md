# 术语与口径

## 一句话 {#tldr}
跨功能共用的术语与统计口径对照：ISK 缩写、安全等级、跳数、市场 5% 档与价差、缓存有效期、AI 确认机制——各处说法要统一时，以本表口径为准。

## 这份手册讲什么 / 从哪开始 {#where}
- 收录**跨功能共用**的口径与术语；功能独有的口径（如倒货推荐度）看各功能手册的「字段与口径」，本文不重复。
- 每条都给到能在界面或手册里核实的出处；查词直接看下方表格，按「术语 → 含义 → 口径 / 出处」组织。
- 核对口径最快的两个界面位置：市场页物品头的「5% / 平均 / 数量」统计行、导航结果的「共 N 跳」概览行。

## 怎么用这份术语表 {#steps}
1. 在表格里找到术语，引用数值或描述现象时按本表口径说，避免"同一个词各自理解"。
2. 让 AI 用同一口径：问句带上口径词（如「5% 均价」「最近一个月走势」「共几跳」）；AI 的数字一律来自工具结果，查不到会明说。
3. 拿不准时以界面里的说明文字与对应手册的「字段与口径」为准；本表与界面冲突时，以界面实际文案为准。

## 术语与口径 {#fields}

### 数字与缩写
| 术语 | 含义 | 口径 / 出处 |
|---|---|---|
| ISK 与 K / M / B / T | 游戏内货币与量级缩写（千 / 百万 / 十亿 / 万亿） | 角色卡片与总资产按 K/M/B/T 缩写并带 ISK；总技能点缩写不带单位（角色页） |
| 技能点 SP | 角色技能点总数 | 卡片按千分位，为 0 或取不到时显示 `-`（角色页） |

### 安全等级与跳数
| 术语 | 含义 | 口径 / 出处 |
|---|---|---|
| 安全等级（安等） | 星系 / 角色的安全等级 | 角色左栏一位小数；星图按高安 / 低安 / 00 三套色，图例两端为 `1.0（高安）`、`0.0 / 负（低安）`；市场表格的安等列是普通数字、不上色 |
| 跳数 | 一条航线的跳跃次数 | 导航概览行「共 N 跳」，逐跳分起点 / 星门 / 旗舰跳 / 跳桥；「距离(ly)」是星系间距，燃料只产生在旗舰跳 |

### 市场口径
| 术语 | 含义 | 口径 / 出处 |
|---|---|---|
| 5% 均价 | 前 5% 订单的价格平均值 | 卖单取最便宜 5%、买单取最贵 5%；不足 2 条时取首条（市场页物品头） |
| 平均 / 数量 | 全部订单均价 / 订单条数 | 平均是算术平均（买卖各自算）；「数量」是订单条数，不是物品数量 |
| 价差（买卖差） | 订单与参考价的差 | 订单页「与市场价差」= 订单价格与星域参考价的差值大小（两位小数），方向看「订单状态」列；参考价买单比最高买价、卖单比最低卖价；历史页签的「价差」由历史统计接口数据算出（区间 = 所选时间范围） |
| 订单有效期 | 订单剩余有效时间 | 「过期时间」形如 `dd.hh:mm:ss`（天.时:分:秒） |
| 缓存有效期（TTL） | 磁盘缓存的新鲜度判定 | 「设置 → 市场」的「订单有效时长」「历史记录有效时长」（分钟）决定"多久之后才重新问 ESI"，不是数据本身有多新；查单个物品的星域订单是实时、不缓存 |

### 位置与 AI 机制
| 术语 | 含义 | 口径 / 出处 |
|---|---|---|
| 数据目录 | 应用设置、登录令牌、各功能配置与缓存的落盘根目录 | 默认 `%LocalAppData%\TheGuideToTheNewEden\V4`（`V4` = 主版本 4.x）；在「设置 → 一般 → 数据目录」可改（重启生效）；选择记录在根目录 `datapath.json` |
| 配置目录 | 数据目录下的 `Configs` | `<数据目录>\Configs`（默认 `%LocalAppData%\TheGuideToTheNewEden\V4\Configs`）；主页「打开配置目录」直接定位这里（「数据目录 → 打开」打开的是它的上级数据目录） |
| 日志目录 | 软件自己的运行日志 | `%LocalAppData%\TheGuideToTheNewEden\Logs`（与数据目录无关、多个版本共用），按日期一个 `.txt`；「App日志 → 查看」直达 |
| AI 按需声明 | 工具按需下发给模型 | 「设置 → AI → 工具开关」开启后，只把与本次提问相关的工具组发给模型；关掉的工具不会下发 |
| AI 写操作确认 | 会改配置的操作先确认 | 回答里出现「需要确认的操作」卡片，点「应用」才执行；「写操作需要确认」关闭**不是免确认**而是直接拒绝；ESI 写操作每次都要确认，黑名单路径确认也绕不过 |

## AI 能替你做什么 {#ai}
- **数字一律来自工具**：内置提示词要求"数字以工具为准、查不到就说查不到"；不要采信对话里的旧数字。让 AI 按本表口径回答，最有效的是把口径写进问法：「伏尔戈 XX 的 5% 均价是多少」「因卡萨斯级最近一个月走势怎么样」「从吉他到米亚尔加怎么走」。
- 读数边界：AI 的旗舰路线**不读导航窗参数**——单跳上限缺省 8 ly、固定允许走星门、不启用省钱优先、不回报燃料；要按船型与技能算，请用星图的导航窗。
- **做不到**：不能替你启动 / 停止订阅型功能（频道预警 / 频道监控 / 频道查价、日志监控、击杀流）与多开预览；能读 / 改白名单内的功能配置（`config_read` / `config_write`，写入需确认、可回滚），但不代你点界面、不代你重启（可用 `feature_restart` 整体重启）；**记忆只存在于单个对话内**（同一个对话默认带上此前完整记录，含工具调用与结果；换对话就是重新开始）；写操作一律先确认（口径见上表）。

## 限制与已知问题 {#limits}
- **建筑市场的「历史」实为该建筑所在星域的历史**（REFACTORING §8-9）：不是建筑自己的历史。
- **倒货切「星系」市场仍会先拉整星域**（§8-22）：星系口径并不比星域便宜。
- **订单 / 合同里的结构位置名解析不到时显示原始 ID**（§8-5）：本地玩家建筑列表里没有该建筑时的回落显示。
- **技能组「组内技能个数」口径略窄**（§8-7）：显示的是本地库与账号都命中的技能数，不是该组全部技能数。
- **AI 术语约束只覆盖本地数据库里的名词**（§8-29）：结构（建筑）名与玩家 / 军团 / 联盟名不在其中。
