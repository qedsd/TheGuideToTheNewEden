# 快速链接

## 一句话 {#tldr}
内置的 EVE 工具站与资源站收藏夹：按分类分组的卡片墙，点卡片直接开浏览器，支持搜索、收藏置顶、导入导出与自己增删编辑。

## 在哪打开 {#where}
- 左侧导航「**快速链接**」。
- 第一行是工具栏：搜索框、分类下拉、「**只看收藏**」、统计文字（「共 N 个链接，当前显示 M 个」）、「**新建链接**」主按钮与「**更多操作**」按钮。
- 工具栏下方是分类快捷跳转条（胶囊）；往下是按分类分组的卡片网格。

## 前置条件 {#prereq}
- 链接数据存本机用户配置目录的 `Configs/Links.json`，首次运行会自动播种内置链接库（覆盖星图、虫洞、市场、工业、官方与中文资源等二十多个分类）。
- 打开链接会调用系统浏览器，应用本身不需要登录角色。

## 操作步骤 {#steps}

### 打开 / 复制一个链接
1. 点卡片任意处在浏览器打开该站；悬停卡片会显示完整描述与地址的提示。
2. 右键卡片：**打开链接 / 复制链接 / 收藏（或取消收藏）/ 编辑链接 / 删除链接**。
3. 复制成功有「已复制链接」通知；删除会先弹确认框（确定删除链接「xx」？）。

### 收藏与置顶
1. 点卡片右上角的星标收藏；收藏项**既留在原分类分组里，又额外出现在最上面的「收藏」分组**（同一张卡可能出现两次，「收藏」组标题上有说明）。
2. 「**只看收藏**」只显示收藏项（该模式下单组平铺、不重复）。
3. 删除链接时会自动剪掉失效的收藏。

### 搜索与筛选
1. 搜索框匹配名称 / 概述 / 描述 / 地址 / 分类 / 平台 / 语言；分类下拉按「全部分类」+ 已有分类过滤。
2. 没有匹配时进入过滤空态，可一键「**清除筛选**」。

### 分组与跳转
1. 分组按分类划分，顺序按该分类的条数从多到少（「收藏」组固定最前）；每组标题右侧紧贴条数，可折叠（默认展开）。
2. 点跳转条上的胶囊（分类名 + 条数），会展开该分组并把它滚动到列表顶部。

### 编辑链接
1. 右键卡片「**编辑链接**」，或工具栏「**新建链接**」打开编辑窗口。
2. 字段：名字、链接、概述、描述、分类、平台、语言。「**分类**」除手打（逗号分隔）外，下方还列出已有分类的可点胶囊（点一下加入、再点移出，免得手打错字变成新分类）。
3. 校验：名称与链接地址必填，地址需以 `http://` 或 `https://` 开头；点「**确定**」保存后卡片立即更新。

### 数据管理（更多操作菜单）
1. 「**从配置重载**」：在外面手改 `Links.json` 后不用重启，重读即可。
2. 「**导入链接表**」：从 JSON 文件合并导入，按地址去重（只补没有的，不覆盖不删除）。
3. 「**导出链接表**」：导出为 JSON 文件备份。
4. 「**恢复默认链接**」：把内置链接库里你还没有的条目合并进来（内置库扩充后，用这一条拿到新条目）。
5. 「**打开配置目录**」：直接定位 `Configs/Links.json` 所在目录。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 名字 / 概述 | 卡片主文案 | 概述在卡片上两行截断，完整内容看提示 |
| 描述 | 卡片提示里的完整说明 | 仅提示显示 |
| 分类 | 分组依据 | 多个分类用逗号分隔；**分组只按第一个分类** |
| 平台 / 语言 | 站点适用平台与语言 | 现仅用于搜索匹配 |
| 收藏 | 置顶一份到「收藏」分组 | 存在应用设置里，不写进 Links.json |
| 统计 | 共 N 个链接，当前显示 M 个 | M 按去重后的可见卡片数 |

## AI 能替你做什么 {#ai}
- 工具：`links_search`（在内置链接库按关键词搜站点 / 工具，匹配口径与本页搜索一致；结果会跳转到本页并填好搜索词，可只搜收藏）。
- 推荐问法：「有没有查价格的网站」「给我几个虫洞工具」「帮我找个装配站」。
- **做不到**：不会替你打开浏览器（回执里给网址，你自己点）；也不会帮你增删、编辑或收藏链接。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 链接地址需以 http:// 或 https:// 开头 | 编辑窗口里地址不合规 | 补全协议前缀再保存 |
| 请填写名称 / 请填写链接地址 | 必填项为空 | 补全后点「确定」 |
| 导入失败：… | 文件不是有效的链接表 JSON | 用本页「导出链接表」的文件做模板 |
| 复制失败：剪贴板被其它程序占用 | 剪贴板被占用 | 稍后重试复制 |

## 限制与已知问题 {#limits}
- **卡片与跳转胶囊不放图标**：只显示文字信息；内置库条目的图标字段不在界面上展示。
- **分组只按第一个分类**：一条链接可写多个分类（都显示成胶囊），但只归入第一个分类的分组。
- **没有拖拽排序**：组内顺序就是链接表里的顺序；想置顶请用收藏。
- **打开 / 复制都是原样地址**：不做任何地址加工（曾经的动态参数机制已移除），一次网络请求都不发。
- **内置链接库会自然过期**：收录的是社区工具站，域名被抢注、站点停运都会发生，不是本地缺陷；用右键「删除链接」清理，删错了用「恢复默认链接」按地址补回来。
- **折叠状态不跨会话**：重启应用后所有分组回到展开。
- **「常用」是按条数近似的**：分组顺序按该分类的链接条数排，不统计真实打开频次。
