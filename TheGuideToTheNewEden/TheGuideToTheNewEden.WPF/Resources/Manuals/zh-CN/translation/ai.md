# 翻译 · AI 翻译

## 一句话 {#tldr}
用你自己配置的大模型翻译整段游戏文本（聊天、邮件、频道置顶信息…）：按对话保存原文与译文、可带上下文让译文连贯，EVE 专有名词按本地术语库约束。

## 在哪打开 {#where}
- 左侧导航「**翻译**」→「**AI 翻译**」。
- 未配置模型时整页是配置引导（「**去配置**」直达设置、「**重新检测**」）；配置后分左右两栏：左栏「**对话**」列表，右栏上方是对话记录、下方是「**输入**」卡。
- 输入卡里的「**弹窗**」把同一页面放进独立的工具窗口（可置顶，未置顶时可被主窗口盖住；弹窗实例里没有「弹窗」按钮）。
- 相关设置：模型协议 / 服务地址 / API Key / 模型名 / 生成参数在「**设置 → AI → 模型**」；术语库 / 单次请求最大字符数 / 结果缓存 / 翻译提示词在「**设置 → AI → 翻译**」；用户术语与 AI 新词候选在「**设置 → 术语表**」。

## 前置条件 {#prereq}
- 需要在「设置 → AI → 模型」选好协议（OpenAI 兼容 / Azure OpenAI / Anthropic / Gemini）并填写服务地址、API Key、模型名；缺了会看到整页引导。模型节与 AI 助手共用，配一次两边都能用。
- 术语约束需要「设置 → 一般」已载入本地化数据库（SDE 的中英术语对照）；没载入也能翻译，只是没有术语命中。
- 翻译记录与结果缓存都保存在本机 `Configs` 目录，不会上传。

## 操作步骤 {#steps}

### 管理对话
1. 点左栏底部「**新建对话**」；对话按最近更新排在最上面，列表项显示标题（默认取第一条原文）、最后一条预览与更新时间。
2. 右键对话可「**重命名对话**」「**删除对话**」「**清空当前对话**」；重命名也可以双击记录区顶部的对话标题或点旁边的铅笔按钮，回车确认、Esc 取消；清空标题则恢复按第一条原文自动取名。

### 翻译一段文本
1. 在底部「**输入**」卡选「**源语言**」与「**目标语言**」（口径见下方表格），输入行右侧显示当前端点摘要。
2. 在多行输入框粘贴内容：**回车 = 翻译**，**Shift+回车 = 换行**。AI 源按次计费，不会边输入边自动查询，必须回车或点「**翻译**」才会发送请求。
3. 成功后记录区新增一对气泡：**原文靠右、译文靠左**；译文下方一行显示模型 · 耗时 · token 与「**术语命中（已注入提示词）**」。文字可像网页一样任意拖选复制，每条最右侧还有「**复制译文**」图标按钮（原文直接在气泡里拖选）。
4. 气泡超行会折叠：原文超三行、译文超五行，末尾「**展开 / 收起**」切换；发送新的一条时，之前没被手动展开过且超行的译文会自动收起一次。

### 带上下文翻译
1. 勾选记录区底部的「**带上上下文（本对话）**」——一个对话一个开关，随对话保存。
2. 打开后，本对话每次翻译都会带上此前**成功**的问答（不限条数），译文更连贯；关闭则每条独立翻译。失败或已停止的记录不会被当作上下文，其他对话的记录也永远不会混进来。

### 并发、停止与长文本
1. 等待期间可以继续发送下一条：每条在自己译文位置显示转圈与「正在翻译…」，记录区顶部显示「正在翻译 N 条…」；「**停止**」会取消全部在跑的请求，对应气泡显示「已停止」。
2. 超过「设置 → AI → 翻译」里「**单次请求最大字符数**」（默认 12000，0 = 不分片）的长文本会分片翻译后合并；模型输出被截断时会**自动从断点续写**（最多 3 次），仍没写完会在术语栏提示译文可能不完整。

## 字段与口径 {#fields}

| 控件 / 字段 | 含义 | 口径 |
|---|---|---|
| 源语言 | 原文是哪种语言 | 「自动检测」按正文判定：汉字→中文、假名→日文、谚文→韩文、西里尔→俄文，其余按英文 |
| 目标语言 | 译成哪种语言 | 选「**自动检测**」= 译成另一种语言；选具体语言则固定目标 |
| 互译语言对（A ⇄ B） | 目标语言为「自动检测」时才显示 | 原文是 B 译成 A、是 A 译成 B、**其它语言一律译成 A**（建议把 A 设成母语）；A/B 不允许相同，可用按钮对调 |
| 带上上下文（本对话） | 对话级开关 | 带上本对话此前全部成功问答，不限条数、不截断单条文本 |
| 术语命中（已注入提示词） | 本次发给模型的术语 | SDE 术语只在中英方向注入；「设置 → 术语表」的用户术语优先级更高 |
| meta 行 | 模型 · 耗时 · token | 分片数 / 续写次数 / 思考关闭也标注在这里 |
| 复制译文 | 复制该条译文 | 复制的是剔除游戏内标记后的纯文本 |

## AI 能替你做什么 {#ai}
- 工具：`translate`（中英互译，本地词库优先、AI 源兜底；**不需要确认**）、`glossary_write`（新增 / 更新 / 删除一条用户术语，**写操作，需要你确认**，一次只改一条）。
- 推荐问法：「把这段频道置顶信息翻成中文」「以后把 Xxx 译成 Yyy」「Rifter 的中文译名是什么」。
- **做不到**：不能替你修改模型端点、API Key 或生成参数（那是「设置 → AI → 模型」的事）；读写不到对话记录文件；`glossary_write` 一次只改一条，批量整理请用「设置 → 术语表」页。
- 本页的界面操作（新建对话、展开气泡等）助手无法代劳。

## 常见失败与处置 {#errors}

| 气泡 / 提示 | 原因 | 处置 |
|---|---|---|
| AI 翻译未配置：请在「设置 → AI 助手 → 模型与翻译」里选择协议并填写服务地址、API Key 与模型名。 | 还没有配置端点 | 到「**设置 → AI → 模型**」配置（提示文案里的路径是旧名，按实际设置页找） |
| 模型没有返回译文（输出被「最大输出 token」截断） | 输出撞上上限，或用的是只回思维链的推理模型 | 调大「最大输出 token」（或设 0 交给服务端默认）；推理模型换普通对话模型 |
| 译文可能不完整：模型的输出上限把这一片截断了（已自动续写，仍未写完）… | 输出上限太小，续写次数用尽 | 调大「最大输出 token」或减小「单次请求最大字符数」 |
| 请求已中断或超时 | 服务端长时间没有返回新内容 | 稍后重试；用「设置 → AI → 模型」的「测试连接」检查端点 |
| 已停止 | 你点了「停止」 | 重新发送即可 |
| HTTP 401：… 这类一句话 | 服务端拒绝请求（Key / 地址 / 模型名不对） | 核对「设置 → AI → 模型」各项，先点「测试连接」 |

## 限制与已知问题 {#limits}
- **真实服务商请先「测试连接」**：协议层的请求与解析只在本地 mock 服务上做过完整核验，各家真实端点未逐家实测。
- **术语库覆盖面**：只约束 SDE 里的名词（物品 / 舰船 / 装备 / 星系 / 星域 / 空间站）；结构（建筑）名、玩家 / 军团 / 联盟名不在其中——可加进「设置 → 术语表」的用户术语。
- **API Key 明文**：保存在本机 `settings.json`（日志不会输出 Key）。
- **并发不设上限**：等待期间连发几条就有几个请求，按次计费的服务商请自行留意；「停止」取消全部。
- **上下文无上限**：长对话（几十条、每条又是整段文本）会让提示词迅速膨胀，遇到"上下文超限"类报错时新建对话即可重置。
- **对话历史是本地明文**：`Configs/AiTranslationHistory.json`，上限 40 个对话、每对话 200 条记录（超出丢最久未更新的），介意可直接删文件。
- **存盘保留原始文本**：显示 / 复制 / 上下文用的都是剔除游戏内标记后的纯文本，标记本身不进提示词。
- **思考模式默认关闭**：仅对模型名或地址含 deepseek 的端点下发该参数，其他服务商不受影响；开思考后生成明显变慢。
