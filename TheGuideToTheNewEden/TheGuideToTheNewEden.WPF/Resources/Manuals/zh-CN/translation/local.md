# 翻译 · 本地词库

## 一句话 {#tldr}
用本地 SDE 数据库的中英对照翻译 EVE 专有名词（物品 / 星域 / 星系 / 空间站）：完全离线、不需要 API Key、不计费，输入即查。

## 在哪打开 {#where}
- 左侧导航「**翻译**」→「**本地词库**」。
- 左右两栏：左栏「**翻译**」卡（方向下拉 + 多行输入框 + 匹配列表，底栏「**翻译 / 清空 / 弹窗**」），右栏「**结果**」卡（名词详情，底栏「**复制译文**」）。
- 「**弹窗**」把同一面板放进独立的工具窗口（可置顶、未置顶时可被主窗口盖住；弹窗里没有「弹窗」按钮）。

## 前置条件 {#prereq}
- 需要 SDE 主库（英文）与**本地化数据库**（中文）都已载入；后者在「**设置 → 一般**」勾选「使用本地化数据库」并选择数据库文件。
- 数据库不可用时，左栏顶部显示黄色提示条，查询会被拦下，不会报错。
- 不联网、不需要任何 Key；查询在本地数据库完成，没有次数与费用。

## 操作步骤 {#steps}

### 查一个名词
1. 左栏输入框输入名词，**中英文都可以**（如「Rifter」或「裂谷级」）。输入停顿后会自动查询（离线不计费），回车或点「**翻译**」立即查询；「**清空**」清空输入与结果。
2. 匹配列表每行直接显示**原文 + 译文 + 类型**（物品 / 星域 / 星系 / 空间站），不用点选就能看到译名；底栏状态行显示「匹配 N 条 · 英文 → 中文」这类方向信息。
3. 点一条列表项，右栏显示：物品图标（仅物品类）、原文、类型与方向、**译文**、原文描述、译文描述。全部文字都可拖选复制；底栏「**复制译文**」复制译名（该条没有译文时复制原文并提示已复制）。

### 选方向
1. 「**方向**」三选一：**自动 / 英文 → 中文 / 中文 → 英文**。
2. 自动方向先按原文是否含中文判定；若该方向一条都没命中，会**自动再试另一个方向**——中英混排、只记得缩写时更不容易"查不到"。
3. 本地词库只做**中英互译**：查询其他语言会明确提示（见常见失败），要翻整句或小语种请用「AI 翻译」页。

### 复制
- 右栏全部文字都可拖选复制；列表项右键可「**复制原文** / **复制译文**」。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 原文 | 匹配到的名词原文 | 按原文语言在对应库里模糊匹配 |
| 译文 | 对照译名 | 每类名词命中封顶 100 条；完全匹配排最前、其余按名称升序 |
| 类型 | 物品 / 星域 / 星系 / 空间站 | 来自 SDE 数据库 |
| 方向 | 本次查询的方向 | 自动方向可能在两次判定后确定 |
| 译文（详情区） | 所选条目的译名 | 译库里没有该条目时显示「**无译文**」（警示色） |
| 描述 | 原文描述 / 译文描述 | 随条目给出，可能为空（为空时整行隐藏） |

## AI 能替你做什么 {#ai}
- 工具：`translate`（中英互译：**本地词库优先**，词库未命中或要整句翻译时回落到已配置的 AI 源；不需要确认）。
- 推荐问法：「Rifter 中文叫什么」「吉他用英文怎么说」「The Forge 是哪个星域」。
- **做不到**：本地词库只认 SDE 里的专有名词，整句翻译、军团 / 角色 / 玩家建筑名不在覆盖范围；助手也不能替你批量翻译一份物品清单。

## 常见失败与处置 {#errors}

| 提示 | 原因 | 处置 |
|---|---|---|
| 本地化数据库不可用：请在「设置 → 一般」勾选“使用本地化数据库”，并确认已选择本地化数据库文件（Resources/Database/Local/zh.db）。 | 本地化库未启用或未选择文件 | 按提示到「设置 → 一般」开启并选择文件，回到本页重查 |
| 本地数据库中没有匹配的名词 | 输入的不是 SDE 收录的专有名词 | 核对游戏内名称；整句或俚语用「AI 翻译」页 |
| 本地词库只能做中英互译（它查的是 SDE 的中英对照）；其他语言请用「AI 翻译」页。 | 查询方向不是中英 | 切回中英方向，或改用「AI 翻译」页 |

## 限制与已知问题 {#limits}
- **只覆盖 SDE 里的名词**：物品 / 星域 / 星系 / 空间站可中英互译；通用文本（句子）、军团 / 角色名、结构（玩家建筑）名译不了——句子与小语种用「AI 翻译」页。
- **没有批量模式**：一次查询一组匹配，"粘贴一份物品清单逐行出译文"未提供。
- **命中上限**：每类名词模糊匹配最多返回 100 条（完全匹配优先、其次按名称升序）。
- **用户术语会覆盖 SDE 译名**：「设置 → 术语表」里的用户术语同样作用于本地词库的查询结果。
