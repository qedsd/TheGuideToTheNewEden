# 翻译 · 频道翻译

## 一句话 {#tldr}
监听游戏内聊天频道，把新消息逐条交给 AI 翻译并实时追加到结果列表；原文 / 译文都可选中复制，EVE 专有名词按本地术语库约束。

## 在哪打开 {#where}
- 左侧导航「**翻译**」→「**频道翻译**」。
- 三栏布局：左「**目标角色**」，中「**频道与参数**」（未选中角色时整栏隐藏），右「**实时译文**」（底栏「**清除**」与「**弹窗**」，底部一行状态统计）。
- AI 未配置时整页显示配置引导（「**去配置**」直达「设置 → AI → 模型」、「**重新检测**」），与「AI 翻译」页同一套。

## 前置条件 {#prereq}
- 需要已在「设置 → AI → 模型」配置端点；没配置会看到整页引导。
- 「目标角色」列出的是本应用已登录的角色；没有角色就无从监听。
- 频道列表来自该角色的**聊天日志文件**——游戏里打开 / 加入过的频道才会出现；应用靠增量读取日志监听新消息，不需要额外 ESI 授权。
- 翻译方向与术语约束继承「AI 翻译」页及「设置 → AI → 翻译」的配置，本页不单独设置。

## 操作步骤 {#steps}

### 开始监听一个角色
1. 左栏「目标角色」点选一个角色；中间出现「频道与参数」。
2. 勾选要翻译的频道（每项带复选框，显示频道名与日志会话开始时间）。
3. 点中栏底部的「**开始**」：右下角提示「**已开始频道翻译**」，左栏该角色行左侧出现橙色竖条（悬停显示「翻译中」）。没勾频道会提示「**未选择需要翻译的频道**」。
4. 游戏里频道来新消息后，右栏按**新 → 旧**追加译文。开始监听时会先补翻该频道**日志尾部最近 20 行**（含频道置顶信息 / MOTD 与最近几句），更早的历史消息不会翻。
5. 中栏底部「**停止**」结束该角色；左栏还有「**开始全部**」「**停止全部**」「**刷新列表**」图标按钮。

### 调整参数（运行中锁定）
- 参数与频道勾选**改动即保存**（按角色持久化到 `Configs/ChannelTranslationSettings.json`），但翻译**运行中**参数区与频道列表会禁用，停止后修改、再开始生效。
- 「**跳过自己的发言**」「**只翻译非中文消息**」：按剔除游戏内标记后的纯文本判断。
- 「**最短长度**」（1–200 字符）：更短的消息直接跳过，不花 token。
- 「**触发关键词**」：留空 = 全部消息都翻译；填了关键词则只翻译命中的消息。
- 「**翻译方向**」是只读展示，跟「AI 翻译」页的源 / 目标语言与互译语言对走，在那边改一次两边同时生效。

### 上下文（默认开）
- 「**带上上下文**」把**同一频道**此前已翻译的几条一起发给模型，译文更连贯；「**上下文条数**」1–20。
- 不同频道互不串；关掉开关则每条独立翻译。

### 复制结果
- 原文与译文都是可拖选复制的富文本；右键条目可「**复制原文** / **复制译文**」，或点每条最右侧的「**复制译文**」图标按钮。
- 原文只显示一行预览，**悬停**可看完整清洗文本（游戏内标记已剔除）；译文超过五行折叠，用「**展开 / 收起**」切换。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 时间 · 发言人 · 频道 · 监听角色 | 每条顶部的来源行 | 说明这条消息来自哪个频道、谁说的、被哪个登录角色读到 |
| 原文 | 单行预览 | 已剔除游戏内标记（颜色 / 字号 / 链接等），`<br>` 转成换行；悬停看全文 |
| 译文 | AI 译文 | 超五行折叠；失败时该条显示红色原因 |
| 已去除游戏内标记 N 个 | 预清洗删掉的标记数 | 有删除时才显示 |
| 术语命中（已注入提示词） | 本次按术语库约束的名词 | 仅中英方向注入 |
| meta 行 | 模型 · 耗时 · token | — |
| 状态行 | 已翻译 N 条 · 列表 N 条 | 列表上限 300 条，新的在顶部，超出丢最旧的 |

## AI 能替你做什么 {#ai}
- 工具：`translate`（单条中英互译，本地词库优先、AI 源兜底；不需要确认）。
- 推荐问法：「把这句频道发言翻成中文」「这句频道置顶信息是什么意思」。
- **可以读 / 改频道翻译配置**：`config_read` / `config_write`（name=`channeltranslation`）读写白名单里的 `ChannelTranslationSettings.json`（每角色频道、上下文条数、跳过规则），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`channeltranslation`，需确认）整体重启：停止全部会话 → 重读设置 → 重开原本在跑的角色（页面需已打开）。
- **做不到**：替你**单独**开始 / 停止监听或勾选频道；结果列表也不作为助手的上下文。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| AI 翻译未配置：请在「设置 → AI 助手 → 模型与翻译」里选择协议并填写服务地址、API Key 与模型名。 | 没有配置端点 | 「**去配置**」到「**设置 → AI → 模型**」（提示文案里的路径是旧名） |
| 未选择需要翻译的频道 | 点「开始」时没勾频道 | 中间栏勾选至少一个频道再开始 |
| 没有返回译文 | 模型空回复 | 多因「最大输出 token」太小或用了推理模型，处置见「AI 翻译」手册 |
| 某条消息一直不出现 | 被跳过规则过滤（自己的发言、短于「最短长度」、未命中「触发关键词」，或开了「只翻译非中文消息」而消息是中文） | 按需放宽参数；用「已翻译 N 条 · 列表 N 条」对照消息量 |

## 限制与已知问题 {#limits}
- **串行队列**：多角色多频道的消息进同一条队列逐条翻译（AI 按次计费且易限流），频道刷屏时延迟与 token 消耗线性增长，没有"一次请求翻多行"的批量。
- **只补翻日志尾部**：频道置顶信息 / MOTD 只在开始监听时随日志尾部一起翻，更早的历史消息永远不翻（有意的成本控制）。
- **验证边界**：真实聊天日志 + 真实模型的完整链路未做过实机核验，首次使用建议先用「AI 翻译」页或「测试连接」确认端点可用。
- **参数即时生效**：改动参数 / 术语对**后续**消息立即生效，正在翻译中的那条不受影响。
- **方向跟随共享设置**：本页不能单独改方向，「AI 翻译」页改了会影响这里。
