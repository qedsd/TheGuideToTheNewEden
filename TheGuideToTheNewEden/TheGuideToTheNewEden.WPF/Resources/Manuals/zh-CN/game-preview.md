# 多开

## 一句话 {#tldr}
把每个 EVE 客户端窗口做成**常驻置顶的实时缩略图浮窗**：可拖动、滚轮缩放、调不透明度，配全局快捷键在多个角色间快速切换——一屏盯多个号，不用来回切游戏窗口。

## 在哪打开 {#where}
- 左侧导航「**多开**」。
- 页面三栏：左「**进程列表**」（每项 = 角色名 + 窗口标题，预览中带黄色小条；右键菜单：**开始预览 / 停止预览 / 上移 / 下移 / 恢复位置 / 激活游戏窗口**；底部**开始全部 / 停止全部 / 刷新列表**）；中「**设置**」卡分「**选中项设置 / 全局设置**」两个页签（未选中进程时只有全局设置）；右「**预览**」卡显示选中进程的实时画面。

## 前置条件 {#prereq}
- 本机在运行 EVE 客户端。列表默认按进程名关键词 `exefile` 匹配（「全局设置 → **进程关键词**」可改，多个用英文逗号分隔、不区分大小写）。
- **角色名从游戏窗口标题解析**：标题形如 `EVE - 角色名` 时取「-」后面的部分；刚启动还没选角色时解析不出，此时它的预览设置不会被保存。

## 操作步骤 {#steps}

### 开始预览
1. 进程列表自动发现客户端；选中一个进程，右栏「**预览**」卡实时显示它的画面（客户端最小化或已退出时显示提示文字）。
2. 右键「**开始预览**」（或中栏底部「开始」）弹出浮窗；「**停止预览**」关闭它。
3. 浮窗两种「**显示样式**」：**带标题栏**（标准标题栏：logo + 角色名 + 关闭键）或**无标题栏**（画面铺满整个窗口，角色名由左上角的**角色名叠加窗**显示）。

### 调整浮窗
1. **拖动 / 缩放**：拖边框即可。默认「**锁定画面比例**」开启：画面区域始终按游戏画面比例，拖一条边另一条边自动联动，不会出现黑边；鼠标滚轮按比例缩放。关闭后窗口可自由改成任意宽高比，游戏画面会**拉伸铺满整个窗口**。该开关在「选中项设置 → 显示样式」下面，默认开启。
2. **不透明度（%）**：滑杆 10–100。调低后**只有画面变透**——能看见被浮窗挡住的客户端或桌面；标题栏 / 高亮边框 / 角色名叠加始终实色。
3. **高亮与隐藏**：「**游戏窗口活动时隐藏**」在对应客户端到前台时收起浮窗；「**游戏窗口活动时高亮**」用「高亮边框颜色」画一圈边框（宽度按上 / 下 / 左 / 右分别设；带标题栏样式不画上边）。
4. **角色名叠加**（无标题栏样式）：字体 / 字号 /「跟随窗口缩放」+「缩放倍率」/ 背景色 / 背景色（高亮时）/ 文字颜色；颜色都支持 `#AARRGGBB` 透明度写法。叠加窗**点击穿透**，不影响拖动与缩放。
5. **快捷键**：「**激活快捷键**」给单个进程设组合键（占位提示「例如 Ctrl+1」，组合键用 + 连接，按键名称可参考「设置-按键列表」）；「**响应全局切换快捷键**」决定该进程是否参与全局快捷键轮切。

### 全局设置
1. **全局快捷键**：设「**向前 / 向后**」两个组合键，按下时按「**切换顺序**」依次激活对应的**游戏窗口**。
2. **切换顺序**：多行文本框（每行一个角色）+「**用当前列表填充**」+「**应用**」；列表右键「上移 / 下移」也会同步改它。
3. **激活模式**：三种窗口激活方式（模式1 标准 / 模式2 兼容 / 模式3），某个模式下激活游戏不生效时换另一个。
4. **统一窗口尺寸**：设宽 / 高后点底部「**统一窗口尺寸**」按钮统一各浮窗尺寸。开启「锁定画面比例」的窗口按游戏画面比例反算高度；关闭的窗口按填写的高度。
5. **自动排列**：设排列方向（**向左 / 向右 / 向上 / 向下**）、对齐方式、间隔、每行 / 列最多（**不含锚点**），点底部「**自动排列**」按钮把所有浮窗排成阵列（至少需要两个可见的预览窗口）。以当前选中项的浮窗为锚点，锚点自身不动；方向指的是「把其余窗口放到锚点的哪一侧」。贴屏幕边缘放不下时会自动翻到反方向；关掉「锁定画面比例」的窗口也会跟随画面移动（角色名叠加窗一起移动）。
6. **窗口吸附**：默认开启。拖动浮窗时，靠近其它可见预览窗的边或角会自动对齐；贴住一条边后可以继续沿这条边滑动。只吸附预览窗口，不吸屏幕边缘；吸附距离可调（默认 12 像素）。
7. **行为**：「**开始全部时包含没有保存过配置的进程**」「**自动开始新出现的进程**」（游戏里选好角色、出现角色名后也会自动开始预览）「**同进程切换角色后沿用设置**」。
8. **分组快捷键**：「**添加分组**」给一组角色（角色名逗号分隔）配「向前 / 向后」组合键，在该组内轮切；「**切换分组后从头开始**」决定再次触发时是否从第一个开始。

### 管理每项配置
1. 选中进程时中栏底部有「**恢复位置**」与「**应用到其余配置**」（把该角色的预览设置复制给其余已保存配置）。
2. 配置按**角色名**保存：同角色再次上线自动沿用它的颜色、位置、快捷键等设置。

## 字段与口径 {#fields}

| 设置项 | 含义 | 口径 |
|---|---|---|
| 显示样式 | 带标题栏 / 无标题栏 | 无标题栏样式的角色名靠叠加窗显示 |
| 锁定画面比例 | 拖拽 / 滚轮缩放时是否反算另一条边 | 默认开启；关闭后可自由设置宽高比，游戏画面拉伸铺满窗口 |
| 窗口吸附 | 拖动时是否吸附到其它预览窗 | 默认开启；支持边对齐、角对齐，贴住边后可沿边滑动 |
| 吸附距离 | 触发吸附的像素阈值 | 默认 12；只对其它可见预览窗生效，不吸屏幕边缘 |
| 不透明度（%） | 画面不透明度 | 只作用于画面；10–100、步进 5 |
| 高亮边框宽度 | 高亮边框在上 / 下 / 左 / 右的留白 | 带标题栏样式不画上边 |
| 名称条颜色 / 名称条高亮颜色 | 旧样式的遗留设置 | 当前画面中没有名称条，修改这两项没有可见效果 |
| 角色名叠加颜色 | `#AARRGGBB`，支持透明度 | 「背景色（高亮时）」在该客户端到前台时顶上来 |
| 进程关键词 | 发现客户端的进程名过滤 | 默认 exefile，不区分大小写 |
| 激活模式 | 前台激活的实现方式 | 三选一 |
| 切换顺序 | 全局快捷键的轮切顺序 | 与列表顺序分开维护，可用「用当前列表填充」同步 |

## AI 能替你做什么 {#ai}
- **可以读 / 改多开设置**：用 `config_list` 找到 `gamepreview`，`config_read` 读取 `GamePreviewSetting.json`（显示样式、不透明度、高亮、快捷键、角色名叠加、统一尺寸 / 排列、进程关键词等都在里面）；`config_write` 修改（会先弹确认，旧内容自动备份），改错可用 `config_restore` 回滚。
- **改完可以重启多开**：`feature_restart`（name=`gamepreview`，需确认）会停止现有预览浮窗、重新读取配置，并按新设置重新开始原本在跑的预览。
- **做不到**：AI 不能单独替你开始 / 停止某一个预览、开关浮窗，也读不到**实时进程列表**、浮窗当前位置与预览画面，不能替你激活或切换游戏窗口。
- 区别在于：**"设置是什么 / 把不透明度改成 60"这类配置问题可以让 AI 做**；"现在有哪些角色在预览 / 浮窗在哪"属于运行中的窗口交互，只能看页面。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 「没有可开始的进程」 | 按进程关键词没匹配到客户端 | 核对「全局设置 → 进程关键词」（默认 exefile），点「刷新列表」 |
| 「注册快捷键失败：…」 | 组合键被其他程序占用或格式不对 | 换一个组合键；格式参考「例如 Ctrl+1」 |
| 「无法获取该客户端的画面，窗口可能已关闭或已最小化」 | 源客户端已退出或最小化 | 恢复客户端窗口；最小化期间浮窗不显示画面 |
| 「至少需要两个可见的预览窗口」 | 只开了一个浮窗就点「自动排列」 | 先开始更多预览再排列 |
| 「该分组没有正在预览的成员」 | 分组里的角色名没有对应的运行中预览 | 核对分组「角色名」拼写与预览状态 |
| 「未识别到角色名，本次预览设置不会被保存」 | 窗口标题解析不出角色名 | 在游戏里选好角色，让标题带上角色名 |

## 限制与已知问题 {#limits}
- **浮窗不进任务栏与 Alt+Tab，自己也不抢焦点**：这是刻意设计——点击浮窗会直接**激活对应的游戏客户端**，浮窗本身不成为前台窗口。
- **画面比例持续跟随游戏**：开启「锁定画面比例」时，游戏改分辨率、拉伸窗口后浮窗会自动重新校正比例，无需手动调整；只有源客户端**最小化**期间例外（见下一条）。关闭锁比例后不再自动校正，窗口保持你拖出来的尺寸。
- **源客户端最小化时**：浮窗不显示画面，改显示提示文字；还原后自动恢复。最小化期间不做比例校正。
- **从浮窗自己的关闭键退出后**：进程列表的选中项可能丢失、设置面板短暂空白（已知遗留问题）；用列表右键「停止预览」或页面按钮关闭更稳。
- **新浮窗的高亮状态可能不准**：开启「游戏窗口活动时高亮」时，刚出现的浮窗会先处于高亮状态，游戏窗口切换一次前台后才按实际状态显示。
- **没有浮窗拖拽排序**：调整顺序用列表右键「上移 / 下移」或「切换顺序」文本框。
