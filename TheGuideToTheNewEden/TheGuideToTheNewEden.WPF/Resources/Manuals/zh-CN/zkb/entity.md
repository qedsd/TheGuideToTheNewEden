# Zkillboard · 实体统计

## 一句话 {#tldr}
看一个角色 / 军团 / 联盟（也支持舰船、星系等）在 zkillboard 的整体战绩：危险系数与抱团概率、击杀与损失、最贵击杀、分类与月份统计。

## 在哪打开 {#where}
- 没有独立导航入口：在「**Zkillboard**」页顶部搜索框搜实体名，或点击杀流 / KB 列表 / KB 详情里的任意实体名，即新开一个实体统计标签；多个实体可同时各占一个标签。
- 页面左栏是「实体信息」「统计概览」两张卡；右栏是六个子页签，首次切到才加载该页签的数据。

## 前置条件 {#prereq}
- 不需要登录角色；数据来自 zkillboard，网络不通或被限流时取不到数。

## 操作步骤 {#steps}

### 看左栏概况
1. 「实体信息」卡：圆形头像 / 徽标、名称与「**浏览器查看**」按钮（用系统浏览器打开该实体的 zkillboard 页面）；下方信息行按实体类型显示对应行（军团 / 联盟 / 执行军团 / 成员 / 星系 / 星域 / 舰船 / 类别 / 安全等级），行值是链接的可点击跳到该实体的统计。
2. 「统计概览」卡：**危险系数**与**抱团概率**两条细条（红色条越长比例越高）加百分比数值；下方三列统计——击杀舰船 / 击杀ISK / 击杀点数（绿）与损失舰船 / 损失ISK / 损失点数（红），以及单挑击杀 / 单挑损失。
3. 危险系数与抱团概率是 **zkillboard 的口径**，软件不做本地重算。

### KB 列表
1. 底部一行：左侧「**类型**」下拉（所有 / 击杀 / 损失 / 虫洞 / 单挑 / 最后一击 / Awox / Npc）与「刷新」；右侧分页。
2. 列表列与点击行为与击杀流一致：单击行开 KB 详情、点实体名跳实体统计、右键「浏览器查看」。「**刷新**」按当前类型重新取数。

### 最贵击杀 / 最高击杀
1. 「**最贵击杀**」：分「历史最高价值KB」与「最近7天最高价值KB」两组卡片（受害者、舰船、估价），点卡片打开该条 KB 详情。
2. 「**最高击杀**」：按「最高击杀玩家 / 军团 / 联盟 / 势力 / 舰船 / 星系」分组折叠展示（分组取决于 ZKB 返回内容），组内按击杀数从高到低，卡片显示排名、名称与击杀数；点卡片打开对应实体的统计。

### 超期击杀
- 分「**泰坦**」「**大航**」两个折叠组；只有该实体确实拥有超期击杀记录时，这个页签才会出现。

### 分类统计 / 月份统计
- 「**分类统计**」表：击杀排名、类别、击杀数、击杀ISK、损失数、损失ISK。
- 「**月份统计**」表：年、月、击杀舰船 / 击杀点数 / 击杀ISK 与损失舰船 / 损失点数 / 损失ISK。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 危险系数 | 实体危险程度 | zkillboard 服务端口径，百分比显示 |
| 抱团概率 | 与团队一起行动的比例 | zkillboard 服务端口径，百分比显示 |
| 击杀 / 损失点数 | zkillboard 的击杀点数 | 由舰船类型折算的点数系统，不是 ISK |
| ISK 数值 | 击杀 / 损失的总价值 | 大数值按量级缩写显示 |
| 估价（KB 列表） | 单条击杀总价值 | zkillboard 估价 |

## AI 能替你做什么 {#ai}
- 工具：`zkb_entity`（只读、无需确认）——输入实体全名，返回危险值（0–100）、群体活动比例（抱团概率）、击杀 / 损失次数与 ISK、单挑战绩、击杀/损失比与 ISK 效率；同名多结果时列出候选请确认；可要求跳过缓存重新拉取。
- 推荐问法：「XX 危险吗」「这团抱团率高不高」「查一下 YY 的战绩」。
- **做不到**：只支持角色 / 军团 / 联盟——舰船、星系等实体的统计请在本页查看；也取不到击杀列表、最贵 / 最高击杀与分类、月份的明细表。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 正在获取统计数据… / 正在加载… | 页签首次取数或刷新中 | 等待完成，遮罩只盖住当前标签 |

- 取数失败时以右下角通知提示，不会弹全局遮罩；多为网络或限流问题，稍后重试即可。

## 限制与已知问题 {#limits}
- **危险系数 / 抱团概率是 zkillboard 的口径**：数值直接取服务端返回，本地不二次计算；同一实体两次查询可能不同（服务端按周期归零或波动）。
- **子页签懒加载 + 短时缓存**：首次切到某页签才取数；实体统计查询有约 2 分钟内存缓存，刚看过的数字短时间内不变。
- **多实体并发**：每个实体标签独立加载，等待遮罩只盖当前标签，不互相影响。
- **「超期击杀」按需出现**：没有泰坦 / 大航击杀记录的实体看不到该页签。
- **排序**：「分类统计」与「最高击杀」各分组按击杀数降序。
