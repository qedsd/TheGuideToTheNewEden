# 星图

## 一句话 {#tldr}
在一张可缩放平移的新伊甸全图上搜索定位星系、按**安全等级 / 主权 / 行星资源 / 击杀热度 / 通行热度**着色，并规划星门或旗舰跳航线（可带航点、规避与跳桥），把航线直接画在图上。

## 在哪打开 {#where}
- 左侧导航「**星图**」。
- 页面上半部是工具条：**搜索星系 / 星域 / 着色模式 / 筛选 / 工具 / 显示设置 / 重置视图 / 更多**（后四个是图标按钮）；跳桥 / 角色 / 势力开关收在「**更多**」下拉里。
- 画布上有三块浮层：顶部居中的悬停提示、右下的选中星系信息卡、左下的色阶图例。
- 「**工具**」下拉里的六个入口都打开**独立工具窗口**：「**导航**」「**一跳覆盖**」「**行星资源清单**」「**跳桥设置**」「**主权分组**」「**情报**」；窗口已开着时再次点击只会把它前置。顶栏的「**显示设置**」图标也打开独立窗口，默认置顶并带标题栏置顶切换按钮。

## 前置条件 {#prereq}
- 打开即用，**不需要登录**：星系节点、星门连线、搜索与安全等级着色都来自本地数据。
- 「击杀热度」「通行热度」以及信息卡上的击杀 / 通行数值来自 ESI，需要联网；取不到时只是这些数值与图层缺失。
- 「主权」着色需要能访问 ESI 主权接口，装载期间显示「正在装载主权数据…」，失败会给出「主权数据装载失败，请检查网络后重试。」
- 「角色」开关需要已授权角色（标出各角色当前位置）；「行星资源」着色与资源清单基于本地数据库（只覆盖 00 星系）。
- 导航窗里的「在游戏中设置」需要一个令牌有效的角色。

## 操作步骤 {#steps}

### 看图与选中
1. 滚轮以鼠标为锚缩放、按住拖动平移；顶栏「**重置视图**」图标把视图重新适配整图。
2. 缩小时只留节点点阵（连线与文字淡出），放大后依次出现星系名、安全等级数字、节点数值与徽标。
3. 鼠标悬停在节点上：顶部居中的提示显示该星系信息，同时高亮它的相邻星门。
4. 点击节点选中：右下信息卡显示星系名、「**详情**」按钮、安全等级徽章、星域等信息行、**击杀**与**通行**数值，以及「**星门邻接**」列表——点邻接里的星系名可直接跳过去。

### 搜索与定位
1. 顶栏「**搜索星系**」框输入名称，**满 2 个字符**才弹出建议列表（每行是星系名 + 所属星域），点选后定位到该星系并清空输入框。
2. 顶栏「**星域**」下拉按星域适配视图；第一项「**全部星域**」回到全图概览。
3. 打开星系详情窗（信息卡上的「**详情**」）后，点窗内右上角的「**固定到主页**」，把它做成主页磁贴（点磁贴会回到星图并定位该星系）。

### 换着色模式与调显示
1. 顶栏「**着色模式**」下拉：**安全等级**（默认）/ **主权** / **行星资源** / **击杀热度** / **通行热度**。
2. 选「行星资源」时，着色模式右侧出现资源类型下拉：**产能 / 人力 / 岩浆气 / 超离子冰**。
3. 左下角图例随模式变化：标题、11 档色条、两端标签与说明文字（安全等级图例两端为 `1.0（高安）` 与 `0.0 / 负（低安）`）；**主权**模式不画色条，只留标题与「同组同色」的说明。
4. 图例里按模式出现开关：行星资源 / 击杀热度 / 通行热度有「**热力**」（聚合色块）与「**主权聚合**」，主权着色有「**热力**」（晕染）；热力行还带「**大小**」滑条、「**网格偏移**」的方向按钮与「**复位**」——这两行只在没勾「主权聚合」（按几何格子聚合）时出现。
5. 顶栏「**显示设置**」图标打开的窗口把参数分成**节点 / 徽标与光晕 / 文字 / 连线与热力**四组滑杆，拖动即时生效并自动记住，「**恢复默认**」一键还原。
6. 「**筛选**」按钮打开弹窗：选**星域**（含「全部星域」）与**安等**区间（两个数字框，中间 `~`），点「**应用**」生效、「**清除筛选**」还原。弹窗提示写明「未命中的星系会灰化；只影响显示，不影响悬停、选中与导航。」

### 开关图层
「**更多**」里的「**跳桥**」显示跳桥点线；「**角色**」显示已授权角色的当前位置；「**势力**」在节点上叠加徽标（缩放足够大时才画）。

### 规划航线
1. 打开「工具 → **导航**」。
2. 在图上或搜索结果里选中星系，点「**选中加入**」加进「**航点**」（窗内提示：「搜索或点击地图选中星系后点"选中加入"；首个航点为起点」）；航点标签上的 `✕` 可移除。「**规避**」用同样的「选中加入」添加。
3. 勾「**旗舰跳**」展开旗舰参数：**旗舰**（船型）、**JDC / JFC**（选到战略货舰时多一栏 **货舰**），以及「**允许走星门**」「**省钱优先**」「**最大跳距(ly)**」——跳距默认按船型与技能推出，也可手填。
4. 点「**计算**」：概览行给出「共 N 跳：星门 … · 旗舰跳 … · 跳桥 … · 旗舰距离 … ly · 燃料 …」；结果表逐跳列出**序号 / 星系 / 安等 / 距离(ly) / 燃料 / 本跳类型**（起点 / 星门 / 旗舰跳 / 跳桥），点某行可在图上定位，「**清除**」连图上的航线一并抹掉。
5. 「**在游戏中设置**」：在窗口底部选一个角色，按航线逐跳写入游戏航点，成功提示「已在游戏中设置航点」。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 安全等级 | 星系安等，体现为节点色与放大后名字右侧的小字 | 高安 / 低安 / 00 三套色；图例两端为 `1.0（高安）` 与 `0.0 / 负（低安）` |
| 着色模式 | 决定节点颜色的口径 | 安全等级 / 主权 / 行星资源 / 击杀热度 / 通行热度 |
| 行星资源类型 | 产能 / 人力 / 岩浆气 / 超离子冰 | 只在「行星资源」着色时可选 |
| 击杀 / 通行 | 选中星系卡片里的 ESI 统计值 | 来自 ESI，不是本地数据；取不到时该处为空 |
| 热力（色块 / 晕染） | 按区域聚合的热度或主权范围 | 色块 = 全图相对排名色，具体数值放大后看节点第二行；「主权聚合」按联盟范围合并 |
| 图例色条 | 11 档相对排名色阶 | 两端标签为最低 / 最高档说明 |
| 距离(ly) | 导航结果里该跳到下一跳的星系间距 | — |
| 燃料 | 该跳的旗舰燃料消耗 | 由旗舰船型与 JFC / 货舰技能换算；非旗舰跳不产生燃料 |
| 本跳类型 | 该跳的通行方式 | 起点 / 星门 / 旗舰跳 / 跳桥 |
| 最大跳距(ly) | 旗舰跳允许的单跳上限 | 默认按船型与 JDC 推算，可在导航窗改写 |
| 星域 / 安等筛选 | 只灰化未命中的星系与相关连线 | 纯显示层：不影响悬停、选中、导航 |

## AI 能替你做什么 {#ai}
- 工具（都**不需要确认**；其中 `map_layer` 传 `showBridges` 会像你手动勾顶栏「跳桥」一样，把跳桥显示开关写进 `Configs/JumpBridgeSetting.json`，另外三个只读或只改当前视图）：
  - `map_route`：按 `from` / `to` / `waypoints` / `navType`（`stargate` 或 `capital`）/ `avoid` / `maxJumpLy` 算路径，并把路径**画到星图上**。
  - `map_system_info`：按星系名回报安等、星域、跳桥、主权与行星资源。
  - `map_layer`：切换 `colorMode`（`security` / `sovereignty` / `resource` / `kills` / `jumps`）与跳桥层 `showBridges`。
  - `system_navigate`：跳到星图并定位指定星系。
- 推荐问法：「从吉他到米亚尔加怎么走」「算一条避开 XX 的路线」「吉他到 XX 的旗舰跳路线」「把星图切到主权着色」「定位到吉他」。
- 约束：星系名必须**唯一命中**，任一名歧义或查不到时工具只回报原因、**不画图**；星图命令是**叠加应用**，不会锁死你的手动操作。
- 跳桥的新增 / 删除 / 导入是**写操作**（需要你确认），见 [星图 · 跳桥](map/jumpbridge)。
- **可以读 / 改星图设置**：`config_read` / `config_write`（name=`map`）读写白名单里的 `MapSettings.json`（图层、配色、显示参数、情报开关、主权分组等），写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`map`）在下次进入星图时生效。
- **做不到**：不能替你在游戏里设置航点；也不能替你点星图窗口里的滑杆或保存按钮（只能改配置文件）。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 主权数据装载失败，请检查网络后重试。 | 拉取主权数据失败 | 检查网络后重选「主权」着色再试；其余模式不受影响 |
| 至少需要两个航点 | 航点不足两个 | 再「选中加入」至少一个星系 |
| 未找到可达航线（检查规避星系/跳距） | 规避星系切断了通路，或旗舰跳距太小 | 减少规避星系，或换船型 / 调大「最大跳距(ly)」 |
| 请先选择一个角色 | 未选角色就点「在游戏中设置」 | 在导航窗底部角色下拉里选一个角色 |
| 请先计算航线 | 还没出结果就点「在游戏中设置」 | 先点「计算」 |
| 角色令牌无效，请重新授权 | 角色授权已过期 | 到角色页重新授权该角色 |
| 设置航点失败（需要有效令牌） | 逐跳写入游戏航点时失败 | 写入**失败即中断**，确认角色授权有效后重试 |
| 正在装载星图数据… 长时间不结束 | 首次进入要读本地星图数据，或数据库临时失败 | 稍候；卡住时离开本页再进入会重新装载 |

## 限制与已知问题 {#limits}
- **筛选是纯显示**：未命中的星系与相关连线灰化，但悬停、选中、导航都不受影响，也不会让情报忽略这些星系。
- **特殊星系不在图上**：虫洞等特殊星系没有节点，无法在星图上定位。
- **「势力」徽标目前只有主权联盟**：NPC 势力徽标还没有数据源，高安星系不会出现势力徽标。
- **情报图标会重叠**：星图情报的舰船图标固定排在节点右侧、最多 8 个后折叠成 `+N`；图标格压到别的星系节点时会让位，但不同星系的图标之间不做避让，密集星域仍会视觉重叠。
- **频道情报有前置**：频道情报要求在「频道预警」页先启动至少一个角色的预警；ZKB 击杀不依赖会话。
- **性能与内存口径**：整图有数千个星系节点与上万条星门连线，拖拽 / 缩放期间每帧都要重画底图内容；底图位图按视口尺寸复用，窗口越大、DPI 越高占用越高（离开页面时释放）。
- **强调色固定**：画布与浮层会随应用深 / 浅主题整套换色，但强调色固定为青 / teal 系，不跟随设置里自选的强调色。
- **AI 的旗舰路线不读导航窗参数**：`map_route` 走 `capital` 时只把 `maxJumpLy`（缺省 8 ly）当单跳上限，并固定「允许走星门」、不启用「省钱优先」，也不回报燃料；它不读导航窗的船型 / JDC / JFC，要按船型与技能算请用导航窗。
