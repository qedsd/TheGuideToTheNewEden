# 角色

## 一句话 {#tldr}
用 EVE 账号**授权**登录角色，在一张「**全部角色**」卡片页上汇总各角色的技能点 / 资产 / 忠诚点与训练进度，再逐个角色打开**工作区**（左栏身份资产、技能队列、ZKB 战绩 + 右侧七个子页）。

## 在哪打开 {#where}
- 左侧导航「**角色**」。
- 顶部是标签栏：第一个标签固定为「**全部角色**」（不可关闭），每个已打开的角色一个标签；标签内容常驻，来回切换不丢状态。
- 「全部角色」标签就是**角色卡片页**：标题「全部角色」+ 右上角「**刷新**」+ 汇总卡（**角色数 / 总技能点 / 总资产 / 忠诚点**）+ 自适应卡片网格；网格末尾固定一张「**添加角色**」卡（绿色加号）。
- 一个角色都没有时：汇总卡与卡片网格都不显示，只显示引导「**还没有登录任何角色**」「登录 EVE 账号后即可查看技能、钱包与各类数据。」与「**登录 EVE 账号**」按钮。
- 角色标签就是**工作区**：左栏自上而下是身份/资产卡、技能队列卡、**ZKB** 战绩卡（取到数据才显示该卡）；左栏右上角与右侧子页区右上角各有一个刷新按钮。右侧七个子页签：**总览 / 技能 / 克隆 / 钱包 / 邮件 / 合同 / 工业**。

## 前置条件 {#prereq}
- 角色数据全部靠**授权**读取：某个服务器下没添加过角色，卡片页就只会是空态。
- 国际服（**Tranquility**）与国服（**Serenity**）的角色列表与授权互相独立，当前用哪套由「设置 → 一般 → **游戏服务器**」决定；切到哪边就只看到哪边的角色。
- 授权范围取「设置 → **权限选择**」里勾选的权限，授权时按当时的勾选向服务器申请；对应权限没勾，相关子功能会取不到数据。
- 军团钱包一行需要角色的财务权限，取不到时整行不显示（而不是显示 0）。
- ZKB 战绩卡依赖第三方 zkillboard，连不上或该角色没有战绩时整张卡不显示。

## 操作步骤 {#steps}

### 添加角色（国际服）
1. 在「全部角色」页点网格末尾的「**添加角色**」，或空态里的「**登录 EVE 账号**」。
2. 软件用系统默认浏览器打开 EVE 授权页；选好角色并授权后，浏览器会停在本地回调页并提示已收到授权、可以关闭该页面返回应用。
3. 回到软件，卡片页自动刷新并出现新角色的卡片（头像、SP、ISK、技能队列）。
4. 若浏览器没打开、或迟迟没有结果，会弹窗提示（标题为「**登录 EVE 账号**」）：授权被拒绝、回调地址端口被占用、等待超时都走这一分支，弹窗正文会尽量给出具体原因。

### 添加角色（国服）
1. 先把「设置 → 一般 → 游戏服务器」切到 **Serenity**；在别的服务器下走国服向导会被拒绝并提示先切服。
2. 点「添加角色」/「登录 EVE 账号」→ 弹出「**新增国服玩家角色授权**」四步向导。
3. **步骤0**：点「**登出**」退出浏览器里已登录的账号（页面报错可以无视）。
4. **步骤1**：点按钮打开网易角色授权页，选角色并授权；完成后浏览器停在一个空白页。
5. **步骤2**：把该空白页的**整条网址**（或其中的 code）粘进输入框（提示「请粘贴授权页面显示的 code」）。
6. **步骤3**：点「**校验授权**」。校验中显示「正在校验授权…」；成功显示「校验授权成功，请点击关闭按钮完成授权」——点「关闭」返回，卡片页刷新出该角色；失败显示「**校验授权失败**」并在下方给出服务端返回的错误详情（可选中复制）。

### 打开工作区
- 点角色卡片（整卡可点）→ 顶部新增该角色标签并切过去；该角色的标签已存在时只切过去，不重建页面。

### 关闭标签与移除角色
- **关闭标签**：点角色标签上角色名右侧的 ✕（悬停提示「移除」）——只关标签，角色还在列表里。
- **移除角色**：点卡片右上角「**⋯**」→「**删除角色**」→ 确认框（标题「全部角色」，正文形如「移除: 角色名?」）；确认后该角色从列表消失，它的授权记录也一并删掉，要再看必须重新添加。
- 「⋯」菜单里还有「**固定到主页**」：把该角色固定成主页快捷方式，之后点主页磁贴直接打开这个角色的工作区。

### 刷新
- 卡片页「**刷新**」：重新拉取所有角色的卡片数据。
- 工作区**左栏右上角刷新**：重拉左栏三张卡（含 ZKB）。
- 工作区**子页区右上角刷新**：只刷新当前显示的子页，不重建页面（切走过的子页状态仍在）。

## 字段与口径 {#fields}

| 位置 / 字段 | 含义 | 口径 |
|---|---|---|
| 汇总 · 角色数 | 当前服务器下已登录角色的个数 | 不含「添加角色」占位卡 |
| 汇总 · 总技能点 | 各角色技能点之和 | 按 K/M/B/T 缩写，不带 ISK 单位 |
| 汇总 · 总资产 | 各角色钱包余额之和 | 按 K/M/B/T 缩写，带 ISK |
| 汇总 · 忠诚点 | 各角色忠诚点之和 | 千分位整数 |
| 卡片 · 在线 / 离线 | 左上角状态指示 | 在线为绿点；离线为红点 + 离线时长（年 / 月 / 天 / 小时 / 分钟逐级降档） |
| 卡片 · SP | 角色技能点总数 | 千分位；为 0 或取不到时显示 `-` |
| 卡片 · ISK | 角色钱包余额 | 按 K/M/B/T 缩写，带 ISK；为 0 或取不到时显示 `-` |
| 卡片 · 技能队列 | 剩余百分比 + 细进度条 + 剩余时间 | 剩余时间按 天 / 小时 / 分钟；未在训练时百分比为 0 并显示「已暂停」；右侧是未完成条数 / 总条数 |
| 卡片 · 头像 | 角色头像 | 圆形；下载失败时显示角色名首字母占位 |
| 左栏 · 出生 | 角色创建时间 | 本地时间（`yyyy.MM.dd HH:mm`） |
| 左栏 · SP | 技能点总数（括号内是未分配） | 未分配数字悬停提示「未使用技能点」 |
| 左栏 · LP | 忠诚点 | 千分位 |
| 左栏 · 安全等级 | 角色安等 | 一位小数 |
| 左栏 · 个人钱包 | 角色钱包余额 | 两位小数 |
| 左栏 · 公司钱包 | 军团钱包余额 | 需要财务权限，取不到则整行不显示 |
| 左栏 · 势力 | 军团名 + `[联盟代号]` | 没有联盟时只显示军团名 |
| 左栏 · ZKB | 危险系数 / 抱团概率（双色条 + 百分比）、击杀舰船 / 击杀ISK / 损失舰船 / 损失ISK | 数值取自 zkillboard，ISK 按 K/M/B/T 缩写；卡内「**ZKB**」按钮跳到 Zkillboard 页并打开该角色的实体统计 |

## AI 能替你做什么 {#ai}
- 工具：`character_list`（列出本软件里已登录的角色名；一个都没有时说明需要先添加角色）、`character_navigate`（打开角色页并进入指定角色的工作区，**动作类**工具，参数是角色全名，省略即默认角色；找不到角色时只回原因、不跳转）。
- 推荐问法：「我登录了哪些角色」「打开 XX 的角色页」「XX 的角色页看看」。
- **做不到**：不能替你完成授权登录，也不能添加 / 移除角色（登录必须在浏览器里由你本人操作）；不能改游戏内的角色数据。
- 角色**数据类**问题（技能、钱包、邮件等）由各子页对应的工具回答，见各子页手册；AI 给的数字以工具返回为准，不要采信对话里的旧值。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 登录失败 | 国际服授权没成功，且没有更具体的原因可显示 | 重试；反复失败到「设置 → 测试 → 回环回调」点「检测」，确认回调地址可用且与 EVE 开发者后台登记的地址一致 |
| 无法监听授权回调地址 …（端口可能已被占用） | 回调端口被别的程序占用 | 关掉占用该端口的程序后重试 |
| 回调地址里没有 code 参数 | 收到的回调网址不完整 | 重新走一次授权 |
| 授权码校验失败（授权码可能已过期或已被使用） | 授权码已失效或被用过 | 重新授权，取一条新的网址 / code |
| 校验授权失败（下方附服务端错误详情） | 国服粘贴的内容不对，或当前服务器 / 凭据与目标服务器不一致 | 确认服务器是 **Serenity**；整条网址或纯 code 都可以粘，然后重新授权 |
| 请粘贴授权页面显示的 code | 输入框空着就点了「校验授权」 | 把授权后空白页的网址或 code 粘进去 |
| 当前游戏服务器不是国服（Serenity）：请先到"设置 → 一般"把服务器切换为国服，再进行国服授权。 | 在非国服下走国服向导 | 按提示切换服务器后再授权 |
| 还没有登录任何角色 | 当前服务器下没有已授权角色 | 点「登录 EVE 账号」添加角色 |

## 限制与已知问题 {#limits}
- **两套服务器完全独立**：切换游戏服务器后，另一服务器已打开的角色标签会被关闭、卡片页重载为新服务器的角色；两边的角色文件与凭据都不同。
- **国服没有自动回调**：只能按向导手动复制网址 / code，不像国际服那样自动收回调。
- **国服向导会盯着服务器**：向导打开期间若切走服务器，向导里的「打开授权页」「校验授权」都会被拒绝并提示先切回国服。
- **国际服回调地址必须两边一致**：回调地址取自本地配置，必须与 EVE 开发者后台登记的 Callback URL 完全一致，改任一处都要同步改另一处，否则授权页会直接报错。
- **卡片不能拖拽排序**：列表按固定顺序展示，不提供拖动调整。
- **数据有短时缓存**：切换标签回来不会重新请求；要立刻取新值就点「刷新」。左栏刷新与子页刷新各管一半。
- **头像在线下载**：下载失败时显示首字母占位，刷新会重新下载。
- **令牌过期会自动尝试刷新**：刷新失败时该角色取不到数据（卡片保持占位），需要重新添加该角色。
- **ZKB 数值会波动**：来自第三方服务，同一角色隔一段时间再看可能不同甚至为 0，不是本地缺陷。
- **移除只影响当前服务器**：另一服务器下同一角色的授权不受影响。
- 工作区左栏的**公司钱包**需要财务权限，无权限时这一行不出现。
