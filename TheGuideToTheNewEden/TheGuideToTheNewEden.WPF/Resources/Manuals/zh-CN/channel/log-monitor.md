# 频道 · 日志监控

## 一句话 {#tldr}
盯着某个角色的**游戏日志**（不是聊天频道），日志里出现你设的**正则关键词**时用系统通知、置顶弹窗、提示音提醒你；支持每个角色多份配置、两种监控模式与循环提示音——挂机时不想漏掉日志里出现的特定字样就用它。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**日志监控**」。
- 页面三栏：左「**角色列表**」（每项是角色名 + 开始时间，监控中带黄色小条，底部**开始全部 / 停止全部 / 刷新列表**）；中「**监控设置**」（选中角色后出现，每份配置一个页签，页签头是配置名 +「**关闭配置**」×）；右「**实时日志**」（只读，右键「**清空内容**」）。

## 前置条件 {#prereq}
- 在「**设置 → 游戏日志**」里配置好日志路径（与「频道 · 监控」共用同一份配置）；左栏角色列表来自日志目录，目录里没有该角色的游戏日志就不会出现。

## 操作步骤 {#steps}

### 选角色与新建配置
1. 左栏点选一个角色；右键角色可「**打开日志文件**」「**打开日志文件夹**」。
2. 中栏底部「**添加配置**」新建一份游戏日志配置；每份配置是中栏的一个页签，页签头的 × 删除它。
3. 左栏底部「**刷新列表**」重新读日志目录。
4. 配置的增删与所有修改**立即保存**——不需要点开始才落盘，改完直接关窗口也不丢。

### 配置监控
1. 「**配置信息**」：日志类型（当前固定为「游戏日志」）+「**配置名称**」。
2. 「**监控模式**」：**出现关键词时通知**（命中即提醒）/ **停止出现关键词后通知**（关键词停止出现一段时间才提醒一次，配套「**判定时间间隔（s）**」）。
3. 「**通知方式**」：**系统通知**（托盘气泡）/ **弹窗通知**（置顶消息弹窗）/ **声音通知**；开声音后可选「**循环播放**」与自定义「**音频文件**」（点「选择」挑文件，留空回落内置默认提示音）。
4. 「**监控关键词**」：界面提示「游戏日志出现相应关键词时将发出通知，支持正则表达式」。点「**添加关键词**」加一行，在「**正则表达式**」框里改写；多个关键词**任一命中**即触发。

### 开始与停止
1. 中栏底部「**开始监控**」启动当前选中的配置；关键词全空会提示「**监控关键词不可为空**」，开始后角色旁出现「监控中」黄色小条。
2. 左栏底部「**开始全部**」一次启动所有角色的所有配置；「**停止全部**」只在有配置运行时出现。
3. 「**清除通知**」只隐藏弹窗并停声，**监控仍在跑**。

### 看实时日志与弹窗
1. 右栏实时显示该角色的日志行：**命中关键词的行标红**，最新一条加粗，自动滚到底；超出显示上限裁掉最早的。
2. 弹窗通知复用频道监控的**置顶消息弹窗**（不出现在任务栏）：标题带「日志监控 - 角色 - 配置名」，新消息加粗并自动滚底。
3. 弹窗底部「**显示游戏窗口**」把对应的 EVE 客户端前置；右上角关闭同样只是隐藏。

## 字段与口径 {#fields}

| 设置项 / 显示 | 含义 | 口径 |
|---|---|---|
| 配置名称 | 页签名与弹窗标题里显示的名字 | 每角色可配多份 |
| 监控模式 | 命中即通知 / 停止出现后通知 | 「停止出现关键词后通知」才有「判定时间间隔」 |
| 判定时间间隔（s） | 关键词停止出现多久后判定"已消失"并提醒一次 | 秒 |
| 系统通知 / 弹窗通知 / 声音通知 | 三种提醒通道，可叠加 | 弹窗每个运行中的配置一个 |
| 循环播放 | 提示音循环 | 循环到「清除通知」 |
| 音频文件 | 自定义提示音路径 | 留空或路径失效回落默认提示音 |
| 监控关键词 | 正则表达式，一行一条 | 任一命中即触发；全空无法开始 |
| 实时日志行 | 命中行标红、最新行加粗 | 只保留最近若干条 |

## AI 能替你做什么 {#ai}
- **可以读 / 改监控配置**：`config_read` / `config_write`（name=`gamelog`）读写白名单里的 `GameLogInfoSettings.json`（配置、关键词、判定间隔、通知方式），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`gamelog`，需确认）整体重启：停止全部会话 → 重读设置 → 重开原本在跑的配置（页面需已打开）。
- **做不到**：替你**单独**开始 / 停止某条配置，也**读不到实时日志与命中记录**——它不知道你监控到了什么、监控是否在跑；`feature_restart` 是整体停掉再按原运行项重开。
- **绕道**：把日志内容手动粘贴给 AI 解读；或让 AI 处理别的频道相关需求（查价、名单统计）。

## 常见失败与处置 {#errors}

| 界面提示 / 现象 | 原因 | 处置 |
|---|---|---|
| 「监控关键词不可为空」 | 关键词行全被删光 | 「监控关键词」分组至少保留一行，或点「添加关键词」 |
| 角色列表为空 | 日志路径不对，或目录里没有该角色的日志 | 「设置 → 游戏日志」核对路径，回本页点「刷新列表」 |
| 某个关键词一直不命中 | 该行正则表达式写错了 | 检查表达式语法；写错的正则不会影响其他关键词 |
| 命中了但没有声音 | 声音文件路径失效 | 清空「音频文件」回落默认提示音，或重新选择文件 |
| 开始后角色旁没有「监控中」小条 | 该配置没有启动成功 | 看关键词校验提示；或重新点「开始监控」 |

## 限制与已知问题 {#limits}
- **异常日志当前隐藏**：配置的「日志类型」固定显示「游戏日志」，「添加配置」也只新建游戏日志配置；历史遗留的异常日志配置仍保留在配置文件里，不显示、不启动。
- **只盯新日志**：开始监控只对之后新写入的日志行生效，开始前的内容不会触发提醒。
- **非法正则静默跳过**：写错的正则那一行永远命中不了（也不影响其他关键词），界面不会报错。
- **实时日志有显示上限**：超出上限裁掉最早的行，只影响显示、不影响监控本身。
- **弹窗与声音按"角色 + 配置"各一份**：提醒来自哪个配置，标题里就能分辨出来。
