# 频道 · 日志监控

## 一句话 {#tldr}
盯着某个角色的**游戏日志**（不是聊天频道），日志里出现你设的**正则关键词**时用系统通知、置顶弹窗、提示音提醒你；支持每个角色多份配置、两种监控模式与循环提示音——挂机时不想漏掉日志里出现的特定字样就用它。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**日志监控**」。
- 页面三栏：左「**角色列表**」（每项是角色名 + 开始时间，监控中带黄色小条，底部**开始全部 / 停止全部 / 刷新列表**）；中「**监控设置**」（选中角色后出现，第一个页签固定是「**战斗日志**」，其后每份配置一个页签，页签头是配置名 +「**关闭配置**」×）；右「**实时日志**」（只读，右键「**清空内容**」）。

## 前置条件 {#prereq}
- 在「**设置 → 游戏日志**」里配置好日志路径（与「频道 · 监控」共用同一份配置）；左栏角色列表来自日志目录，目录里没有该角色的游戏日志就不会出现。

## 操作步骤 {#steps}

### 选角色与新建配置
1. 左栏点选一个角色；右键角色可「**打开日志文件**」「**打开日志文件夹**」。
2. 中栏底部「**添加配置**」新建一份游戏日志配置；每份配置是中栏的一个页签，页签头的 × 删除它。
3. 左栏底部「**刷新列表**」重新读日志目录。
4. 配置的增删与所有修改**立即保存**——不需要点开始才落盘，改完直接关窗口也不丢。

### 配置监控
1. 「**配置信息**」：日志类型（当前固定为「游戏日志」）+「**配置名称**」。
2. 「**监控模式**」：**出现关键词时通知**（命中即提醒）/ **停止出现关键词后通知**（关键词停止出现一段时间才提醒一次，配套「**判定时间间隔（s）**」）。
3. 「**通知方式**」：**系统通知**（托盘气泡）/ **弹窗通知**（置顶消息弹窗）/ **声音通知**；开声音后可选「**循环播放**」与自定义「**音频文件**」（点「选择」挑文件，留空回落内置默认提示音）。
4. 「**监控关键词**」：界面提示「游戏日志出现相应关键词时将发出通知，支持正则表达式」。点「**添加关键词**」加一行，在「**正则表达式**」框里改写；多个关键词**任一命中**即触发。

### 开始与停止
1. 中栏底部「**开始监控**」启动当前选中的配置；开始前会重新扫描游戏日志目录，把角色日志更新到最新日期的文件；关键词全空会提示「**监控关键词不可为空**」，开始后角色旁出现「监控中」黄色小条。
2. 左栏底部「**开始全部**」一次启动所有角色的所有配置；「**停止全部**」只在有配置运行时出现。
3. 「**清除通知**」只隐藏弹窗并停声，**监控仍在跑**。

### 看实时日志与弹窗
1. 右栏实时显示该角色的日志行：**命中关键词的行标红**，最新一条加粗，自动滚到底；超出显示上限裁掉最早的。
2. 弹窗通知复用频道监控的**置顶消息弹窗**（不出现在任务栏）：标题带「日志监控 - 角色 - 配置名」，新消息加粗并自动滚底。
3. 弹窗底部「**显示游戏窗口**」把对应的 EVE 客户端前置；右上角关闭同样只是隐藏。
4. 弹窗顶部会显示「**战斗日志**」状态条（被反跳 / 毁电 / 遥修 / 伤害 DPS…），只要该角色的战斗日志在运行就出现；状态条右上角「**清除战斗状态**」把当前所有行收掉（反跳 / 干扰之类的常驻行也靠它）。

### 战斗日志（遥修 / 电子战，阶段 357）
1. 中栏第一个页签固定是「**战斗日志**」（不可删除、不落盘）；其它页签仍是普通关键词监控，**新建配置只会建普通监控**。
2. 先打开「**启用战斗日志**」（它只表示"要不要监控"，不会自己开始），再点中栏底部「**开始监控**」：立刻开始读该角色的游戏日志，并弹出日志监控小窗；**即使还没发生战斗，窗口也会显示**（战斗区显示「无战斗」，不会因为没数据自动消失），停止监控时才关闭。卡片高度随内容行数变化，不会被拉伸去填满窗口。
   窗口标题栏右侧依次是：**清除所有日志**（橡皮擦：一次清掉战斗行 + 关键词命中，有内容时才出现）/ **前置游戏**（显示器图标，把 EVE 窗口切到前台）/ **最小化** / **关闭**；底部不再单独占一条按钮栏。
3. 「**过期时间**」默认 **60 秒**，可手动输入任意秒数：数值类卡片超过这个时间没有新日志就**整体置灰**（卡面不写「已过期」，悬停提示才显示）；日志行**不会自动消失**，只有手动点「清除所有日志」或停止监控才会清掉。状态类（电子战 / 反跳）另有「**状态变灰**」时间，默认 **300 秒（5 分钟）**，同样只变灰不消失。
4. 「**显示分类**」可逐项勾选（跃迁扰频器 / ECM / 停滞缠绕光束 / 目标标记装置 / 武器扰断器 / 毁电 / 远程感应抑阻器 / 其他电子战 / 遥修 / 吸电 / 传电 / 伤害），**默认全部勾选**；设置里只记录"取消的项"，所以以后新增的分类默认也是开的。勾上的分类全部显示（卡片会换行并可滚动）。
5. 卡片行文统一为「**数量 单位　每秒 单位/s**」（中间用空格，不再有 `/`），例如 `45 GJ 22.5 GJ/s`；伤害同样是 HP 与 HP/s（如 `200 HP 66.7 HP/s`）。
   卡面上**不写"输入 / 输出"**，方向放在**悬停提示**里（每行一条，带装备、来源、实测间隔、时间）。
   文字颜色看**对你来说是收益还是伤害**：**伤害红、收益绿、中性黑白**——
   - `伤害` / `毁电` / `吸电`：别人打你 / 毁你 / 吸你 = **红**（输入），你打 / 毁 / 吸别人 = **绿**（输出）；毁电按日志里的名字判断——`舰船* [军团] [角色]` 是别人毁你（红），`角色 (舰船*)` 是你毁别人（绿）；
   - `遥修` / `传电`：别人修你 / 传你电 = **绿**（第一行），你修别人 / 传电给别人（只是把资源给出去，不算伤害也不算收益）= **黑白**（第二行）；
   - **吸电 + 传电合并成一张「电容」卡**：行尾标 `吸电` / `传电`，输入输出都列；\n   - **遥修按护盾 / 装甲 / 结构分行，输入与输出都列**：同一张卡片里垂直列出，每行末尾标类型（如 `100 HP 50 HP/s 护盾`、`0 HP 结构`），**0 值也照样显示**；最多六行，行多时字号自动缩小。\n   每一行里**数量用大字号**（16 / 行多时 15），单位 / 每秒 / 类型用小字号（10），例如 `100`（大字）`HP 50 HP/s 护盾`（小字）；两者**底部对齐**。\n   卡片按可用宽度**等宽排布**：先水平铺开，放不下就换行，同一行卡片**宽度一致、高度也一致**（矮卡拉伸到本行最高），一行只剩一张时该卡铺满整行。\n   战斗区**没有固定高度上限**：内容多就往下长，窗口不够高时在卡片区滚动，窗口拉高就能看全。
6. **电子战按装备分组显示**（跃迁扰频器 / ECM / 停滞缠绕光束 / 目标标记装置 / 武器扰断器 / 远程感应抑阻器），型号不同但同组就共用分组名；**跃迁扰断器与扰频器按 SDE 同组，合并为「跃迁扰频器」**。**自己的装备对别人用 = 绿，被别人施加 = 红**，不再用「被…」措辞。认不出型号的电子战行归入「**其他电子战**」，不静默丢弃。状态类只在"作用上"时写一条日志，所以不会超时消失（只按「状态变灰」时间变灰），保留到你点「清除所有日志」或停止监控。
7. 数据同时供「**多开**」预览窗叠加层使用；多开那边只负责"显不显示"，不自己读日志——这里没开，多开就没有战斗行。叠加层只显示**输入**侧（别人打你 / 毁你 / 吸你 / 修你），你自己的输出只在日志窗口里。
8. 普通关键词配置的命中，也可以在「多开 → 全局设置 → 显示关键词命中」里选择显示到预览窗（默认关闭，保留 30 秒）。
9. 日志监控小窗可以**拖边缘 / 拖角自由缩放**（没有最小尺寸）；窗口按角色自动记忆最后的位置和尺寸、下次打开恢复（位置会限制在当前屏幕范围内）；「**窗口不透明度**」只让窗口背板变透明，文字与卡片始终实色（与频道预警小窗同一做法），100 = 完全不透明。

## 字段与口径 {#fields}

| 设置项 / 显示 | 含义 | 口径 |
|---|---|---|
| 配置名称 | 页签名与弹窗标题里显示的名字 | 每角色可配多份 |
| 监控模式 | 命中即通知 / 停止出现后通知 | 「停止出现关键词后通知」才有「判定时间间隔」 |
| 判定时间间隔（s） | 关键词停止出现多久后判定"已消失"并提醒一次 | 秒 |
| 系统通知 / 弹窗通知 / 声音通知 | 三种提醒通道，可叠加 | 弹窗每个运行中的配置一个 |
| 循环播放 | 提示音循环 | 循环到「清除通知」 |
| 音频文件 | 自定义提示音路径 | 留空或路径失效回落默认提示音 |
| 监控关键词 | 正则表达式，一行一条 | 任一命中即触发；全空无法开始 |
| 实时日志行 | 只显示日志原文，最新一条高亮加粗 | 不再显示时间 / 配置名；只保留最近若干条 |
| 战斗日志：过期时间 | 超过该秒数没有新日志的卡片整体置灰，悬停提示只显示「已过期」 | 默认 60 秒，可手输任意秒数；**行不会消失**（只有手动清除/停止监控才清），反跳 / 干扰不过期 |
| 战斗日志：数值行文 | 「数量 单位　每秒 单位/s」，遥修行尾再带类型 | 伤害也是 HP / HP/s；遥修分护盾 / 装甲 / 结构三行，0 值也显示；行数决定卡片高度 |
| 窗口不透明度 | 日志监控小窗背板的不透明度 | 1–100，100 = 不透明；只作用于背板，文字 / 卡片始终实色；窗口可自由缩放、无最小尺寸；位置与尺寸按角色自动记忆并在下次打开恢复 |
| 战斗日志：分类 | 控制哪些分类显示 | 12 类独立开关；数值分类显示"最近一次 + 按实测轮间隔算出的每秒速率"，电子战状态保留到清除 |

## AI 能替你做什么 {#ai}
- **可以读 / 改监控配置**：`config_read` / `config_write`（name=`gamelog`）读写白名单里的 `GameLogInfoSettings.json`（配置、关键词、判定间隔、通知方式），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`gamelog`，需确认）整体重启：停止全部会话 → 重读设置 → 重开原本在跑的配置（页面需已打开）。
- **做不到**：替你**单独**开始 / 停止某条配置，也**读不到实时日志与命中记录**——它不知道你监控到了什么、监控是否在跑；`feature_restart` 是整体停掉再按原运行项重开。
- **绕道**：把日志内容手动粘贴给 AI 解读；或让 AI 处理别的频道相关需求（查价、名单统计）。

## 常见失败与处置 {#errors}

| 界面提示 / 现象 | 原因 | 处置 |
|---|---|---|
| 「监控关键词不可为空」 | 关键词行全被删光 | 「监控关键词」分组至少保留一行，或点「添加关键词」 |
| 角色列表为空 | 日志路径不对，或目录里没有该角色的日志 | 「设置 → 游戏日志」核对路径，回本页点「刷新列表」 |
| 某个关键词一直不命中 | 该行正则表达式写错了 | 检查表达式语法；写错的正则不会影响其他关键词 |
| 命中了但没有声音 | 声音文件路径失效 | 清空「音频文件」回落默认提示音，或重新选择文件 |
| 开始后角色旁没有「监控中」小条 | 该配置没有启动成功 | 看关键词校验提示；或重新点「开始监控」 |

## 限制与已知问题 {#limits}
- **异常日志当前隐藏**：配置的「日志类型」固定显示「游戏日志」，「添加配置」也只新建游戏日志配置；历史遗留的异常日志配置仍保留在配置文件里，不显示、不启动。
- **只盯新日志**：开始监控只对之后新写入的日志行生效，开始前的内容不会触发提醒。
- **非法正则静默跳过**：写错的正则那一行永远命中不了（也不影响其他关键词），界面不会报错。
- **实时日志有显示上限**：超出上限裁掉最早的行，只影响显示、不影响监控本身。
- **弹窗与声音按"角色 + 配置"各一份**：提醒来自哪个配置，标题里就能分辨出来。
- **战斗日志只覆盖有日志的电子战**：反跳 / 毁电 / 吸电 / ECM / 遥修 / 传电 / 承伤有日志；**网子、感应抑阻、武器扰断、目标标记没有日志行**，显示不了。
- **中文日志已按真实客户端校准**（伤害/遥修/毁电/吸电/ECM/反跳/未命中/0 值/第三方反跳）；以后遇到没见过的措辞会被收集到诊断里，补词表即可，不影响其它功能。
- **日志轮换已跟随**：游戏重开/换文件后，关键词监控与战斗日志都会自动切到该角色的最新日志（阶段 357 修复，旧版运行中会断流）。
