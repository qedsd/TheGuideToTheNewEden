# 频道 · 查价

## 一句话 {#tldr}
盯着某个角色的聊天频道，消息里出现**物品名**时自动识别并弹出**置顶查价窗口**：一条消息报了多个物品就汇总成卡片列表，只报一个就给出物品卡加**近三个月价格曲线**——别人在频道里问价，你不用再手动去市场页搜。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**频道查价**」。
- 页面三栏：左「**角色列表**」（运行中的角色带黄色小条，底部**开始全部 / 停止全部 / 刷新列表**）；中「**频道列表**」（复选框 + 频道名 + 时间，底部「**刷新列表**」）；右「**查价设置**」卡（底部**开始 / 停止 / 重置位置 / 同步全部设置**图标按钮）。
- 查价结果在**独立的置顶窗口**里显示（不出现在任务栏）。

## 前置条件 {#prereq}
- 在「**设置 → 游戏日志**」里配置好日志路径（与「频道 · 监控」共用），日志目录里要有该角色的聊天日志；游戏里加入过要监听的频道。
- 取价走所选**星域**的市场订单 / 历史（星域市场不需要登录角色）。

## 操作步骤 {#steps}

### 选角色、频道与市场
1. 左栏点选一个角色；中栏勾选要监听的频道（监控中时勾选与刷新被禁用）。
2. 右栏「**市场**」分组：点「**本地位置**」按钮，在弹层里搜索并选择星域（结果窗标题会带上所选星域名）。
3. 「**基本**」分组：**触发关键词**（留空则查询所有内容）与**多物品分隔符**（留空则把整条消息当单个物品识别）。

### 开始与停止
1. 右栏底部「**开始**」；成功后提示「**已开始监控频道**」，角色旁出现黄色「监控中」小条。
2. 左栏「**开始全部**」一次启动所有角色的监控；「**停止全部**」只在有角色运行时出现；「**重置位置**」让结果窗回到屏幕居中；「**同步全部设置**」把当前角色的设置复制给其他角色（需先停止所有，会弹确认框）。

### 看结果窗
1. 频道消息命中触发关键词后，消息里的名字会与本地市场物品库匹配，命中即弹出置顶结果窗；点关闭只是**隐藏**，下次命中再弹到前台并更新内容。
2. **多物品**（消息里用分隔符隔开多个名字）：顶部汇总卡显示物品数与整体卖 / 买的 5% 与 Top 价；下面每个物品一张卡片——**物品图标 + 名称 + 「详细」按钮**，5% / Top / 数量 三列的卖单与买单，以及「**过去7天**」的最高 / 平均 / 最低 / 总销量。
3. **单物品**：一张物品卡（字段同上）+「**过去三个月价格**」曲线（最高 / 平均 / 最低三条线，图例在顶部，图表支持横向缩放）。
4. 窗口右上角「**刷新**」重新取价；卡片上的「**详细**」跳到「**商业 → 市场**」页并选中该物品（主窗口随之置前）。

## 字段与口径 {#fields}

| 显示 / 设置项 | 含义 | 口径 |
|---|---|---|
| 5% | 前 5% 订单均价 | 卖单取最便宜 5%、买单取最贵 5%（与市场页同口径） |
| Top | 最优价 | 卖单最低价 / 买单最高价 |
| 数量 | 订单条数 | 卖 / 买各自统计 |
| 过去7天 · 最高/平均/最低/总销量 | 近 7 天历史统计 | 所选星域 |
| 过去三个月价格 | 三条历史价格线 | 最高 / 平均 / 最低 |
| 触发关键词 | 消息触发条件 | 留空 = 所有消息都尝试识别 |
| 多物品分隔符 | 拆分多个物品名的分隔符 | 留空 = 整条消息按单个物品识别 |
| 本地位置 | 取价的市场星域 | 结果窗标题同此星域 |

## AI 能替你做什么 {#ai}
- **可以读 / 改查价配置**：`config_read` / `config_write`（name=`channelmarket`）读写白名单里的 `ChannelMarketSettings.json`（关键词、分隔符、市场星域等），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`channelmarket`，需确认）整体重启：停止全部会话 → 重读设置 → 重开原本在跑的角色（页面需已打开）。
- **做不到**：替你**单独**开始 / 停止监听或勾选频道，也不能读取结果窗内容与命中记录；更不能挂在你的聊天频道上自动弹窗。
- **绕道**：价格查询本身已被市场工具覆盖——直接问 AI「XX 在伏尔戈多少钱」可以用市场工具取实时订单与历史，但那是一次一答，不会持续盯频道。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 中栏 / 右栏不显示 | 未选中角色 | 左栏先点选一个角色 |
| 频道列表为空或勾不了 | 日志里没有频道，或正在监控中 | 未监控时点中栏「刷新列表」；监控中先停止 |
| 报了物品名却不弹窗 | 名字没命中本地市场物品库（别名 / 错别字 / 非市场物品） | 用游戏内物品全名；确认分隔符设置与消息格式一致 |
| 结果窗不见了 | 被点关闭（关闭即隐藏）或被别的窗口挡住 | 再次命中会自动弹到前台；或点「重置位置」 |
| 价格一直不变 | 命中了取价缓存 | 点结果窗右上角「刷新」重新取 |
| 物品图标空白 | 图片下载失败或运行环境受限 | 不影响价格数据，可忽略 |

## 限制与已知问题 {#limits}
- **物品识别只认本地市场物品库**：识别不出的名字（简称、错别字、非市场物品）不会触发弹窗。
- **「详细」只选中右侧物品**：跳转后订单 / 历史随之加载，但左侧市场树不会显示选中高亮。
- **价格按所选星域取数并带缓存**：不同星域价格不同；结果窗标题里就是当前星域。
- **图标取自网络**：加载失败就留空、只显示文字，不影响数值。
- **多物品与单物品是两种版式**：单物品卡片与价格曲线只在"识别出的物品只有一个"时出现，其余情况走卡片列表。
