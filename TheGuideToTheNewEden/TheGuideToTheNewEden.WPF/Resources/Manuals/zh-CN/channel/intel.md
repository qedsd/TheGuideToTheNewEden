# 频道 · 预警

## 一句话 {#tldr}
盯住角色聊天日志里的情报频道，按「本地位置 + N 跳范围」把提到敌情的星系在**置顶预警小窗**的星图上点亮，并可同时发声、发系统通知、订阅 ZKB 击杀预警。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**频道预警**」。
- 页面三栏：左「**角色列表**」（运行中的角色带橙条，悬停提示「预警中」）、中「**频道列表**」（复选框 + 频道名 + 最后更新时间）、右「**预警设置** / **频道内容**」两个页签。
- 「预警设置」下有六个可折叠分组：**预警范围 / 通知方式 / 预警弹窗 / 预警声音 / 关键词 / 其他**；「预警弹窗」「预警声音」只在对应通知方式勾选后出现。
- 「通知方式」勾上「**弹窗**」后才会另开一个**预警小窗**：始终置顶、不显示在任务栏；新版小窗只保留标题栏 / 星图 / 底部频道内容抽屉，不再单独显示本地、范围或预警/降级计数。

## 前置条件 {#prereq}
- 在「**设置 → 游戏日志**」里填对**游戏日志路径**（说明是"只需选择 logs 文件夹"）；本页默认读它下面的聊天日志目录。没填时用默认位置（我的文档下的 EVE 日志目录）。
- 该目录里要**有角色的聊天日志文件**：左栏角色列表和中栏频道列表都是从日志里读出来的；日志目录不可用或没有聊天日志时，左栏为空，需要先配置正确的日志路径。
- 游戏里**加入过要监听的情报频道**（例如本地频道），日志里才有这个频道可选。
- 角色要有**本地位置**：手动选一个星系，或勾「自动更新本地位置」由本地频道带出来。特殊星系不支持预警。

## 操作步骤 {#steps}

### 选角色与频道
1. 左栏「角色列表」点选一个角色；橙条与「预警中」提示代表该角色正在跑预警。
2. 中栏「频道列表」勾选要监听的频道（可多选）。
3. 左栏底部三个按钮：**开始全部** / **停止全部**（有角色在运行时才出现）/ **刷新列表**（重新读日志目录；会清掉当前选中的角色，需重选）。
4. 日志目录里读不到频道时，中栏与右栏都不显示，这时点「开始预警」不会有任何反应：先回左栏「刷新列表」，或去「设置 → 游戏日志」核对路径。

### 定预警范围
1. 「**预警范围**」→「本地位置」：点按钮弹出搜索列表，可按星系名或星系 ID 过滤（列表本身含特殊星系），点选后作为预警中心。
2. 「范围跳数」：0–8 跳，超出这个跳数的星系不会触发。
3. 「自动更新本地位置」勾「是」：由本地频道自动跟着角色走。

### 选通知方式
- 「**通知方式**」三个勾选框：**弹窗 / 声音 / 系统**。弹窗＝预警小窗、声音＝按跳数配置的报警声、系统＝托盘气泡通知；「预警弹窗」「预警声音」两个分组只在对应勾选框勾上时出现。

### 配预警弹窗与声音
1. 「**预警弹窗**」：显示模式（**一直显示 / 必要时显示**）、显示样式（**默认 / SMT / Near2**）、不透明度滑条。
2. 「**预警声音**」：每跳一行，每行是 跳数 + 音量滑条 + **循环** + 声音文件框 + **选择**（打开文件对话框挑音频）。不同跳数可以配不同声音；文件框留空时播放内置的默认提示音。
3. 改「范围跳数」会**自动增行 / 删行**（行数＝跳数 + 1，从 0 跳起）：缩短范围会把超出的大跳数那几行连同已配好的文件一起丢掉。

### 配关键词与其他
1. 「**关键词**」：**忽视预警关键词**（命中就不预警）、**解除预警关键词**（命中就解除）；两个框可填多个关键词，用逗号隔开（界面提示「每个关键词使用,隔开」）。
2. 「预警星系名语言」：多选列表，用来匹配正文里的星系名，首项是 `default(en)`，其余是本地语言库。
3. 「**其他**」：**自动解除预警**（分钟）、**自动降低预警级别**（分钟）、**ZKB预警**（只对间隔多少秒内的 KB 触发）。

### 开始、看内容、用弹窗
1. 底部「**开始预警**」：校验通过后角色进入运行态；**运行中整个「预警设置」与频道勾选都会被禁用**，要改设置先停止。
2. 底部另有：**停止预警** / **清除声音** / **重置位置**（把小窗放回屏幕中央）/ **同步全部设置**（把当前角色设置覆盖到其他角色：会弹确认框，并先停止全部正在运行的预警）。
3. 「**频道内容**」页签逐条追加，格式 `角色 [时间] 发言人 > 内容`：预警行用危险色且**舰船名加粗**，解除行用成功色；超出显示上限会裁掉旧行，右键「**清除**」清空当前内容。
4. **ZKB 击杀行不会出现在本页「频道内容」里**：ZKB 预警只更新星图、报警声音与系统通知；新版小窗的频道抽屉会单独补一条“击杀”行（见「限制与已知问题」）。
5. **预警小窗**：顶部只有标题、角色名和「预警中 / 待命」状态；中间星图**始终绘制配置的 N 跳内全部星系**（安静星系为浅灰小点，仍可悬停/右键），「重点」只决定哪些节点/星门加亮和显示标签，**不会缩小 N 跳范围**。
6. 小窗底部是「**频道内容**」抽屉，默认收起只留摘要；点抽屉标题展开消息列表，可按 **全部 / 预警 / 解除 / 击杀** 过滤；展开后拖动抽屉上方的分隔条可调整高度。没有单独的「仅地图」按钮；抽屉收起时就是地图加一条摘要。
7. 星图悬停星系显示「星系名 + 跳数 + 最新预警内容」，右键预警中的星系可单独解除；滚轮缩放、拖拽平移、双击复位。右侧「**几何离群**」卡片表示**跳数仍在 N 跳内、但 2D 坐标远离视野中心**的星系，点击可定位，不代表超出范围。
8. 地图右下角竖排按钮：**重置地图** / **清除所有预警** / **停止声音** / **激活游戏窗口**；点「激活游戏窗口」前置 EVE。标题栏的 X = **停止该角色预警**（不是隐藏）。「必要时显示」模式下预警全部解除后会延迟一段时间自动隐藏，隐藏会一并停掉声音。

## 字段与口径 {#fields}

| 界面项 | 含义 | 口径 |
|---|---|---|
| 本地位置 | 预警中心星系 | 手选（可按名称或 ID 搜索，含特殊星系）或由本地频道自动定位 |
| 范围跳数 | 触发预警的跳数半径 | 0–8；按星门距离计算，超出的星系不预警 |
| 自动更新本地位置 | 是否跟着角色走 | 由本地频道回写；勾上后立即解析一次 |
| 弹窗 / 声音 / 系统 | 三个通知通道 | 可任意组合；弹窗与声音的后续分组按勾选显隐 |
| 显示模式 | 小窗何时出现 | 一直显示 / 必要时显示 |
| 显示样式 | 小窗星图样式 | 默认 / SMT / Near2（见限制） |
| 不透明度 | 小窗背板透明度 | 1–100，**只作用于背景**，文字与星图始终实色 |
| 音量 / 循环 | 每跳声音参数 | 音量 0–100；循环＝播完重播；文件留空用默认提示音 |
| 忽视 / 解除预警关键词 | 命中即不预警 / 即解除 | 逗号分隔多个 |
| 预警星系名语言 | 匹配正文用的星系名库 | 多选，`default(en)` + 本地语言库 |
| 自动解除预警 | 触发后自动解除 | 分钟粒度，≥1 |
| 自动降低预警级别 | 触发后自动降级 | 分钟粒度，≥0.5 |
| ZKB预警 / 间隔秒数 | 订阅 zkillboard 击杀 | 只把该时间窗内的 KB 计入；秒，≥1 |
| 频道内容各行 | 命中的聊天行 / 小窗频道抽屉 | 本页时间取日志里的 EVE 时间；新版小窗另补 ZKB 击杀行 |

## AI 能替你做什么 {#ai}
- **可以读 / 改预警配置**：`config_read` / `config_write`（name=`intel`）读写白名单里的 `IntelSettings.json`（每角色的频道、关键词、声音、范围等），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`channelintel`，需确认）整体重启：停止全部会话 → 重读设置 → 只重开原本在跑的角色（页面需已打开）。
- 能间接帮上忙的只读查询工具：`character_location`（我在哪，用来确认本地位置）、`map_route`（两地多少跳、怎么走）、`system_navigate`（跳到星图看某个星系）、`zkb_entity`（某个角色 / 军团最近的击杀）、`map_system_info`（星系资料）。这几个都不会改动你的数据，调用前不需要你确认。
- 推荐问法：「我现在在哪个星系」「这里到吉他多少跳」「XX 军团最近有什么损失」「读一下我的预警设置」。
- **做不到**：替你**单独**开始 / 停止某个角色的预警，也不能读取预警小窗与「频道内容」的实时文本；`feature_restart` 是整体停掉再按原运行项重开。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 未选择角色 | 左栏没有选中角色就开始预警 | 先点选一个角色 |
| `角色名: 请设置角色当前所处星系` | 该角色还没有本地位置 | 在「预警范围 → 本地位置」选一个星系，或勾「自动更新本地位置」 |
| `角色名: 当前星系不支持频道预警` | 本地位置是特殊星系 | 换一个普通星系 |
| `角色名: 请选择预警频道` | 日志里能读到频道，但一个都没勾 | 勾至少一个频道 |
| 日志目录里找不到该角色的频道 | 日志路径不对，或「聊天频道文件有效天数」太小 | 核对「设置 → 游戏日志」的路径与有效天数，再回左栏点「刷新列表」 |
| `角色名: 未找到聊天日志，请先在「设置 → 游戏日志」选择正确的日志路径（...）` | 聊天日志目录不存在或为空 | 打开「设置 → 游戏日志」选择 EVE 的 `logs` 目录，再回本页刷新 |
| `角色名: 添加预警服务失败` | 预警小窗 / 声音服务没能注册 | 确认系统托盘可用（受限环境下托盘会被系统拒绝），重启应用再试 |
| `开启ZKB预警失败，详情请检查日志：...` | ZKB 订阅没能启动 | 取消「ZKB预警」或稍后重试；详情看日志 |

## 限制与已知问题 {#limits}
- **小窗范围不裁剪**：小窗始终绘制配置的 N 跳内全部星系；「重点」只影响标签、节点亮度与星门强调，不会只保留本地/预警及其邻居，也不会缩小 N 跳范围。「几何离群」只表示 2D 坐标远离视野中心，仍属于当前范围。
- **ZKB 击杀行只在小窗频道抽屉显示**：本页「频道内容」仍只显示聊天日志行；小窗里 ZKB 击杀会标为「击杀」。
- **显示样式的 SMT / Near2 暂未生效**：设置项保留，目前一律按新版默认星图样式呈现。
- **角色列表只从聊天日志读取**：日志目录不可用或没有聊天日志时为空；请先在「设置 → 游戏日志」配置 EVE 的 `logs` 目录。
- **运行中不能改设置**：开始预警后「预警设置」与频道勾选整体禁用，先「停止预警」才能改。配置按角色分别保存，在开始预警时落盘。
- **频道列表右键的"打开文件 / 打开文件夹"没有做**；角色列表也**不支持拖拽排序**。
- **不透明度只作用于小窗背景**：文字与星图不会跟着变淡。
- **小窗是置顶窗且不占任务栏**：程序化唤出时**不抢焦点**，所以它不会自己盖到最前面；想回到游戏请点小窗右下角的「**激活游戏窗口**」。
- **批量设置先停后改**：点「同步全部设置」弹确认框，确认后会**先停止全部正在运行的预警**，再把当前角色的设置覆盖给其他角色（之后需重新开始）。
- **托盘气泡没有"每条通知"的身份**：点**任何**一条气泡都会顺带停掉全部报警声音；多条通知堆在操作中心时，点旧的那条执行的是最新一条的动作。
- **托盘在低完整性进程下会被系统拒绝**：应用若从受限目录 / 受限上下文运行，「系统」通知通道与"关闭到托盘"会不可用。
- **ZKB预警依赖第三方服务**：短时间内收不到击杀、或统计数据为 0，属服务端波动，不是本地故障。
- **星图的频道情报面板依赖本页**：要先在本页启动至少一个角色的预警，星图情报才有频道来源（ZKB 部分不依赖本页）。
- **自动解除 / 降低预警级别**按分钟设置（下限分别是 1 与 0.5），实际由小窗的固定周期检查，生效时间会比设置值稍晚；不勾就完全靠人工解除。
- **声音循环是"播完重播"**：两遍之间可能有极短间隙。
- **「频道内容」有显示条数上限**：超出后只保留较新的行；右键「清除」只清空当前内容，不影响正在运行的预警。
