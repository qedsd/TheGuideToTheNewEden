# 频道 · 监控

## 一句话 {#tldr}
盯着某个角色的游戏聊天频道，消息里出现你设的**正则关键词**时弹出**置顶消息弹窗**、播放提示音并发系统通知——挂机挖矿、站岗时不错过频道里喊你。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**频道监控**」。
- 页面三栏：左「**监控角色**」列表（运行中的角色带黄色小条，悬停提示「监控中」）+ 底部**开始全部 / 停止全部 / 刷新列表**三个按钮；中「**角色频道列表**」（复选框 + 频道名 + 最后更新时间）+ 底部「**刷新列表**」按钮；右栏是「**设置 / 频道内容**」两个页签 + 底部**开始监控 / 停止监控 / 清除通知**按钮。
- 未选中角色时，中栏与右栏不显示。

## 前置条件 {#prereq}
- 在「**设置 → 游戏日志**」里填对**游戏日志路径**（只需选择 logs 文件夹）；本页默认读它下面的聊天日志目录。没填时用默认位置（我的文档下的 EVE 日志目录）。
- 该目录里要**有角色的聊天频道日志文件**：左栏角色列表和中栏频道列表都是从日志里读出来的；「**聊天频道文件有效天数**」决定往前找多少天的文件（越大查找越慢）。
- 游戏里**加入过要监控的频道**，日志里才有这个频道可勾。

## 操作步骤 {#steps}

### 选角色与频道
1. 左栏点选一个角色；中栏勾选要监控的频道（可多选，勾选会按角色记住，下次自动恢复）。
2. 左栏底部「**刷新列表**」重新读日志目录（同名角色仍在列表里会保持选中）；中栏底部「**刷新列表**」只重新载入当前角色的频道列表并恢复已勾选项。游戏里新开/新进频道后，点左栏那个才会出现。
3. 左栏底部「**开始全部**」一次启动所有角色；「**停止全部**」只在有角色运行时出现。

### 配置通知与关键词
1. 右栏「**设置**」页签 →「**通知方式**」：**系统通知**（托盘气泡）/ **弹窗通知**（置顶消息弹窗）/ **声音通知**（提示音）/ **循环播放**（声音循环到被清除为止）。
2. 「**音频文件**」框填自定义提示音路径，或点「**选择**」挑文件（支持 mp3/wav/wma/flac）；留空或文件不存在时播放内置默认提示音。
3. 「**监控关键词**」：界面提示「游戏日志出现相应关键词时将发出通知，支持正则表达式」。点「**添加**」新增一行（默认 `.*`，即匹配一切），在「正则表达式」框里改写；每行右侧的删除按钮移除该行。多个关键词**任一命中**即触发。

### 开始与停止
1. 底部「**开始监控**」启动当前角色；开始前会重新扫描日志目录，把勾选频道更新到最新日期的聊天日志文件；成功后右下角出现「开始监控：角色名」通知，角色名旁出现黄色「监控中」小条。
2. 开始前会校验：没选角色提示「未选择角色」、关键词全空提示「监控关键词不可为空」、没勾频道提示「未选择监控频道」。
3. **运行中**，「设置」页签与频道勾选会被禁用；要改设置先「**停止监控**」。
4. 「**清除通知**」只隐藏弹窗并停声，**监控仍在跑**。

### 看命中内容与弹窗
1. 「**频道内容**」页签逐条追加命中的消息，格式 `角色 [时间] 发言人 > 内容`（内容加粗，最新一条永远是粗体），自动滚到底；超出显示上限裁掉最早的，右键「**清除**」清空当前内容。
2. 开了「弹窗通知」后，每个角色有一个**置顶消息弹窗**（不显示在任务栏）：新消息追加并加粗、自动滚底，右键可「清除」。
3. 弹窗底部「**显示游戏窗口**」把对应的 EVE 客户端前置，并停止该角色的提醒（弹窗隐藏、声音停）。
4. 点弹窗右上角关闭同样只是隐藏并停声；系统通知（托盘气泡）标题为「频道监控 - 角色名」。

## 字段与口径 {#fields}

| 设置项 / 列 | 含义 | 口径 |
|---|---|---|
| 系统通知 | 命中时发托盘气泡 | 标题「频道监控 - 角色名」 |
| 弹窗通知 | 命中时弹出置顶消息弹窗 | 每个角色一个弹窗；不出现在任务栏 |
| 声音通知 | 命中时播放提示音 | 按系统音量的 100% 播放 |
| 循环播放 | 提示音循环 | 循环直到「清除通知」或点弹窗按钮 |
| 音频文件 | 自定义提示音 | 留空或路径失效时回落内置默认提示音 |
| 监控关键词 | 触发条件 | 正则表达式，一行一条；全部为空时无法开始 |
| 角色频道列表行 | 频道名 + 最后更新时间 | 来自日志文件，只列出有效天数内的频道 |
| 频道内容行 | 命中的消息 | 只显示命中关键词的消息；开始监控**之前**的历史消息不触发 |

## AI 能替你做什么 {#ai}
- **可以读 / 改监控配置**：`config_read` / `config_write`（name=`channelmonitor`）读写白名单里的 `ChannelMonitorSetting.json`（频道、正则关键词、通知方式），写入需确认、旧内容自动备份、可用 `config_restore` 回滚。改完用 `feature_restart`（name=`channelmonitor`，需确认）整体重启：停止全部会话 → 重读设置 → 重开原本在跑的角色（页面需已打开）。
- **做不到**：替你**单独**开始 / 停止某个角色的监控，也不能读取命中记录与弹窗内容；`feature_restart` 是整体停掉再按原运行项重开。
- 想用 AI 处理相关的事，只能绕道：比如让 AI 查某个物品的价格（市场工具）、查合同（`character_contracts`），或者把频道里看到的文本手动粘贴给 AI 解读。

## 常见失败与处置 {#errors}

| 界面提示 / 现象 | 原因 | 处置 |
|---|---|---|
| 「未选择角色」 | 没选角色就点了开始 | 左栏先点选一个角色 |
| 「监控关键词不可为空」 | 关键词行全被删光 | 回「设置」页签的「监控关键词」分组，至少留一行或点「添加」 |
| 「未选择监控频道」 | 中栏一个频道都没勾 | 勾上要监听的频道；没有频道就先回日志路径排查 |
| 「添加通知服务失败」 | 已存在同名角色的弹窗 / 声音实例（同名角色重复启动） | 先「停止监控」再重新开始 |
| 左栏角色列表为空 | 日志路径不对，或目录里没有聊天频道日志 | 去「设置 → 游戏日志」核对路径，再回本页点「刷新列表」 |
| 命中了但没有声音 | 声音文件路径失效 | 清空「音频文件」回落默认提示音，或重新选择有效文件 |

## 限制与已知问题 {#limits}
- **运行中锁设置**：监控运行时「设置」页签与频道勾选禁用，改配置要先停止。
- **只盯新消息**：开始监控只对之后新写入的日志行生效，开始前的历史消息不会触发通知。
- **角色与频道列表不自动刷新**：游戏里新产生的日志要点「刷新列表」才会出现；频道列表只列「聊天频道文件有效天数」内的文件。
- **弹窗与声音按角色各一个实例**：两个游戏客户端出现同名角色时会冲突（报「添加通知服务失败」）。
- **系统通知依赖托盘可用**：托盘不可用的环境下（如受限上下文里运行）气泡通知可能发不出来，弹窗与声音不受影响。
