# 频道 · 统计

## 一句话 {#tldr}
把游戏频道成员名单（Ctrl+C 复制的那一列名字）粘贴进来一键分析：统计每个角色的**军团 / 联盟归属与人数分布**，可选拉取 zkillboard 战绩（击杀 / 损失 / 威胁值 / 常用船等），配合**忽略名单**过滤已知的人——进频道先摸一遍底。

## 在哪打开 {#where}
- 左侧导航「**频道**」→「**频道统计**」。
- 页面三栏：左「**名称列表**」输入卡（占位提示「在游戏频道玩家列表处Ctrl+C后在此处Ctrl+V」，底部**分析**与**设置**两个图标按钮）；中「**设置**」卡（点「设置」展开，底部「**关闭**」收起）；右栏「**统计 / 详细**」两个页签，底部显示结果条数（`N 角色`）。

## 前置条件 {#prereq}
- **不依赖已登录角色**：名称解析优先查本地数据库，本地没有的名字会联网查 ESI；开启 ZKB 战绩还要访问 zkillboard——需要可用网络。
- 名单必须是**完整角色名**（不是简称 / 昵称），一行一个；游戏内复制的名单直接整段粘贴即可。

## 操作步骤 {#steps}

### 粘贴名单并分析
1. 游戏里打开频道成员列表按 Ctrl+C，回本页在「名称列表」里 Ctrl+V（多行直接粘贴）。
2. 点底部「**分析**」。识别成功后右栏出结果、底部显示条数；一个有效名字都没识别出来时提示「**未识别到有效角色名称**」。

### 看统计
1. 「**统计**」页签左右两张小卡：「**军团**」「**联盟**」，每行是徽标 + 名称 + 人数，按人数从多到少排；徽标取不到时只显示文字。
2. 注意口径：这里的人数是「**名单内归属该军团 / 联盟的人数**」，不是该军团的成员总数。

### 看详细表格
1. 「**详细**」页签是逐角色表格（列见下表）；列多，用表格下方 / 外层的滚动条横向查看。
2. 表格**右键**：忽略该角色 / 忽略该军团 / 忽略该联盟 / **重新获取ZKB信息**（对选中行原位重取战绩）。

### 设置 ZKB 与忽略名单
1. 左栏底部「**设置**」展开中栏。「**ZKB**」分组：勾「**分析ZKB数据**」后分析时顺带拉战绩（人多会明显变慢），「**获取ZKB数据最大数量**」限制最多为多少名角色拉取。
2. 「**忽略名单**」分组：勾「**启用忽略名单**」后，分析时会过滤名单里命中的角色 / 军团 / 联盟；「**结果详细包含在过滤名单中的角色**」「**结果统计包含在过滤名单中的角色**」两个开关决定被忽略的角色是否仍出现在「详细」表格或计入统计（不勾时人数按剔除忽略成员后计算）。
3. 点「**添加**」录入忽略项：数字 ID 可留空，填名称并选类别（角色 / 军团 / 联盟）后「**确定**」；重复添加会提示「**ID或名称已存在**」。列表里每项右侧的按钮可删除。以上设置（含忽略名单与 ZKB 设置）保存进 `Configs/ChannelScanSetting.json`，改动即落盘。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 角色 | 角色名 | 按名单输入顺序排列 |
| 军团 / 联盟 | 当前归属 | 本地库 + ESI 解析；无联盟时为空 |
| 威胁值 | zkillboard 的危险值（0–100） | 需 ZKB 数据 |
| 单挑击杀数 (占比) | 单挑击杀数及占总击杀的比例 | 需 ZKB |
| 总击杀数 / 总损失数 | zkillboard 累计击杀 / 损失 | 需 ZKB |
| 抱团概率 | 抱团作战的占比 | zkillboard 口径；需 ZKB |
| 拥有超期 / 可开黑诱导 | 是否有超级旗舰 / 隐秘诱导舰船的战绩记录 | 复选框列，需 ZKB |
| 最常用的船 / 最常用的船分类 | ZKB 战绩里出现最多的舰船与分类 | 需 ZKB |
| 最常出现的星系 / 最常出现的星域 | ZKB 战绩里最活跃的地点 | 需 ZKB |
| 统计页人数 | 军团 / 联盟的名单内成员数 | 剔除忽略成员；徽标 + 名称 + 数量展示 |
| 结果条数 | 识别出的角色数 | 卡片底部「N 角色」 |

## AI 能替你做什么 {#ai}
- 工具：`channel_scan`（只读，无需确认）。把名单发给它，返回**军团 / 联盟人数排行**；参数 `withZkb` 开启后附带前若干人的 ZKB 摘要（危险值 / 抱团 / 击杀 / 损失）。
- 推荐问法：「统计这份名单，看看有哪些大团」「这 13 个人是哪个军团的，顺带查下威胁值」。
- **规模限制**：工具一次最多 300 个名字，默认列前 10 个军团 / 联盟（上限 30）、ZKB 只查前 15 人（上限 30）；更大的名单请用本页处理（页面的 ZKB 上限可自己调）。
- **做不到**：工具只给人数排行与 ZKB 摘要，没有页面的 14 列详细表格；不管理忽略名单；拿不到在线状态；也不能替你点「重新获取ZKB信息」或修改页面设置。

## 常见失败与处置 {#errors}

| 界面提示 / 现象 | 原因 | 处置 |
|---|---|---|
| 「未识别到有效角色名称」 | 粘贴内容里没有可识别的完整角色名 | 确认复制的是频道成员列表；名单一行一个完整名字 |
| 分析很慢 | 本地库没有的名字要逐个查 ESI；开了 ZKB 还要逐人拉战绩 | 先关掉「分析ZKB数据」或调小「获取ZKB数据最大数量」看归属 |
| 「详细」里 ZKB 各列是空的 | 本次分析没开「分析ZKB数据」，或该角色没有公开战绩 | 勾上后重新分析，或选中行右键「重新获取ZKB信息」 |
| 「请输入规范的数字ID」 / 「请输入名称」 | 忽略项的 ID 填了非数字，或名称为空 | 按提示补齐；数字 ID 可留空 |
| 「ID或名称已存在」 | 忽略名单里已有同名或同 ID 项 | 直接用现有项，无需重复添加 |

## 限制与已知问题 {#limits}
- **ZKB 是第三方服务**：战绩数字随服务端统计波动，两次分析的结果可能不同，某次取不到也可能是服务端的问题而非本机故障。
- **超期 / 黑诱判断来自公开战绩**：该角色在 zkillboard 没有记录时，这两列判断不出来；有战绩也不代表现在仍如此。
- **徽标加载失败只显示文字**：军团 / 联盟徽标取不到时不会重试，人数不受影响。
- **忽略名单是全局一份配置**：对所有分析生效，不按会话区分；只想临时排除某人时，直接删名单里那一行再分析。
