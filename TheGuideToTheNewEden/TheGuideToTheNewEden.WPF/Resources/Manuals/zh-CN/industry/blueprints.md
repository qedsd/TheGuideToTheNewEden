# 工业 · 蓝图浏览器

## 一句话 {#tldr}
按产品名搜索可制造的物品，查看它的蓝图、分组、最大流程、基础耗时，以及每流程的材料、产物（含发明概率）与技能需求。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**蓝图浏览器**」。
- 左侧是搜索与结果列表，右侧是蓝图详情表。

## 前置条件 {#prereq}
- 需要本地 SDE 主库已载入（蓝图 / 材料 / 产物 / 技能表）。
- 全部为本地查询，不联网、不需要角色授权。

## 操作步骤 {#steps}
1. 在搜索框输入产品名（支持中英文），回车或点「搜索」。
2. 在左侧结果里选一个产品。
3. 右侧标题显示产品名，副标题显示蓝图、分组、最大流程与基础耗时。
4. 详情表按「材料 / 产物 / 技能」三类列出名称、数量与备注（产物备注为成功率，技能备注为等级）。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 蓝图 | 生产该产品的蓝图名 | 本地库解析，查不到显示原始 ID |
| 分组 | 产品所属物品组 | 来自 groups 表 |
| 最大流程 | 单张 BPC 的最大流程数 | 0 表示 BPO / 不限制 |
| 基础耗时 | 单流程基础耗时（秒） | 未套 TE |
| 材料 | 每流程材料 | 未套 ME；数量为单流程 |
| 产物 | 每流程产物 | 发明产物带成功率 |
| 技能 | 该活动技能需求 | 等级 |

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关访问蓝图相关端点。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 搜不到物品 | 名称不匹配或该物品没有蓝图 | 换关键词；原矿 / 行星产物没有蓝图属正常 |
| 详情为空 | 主库未载入 | 检查 `Resources/Database/main.db` |
| 数量与游戏内不同 | 这里是每流程基础值 | 需套用 ME/TE 才是实际值 |

## 限制与已知问题 {#limits}
- 只列出**有制造 / 反应蓝图**的产物；纯采集物、行星产物、蓝图本身通常不在结果里。
- 一次最多返回 100 条搜索结果。
- 材料数量是**未套 ME** 的单流程值，不随角色蓝图变化。
