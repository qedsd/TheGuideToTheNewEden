# 工业 · 蓝图浏览器

## 一句话 {#tldr}
按产品名搜索可制造物品，用「输入材料 → 蓝图核心 → 输出产物」的配方视图查看每个活动，
并附带技能需求、精炼产出与压缩产物。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**蓝图浏览器**」。
- 左侧是搜索与结果卡片，右侧是配方可视化与技能/回收信息。

## 前置条件 {#prereq}
- 需要本地 SDE 主库已载入（蓝图 / 材料 / 产物 / 技能 / typeMaterials / compressibleTypes 表）。
- 全部为本地查询，不联网、不需要角色授权。

## 操作步骤 {#steps}
1. 在搜索框输入产品名（支持中英文），回车或点搜索。
2. 在左侧结果卡片里选一个产品。
3. 右侧标题显示产品名、蓝图、分组、最大流程；下方是活动页签（制造 / 反应 / 发明 / 复制 / 研究等）。
4. 点活动页签切换配方：中间是蓝图核心与基础耗时，左侧是输入材料，右侧是输出产物。
5. 下方查看技能需求；右侧卡片显示精炼产出与压缩产物（如果有）。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 蓝图 | 生产该产品的蓝图名 | 本地库解析，查不到显示原始 ID |
| 分组 | 产品所属物品组 | 来自 groups 表 |
| 最大流程 | 单张 BPC 的最大流程数 | 0 表示 BPO / 不限制 |
| 基础耗时 | 该活动单流程基础耗时（秒） | 未套 TE |
| 材料 | 每流程材料 | 未套 ME；数量为单流程 |
| 产物 | 每流程产物 | 发明产物带成功率 |
| 技能 | 该活动技能需求 | 等级 |
| 精炼产出 | typeMaterials 回收表 | 单件回收产出，未套效率 |
| 压缩产物 | compressibleTypes | 压缩后的物品与体积 |

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关访问蓝图相关端点。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 搜不到物品 | 名称不匹配或该物品没有蓝图 | 换关键词；原矿 / 行星产物没有蓝图属正常 |
| 详情为空 | 主库未载入 | 检查 `Resources/Database/main.db` |
| 数量与游戏内不同 | 这里是每流程基础值 | 到制造计划页套 ME/TE/rig |

## 限制与已知问题 {#limits}
- 这是**浏览型页面**，搜索结果保留在左侧列表；制造计划的目标在目标 Tab 的左侧常驻物品树中选择。
- 只列出**有制造 / 反应蓝图**的产物；纯采集物、行星产物、蓝图本身通常不在结果里。
- 一次最多返回 100 条搜索结果。
- 材料数量是**未套 ME** 的单流程值，不随角色蓝图变化。
- 还没有「拥有的蓝图」叠加、分类/分组筛选、T2/T3 生产链跳转。
- 精炼产出未套回收效率 / 技能 / 建筑 rig。
- 启用本地化数据库时，材料/产物/技能/回收名称与分组名按本地化库显示；缺译条目回落英文。
