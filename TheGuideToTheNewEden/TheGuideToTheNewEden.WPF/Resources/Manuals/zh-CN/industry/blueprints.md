# 工业 · 蓝图浏览器

## 一句话 {#tldr}
在左侧按分类 / 物品组树形浏览可制造物品，支持实时搜索；用「输入材料 → 蓝图核心 → 输出产物」的配方视图查看每个活动，
并附带技能需求。成品的回收 / 压缩当前未开放入口，不混在蓝图浏览器里。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**蓝图浏览器**」。
- 左侧是可制造物品树与搜索，右侧是配方可视化与技能需求。
- 右侧配方区只保留「输入材料 → 输出产物」两栏和中间的细箭头；蓝图名、最大流程写在标题副标题，活动耗时写在活动页签，不再有中间的大图标/蓝图卡片。

## 前置条件 {#prereq}
- 需要本地 SDE 主库已载入（蓝图 / 材料 / 产物 / 技能表）。
- 全部为本地查询，不联网、不需要角色授权。

## 操作步骤 {#steps}
1. 在左侧树里展开分类 / 物品组，或在搜索框输入名称（支持中英文）；搜索会实时过滤并自动展开匹配项。
2. 选中一个物品，右侧加载它的全部活动。
3. 右侧标题显示产品名、蓝图、分组、最大流程；下方是活动页签（制造 / 反应 / 发明 / 复制 / 研究等）。
4. 点活动页签切换配方：中间是蓝图核心与基础耗时，左侧是输入材料，右侧是输出产物。
5. 下方查看技能需求；成品的回收 / 压缩当前未开放入口。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 蓝图 | 生产该产品的蓝图名 | 本地库解析，查不到显示原始 ID |
| 分组 | 产品所属物品组 | 来自 groups 表 |
| 最大流程 | 单张 BPC 的最大流程数 | 0 表示 BPO / 不限制 |
| 基础耗时 | 该活动单流程基础耗时（秒） | 未套 TE |
| 材料 | 每流程材料 | 未套 ME；数量为单流程 |
| 产物 | 每流程产物 | 发明产物带成功率 |
| 技能 | 该活动技能需求 | 等级 |

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关访问蓝图相关端点。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 搜不到物品 | 树里没有该物品，或名称不匹配 | 换关键词；纯采集物 / 没有制造、反应、行星配方的物品不在树里 |
| 详情为空 | 主库未载入 | 检查 `Resources/Database/main.db` |
| 数量与游戏内不同 | 这里是每流程基础值 | 到制造计划页套 ME/TE/建筑改装件 |

## 限制与已知问题 {#limits}
- 这是**浏览型页面**：左侧是可制造物品树（分类 / 物品组），搜索实时过滤并自动展开匹配项；选中物品后右侧显示配方。
- 树里列出有制造 / 反应 / 行星开发配方的产物；纯采集物、蓝图本身通常不在树里。
- 材料数量是**未套 ME** 的单流程值，不随角色蓝图变化。
- 还没有「拥有的蓝图」叠加、分类/分组筛选、T2/T3 生产链跳转。
- 本页只展示蓝图配方与技能；成品的回收 / 压缩当前未开放入口，不混在蓝图浏览器里。
- 启用本地化数据库时，材料/产物/技能名称与分组名按本地化库显示；缺译条目回落英文。
