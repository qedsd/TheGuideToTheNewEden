# 工业 · 制造计划

## 一句话 {#tldr}
把「要造什么」递归展开成完整物料清单：哪些自己做、哪些直接买、要多少材料、安装费多少，并给出直接买与自建的参考对比。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**制造计划**」。
- 左侧是目标与参数，右侧是汇总卡与 BOM 结果表。

## 前置条件 {#prereq}
- 需要本地 SDE 主库（蓝图 / 材料表）已随程序更新。
- 安装费需要成本指数与调整价，首次计算会联网下载并缓存 1 小时。
- 角色抵扣（资产 / 在制任务 / 自有蓝图 ME-TE）需要已登录角色与对应权限；不选角色时只做数量展开。

## 操作步骤 {#steps}
1. 在「目标产物」输入物品名并搜索（支持中英文名），从结果里选一个。
2. 设置数量、ME、TE；用「市场位置」选择成本指数所在星系（星域 / 星系 / 建筑页签）。
3. 按需设置设施税、空间加成、rig 材料 / 时间加成。
4. 选择角色并勾选要参与的抵扣项（资产 / 在制任务 / 自有蓝图）。
5. 点「计算物料清单」：等待结束后，右侧显示汇总与逐层 BOM。
6. 点「复制采购清单」把需要采购的物品与数量复制到剪贴板。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 决策 | 该节点自制还是采购 | 有蓝图即可造；黑名单 / 环 / 深度限制会强制采购 |
| 需要 | 本节点要交付的数量 | 件的数量，已含父节点需求 |
| 产出 | 实际产出 | 每流程产出 × 流程数 |
| 流程 | runs | `ceil(需要 / 每流程产出)` |
| 采购 | 仍需购买的数量 | 需要扣除库存（资产 / 在制 / 挂机库）后的差额 |
| 安装费 | 作业安装费 | `EIV × 成本指数 × (1 + 设施税)` |
| 直接买 / 自建 | 目标产物的两种成本 | 平均价（直接买） vs 材料递归 + 安装费（自建） |
| 材料缩减 | ME 与 rig | `floor(qty × runs × (1−0.01ME) × (1−rigME))`，下限为流程数 |

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关读取蓝图 / 工业任务等原始数据，复杂计算请在页面完成。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 提示缺少本地库 | SDE 主库未载入 | 检查 `Resources/Database/main.db` 是否为新版 |
| 安装费为 0 | 未选星系或成本指数未取到 | 选择星系后重算；确认网络可用 |
| 材料数量与游戏内不一致 | ME/TE 或 rig 设置不同 | 按实际蓝图与结构 rig 调整参数 |
| 复制为空 | 尚未计算或无需采购 | 先计算，再复制 |

## 限制与已知问题 {#limits}
- rig 加成目前按**全局**一份值生效（不区分物类），也不区分设施分档。
- 成本指数取所选位置的星系；选星域时使用该星域的第一个星系。
- 买 / 建对比使用平均价，不是实时最低卖价，仅供量级参考。
- BOM 结果表是扁平缩进展示，不是可折叠树；超过 4000 行会截断显示。
