# 工业 · 制造计划

## 一句话 {#tldr}
把多个「要造什么」递归展开成完整物料清单：哪些自己做、哪些直接买、要多少材料、任务费用多少；
并按角色技能槽位（制造 / 发明 / 反应各 1–11）生成排产，展示每一步投入产出、角色分工、关键路径与瓶颈。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**制造计划**」。
- 页面分三个顶层页签：**计划设置**（计算前）/ **计划详细**（计算后）/ **已保存计划**。
  - 计划设置内含四个子页签：**目标 / 工艺 / 建筑 / 角色与市场**；
  - 计划详细内含两个子页签：**概况 / 生产详情**；生产详情内含 **排程 / 步骤 / 工位 / 关系 / BOM·成本**；
  - 已保存计划可保存/载入「目标 + 全部参数」，见下文。
- 右上角有悬浮「执行计划」按钮（计算中变为「停止计算」）；计算完成会自动切到「计划详细 → 生产详情 → 排程」（没有排产任务时回「概况」）。

## 前置条件 {#prereq}
- 需要本地 SDE 主库（蓝图 / 材料 / 产物 / 技能 / typeDogma 表）已随程序更新。
- 任务费用需要成本指数与调整价；EIV 使用 CCP `adjusted_price`，不使用市场挂单价；首次计算会联网下载并缓存 1 小时。
- 角色抵扣（资产 / 在制任务 / 角色自有蓝图（ME/TE 与 BPC 流程）/ 发明技能）需要已登录角色与对应权限；
  不选真实角色时只做数量展开与公开价格；自定义角色只补排产能力，不提供这些抵扣。
- 排产需要角色技能：制造 / 发明 / 反应槽位（各 1–11）与时间修正都由技能决定；未登录或技能读取失败时按每类 1 条保守估算，未选择角色时使用默认角色 11/11/11（按满技能估算）。没有登录角色时也可以添加「自定义角色」，只需填写名称和工业技能等级。
- 「拉取详细订单 / 盈利」会拉取「价格市场」所在星域的公开订单，首次较慢，之后按 10 分钟缓存；默认勾选。
- 拉取详细订单时，页面右下角会显示「第 X/Y 页」和进度条，不会锁住整个界面，可以继续切换 Tab 或操作其他功能；缓存命中时只显示阶段文案。
- 「成本指数位置」（计划设置 → 工艺）与「价格市场」（计划设置 → 角色与市场）相互独立：前者决定任务费用指数，后者决定详细订单、参考价与收入。
- 启用本地化数据库时，BOM / 成本与配方里的物品名会显示本地化名称。

### 自定义角色（无需登录）
- **添加**：「计划设置 → 角色与市场 → 参与角色」下方点「添加」，填写名称与技能等级；新建时全部工业技能默认 5 级，按实际角色改低即可。保存后勾选即参与计算。
- **技能**：制造/发明/反应槽位各 = `1 + 两项相关技能`（0–5 级，夹取 1–11）；制造/反应时间按 4%/3% 递减，发明时间暂按 ×1.0。窗口底部会实时预览槽位与时间修正。
- **范围**：自定义角色只影响排产，不提供角色资产、在制任务、角色自有蓝图或发明技能加成；价格与市场仍按公共数据。
- **持久化**：定义保存在 `Configs/IndustrySetting.json` 的 `CustomCharacters`，勾选写入 `SelectedCharacterIds`（负数 Id，与真实角色区分）；保存计划时会随设置快照保存。
- **编辑/删除**：自定义角色条目右侧的「编辑 / 删除」；删除不会影响真实角色。

## 操作步骤 {#steps}
1. 在「计划设置 → 目标」左侧的常驻物品树里搜索/展开分类、物品组；默认全部收起，输入搜索词会自动展开匹配项。
2. 点产物行尾的 `+` 加入右侧目标列表；在右侧数字框填写数量（可用上下箭头微调），同一物品会合并数量。每个目标行可以单独选择发明解密器：跟随全局 / 无解密器 / 指定解密器。
3. 在「计划设置 → 工艺」设置 ME/TE、成本指数位置、设施税、空间加成、发明解密器、发明尝试次数/成功率/BPC 每张流程、反应规则。
4. 在「计划设置 → 建筑」设置材料 / 时间 / 费用加成与设施税；可用「建筑档案」保存/应用整套加成，方便在不同建筑之间切换。
5. 在「计划设置 → 角色与市场」勾选参与角色，以及资产 / 在制 / 角色自有蓝图 / 技能；在「使用库存仓库」勾选要参与抵扣的仓库（仓库在「工业 → 库存」管理）；需要按某市场算价格时勾选「拉取详细订单 / 盈利」并选择「价格市场」（默认沿用成本指数位置）。在「建筑」里还可以设置 SCC 附加费（默认 4%）和行星出口税（默认 5%）。
6. 点「执行计划」：自动切到「计划详细 → 生产详情 → 排程」（全采购/无排产任务时回概况）。执行期间按钮变为「停止计算」，可以中止市场分页、角色读取和 BOM 展开；停止后已完成的数据保留。
7. 在「计划详细 → 生产详情」使用排程 / 步骤 / 工位 / 关系 / BOM·成本 五个子页签；右侧是选中任务详情、候选角色和「改派」。也可以在概况目标卡片的「BOM / 成本」或步骤行的「查看」直接跳到对应物品节点。
8. 概况里可对单个产物「复制本产物采购 / 导出本产物 CSV」，也可以「复制全部采购 / 导出全部 CSV」；采购清单已扣除库存/上游剩余。
9. 在「计划详细 → 生产详情 → BOM / 成本」里点节点左侧的箭头展开/收起；选中节点后右侧查看成本构成、发明数据、市场参考。
10. BOM / 成本节点详情可「强制制造 / 强制采购 / 加入黑名单」。
11. 需要复用一套配置时：在「已保存计划」填写计划名称 →「保存为新计划」；选中计划后可「载入 / 覆盖保存 / 重命名 / 删除」。保存会连同当前计算结果（每个物品的参考单价/成本/利润）一起落盘；载入直接显示保存时的快照，要按当前价格刷新请重新计算。

### 生产详情：排程、步骤、工位与关系
计算完成后自动进入「计划详细 → 生产详情 → 排程」（没有排产任务时回概况）；五个子页签：
- **排程**：只列有任务的产线；任务条按类型着色、无边框，名称放不下时自动省略（悬浮看完整名称/时间/产线）。时间轴按任务起止分段，长任务 / 长空闲段按 sqrt 压缩，总宽限制在约 1600–3600px，刻度按像素自适应（超过 24h 显示真实日期）；工具栏支持缩放 / 100% / 适配全宽与导出排程 CSV。在制任务显示为「在制 · 物品名」并占用对应槽位；行星任务在独立「行星」产线。按住鼠标左键可平移，滚轮照常滚动。
- **步骤**：按发明 / 反应 / 组件 / 总装分组；列出产出、投入（采购 / 库存 / 上游着色）、产线·时间与任务费；时间列是「开始 → 结束」，悬浮看耗时；行尾「查看」跳到 BOM / 成本节点。
- **工位**：按制造 / 发明 / 反应分组显示有任务的槽位卡片（制造 Accent / 发明 Success / 反应 Caution）；右上角「+N」= 该产线后续还有 N 个任务排队，不是额外槽位。
- **关系**：依赖树（目标在右、依赖在左）；浅灰线 = 依赖，橙线 = 关键路径；可拖拽平移、滚轮缩放。
- **BOM / 成本**：进入后右侧显示节点详情（任务详情面板隐藏），其他页签显示任务详情。
右侧「候选角色 / 分工依据」列出各角色槽位、时间修正与该任务耗时；「改派」把手动 pin 到该角色并重排；「自动排产」清除 pin。顶部「优化目标」可选最短完成 / 最低成本 / 平衡（最短完成为主排序）。概况另有 ROI、每槽位小时利润、资金占用与盈亏平衡单价。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 决策 | 该节点自制还是采购 | 有蓝图即可造；黑名单 / 环 / 深度限制 / 手动决策会覆盖 |
| 需要 | 本节点要交付的数量 | 件的数量，已含父节点需求 |
| 产出 | 实际产出 | 每流程产出 × 流程数 |
| 流程 | runs | `ceil(需要 / 每流程产出)` |
| 采购 | 仍需购买的数量 | 需要扣除库存（角色资产 / 在制 / 上游剩余）后的差额 |
| 任务费用 | Job Cost（任务费用） | `EIV × (成本指数 × 结构费用倍率 + 设施税 + SCC)`；EIV 使用 CCP `adjusted_price`，**不使用市场挂单价**；已包含在总成本/现金支出中 |
| 总成本 | 同口径自建成本 | 材料全量市值（含库存）+ 任务费用 |
| 现金支出 | 实际现金支出 | 需购买材料（扣库存）+ 任务费用 |
| 库存抵扣 | 库存材料市值 | 总成本 − 现金支出 |
| 参考收入 | 目标产物参考收入 | 实际产出数量 × 参考单价（优先最高买价，回退最低卖价 / 平均价） |
| 利润 / 利润率 | 参考利润 | 收入 − 总成本；利润单位 ISK，括号内为利润率（%） |
| 材料缩减 | ME 与建筑改装件 | `floor(qty × runs × (1−0.01ME) × (1−改装件ME))`，下限为流程数 |
| 建筑加成 | 材料/时间折扣与费用 | 建筑页的材料 / 时间 / 费用总加成；材料/时间与蓝图 ME/TE 相乘，费用先乘建筑折扣再乘设施税 |
| 发明 | 成功率 / BPC run / ME-TE | 基础概率 × 加密学 × 数据核心技能 × 解密器；失败尝试也计成本；BPC 可复用；工艺页可覆盖尝试次数 / 成功率 / BPC 每张流程（0 自动） |
| 反应 | 反应材料是否套 ME / 建筑改装件 | 默认不套；可在「工艺」手动打开 |

### 发明成本自定义
- **尝试次数**：0 = 自动 `ceil(BPC 需求 / 成功率)`；>0 手动。自动与手动都按每次尝试消耗数据核心 / 解密器 / T1 蓝图（未拥有时）。
- **成功率覆盖**：0 = 按加密学、数据核心技能、解密器计算；1–100% 手动覆盖。
- **BPC 每张流程**：0 = SDE 发明产物数量 + 解密器 run 修正；>0 手动。BPC 可多次使用，需求张数 = `ceil(生产流程 / 每张流程)`。
- 节点详情会显示尝试次数、BPC 需求 × 每张 run、期望成功数；手动次数不足时给出警告。

### 槽位与时间修正
- **槽位来自技能**：制造 = 1 + Mass Production + Advanced Mass Production；发明 = 1 + Laboratory Operation + Advanced Laboratory Operation；反应 = 1 + Mass Reactions + Advanced Mass Reactions，范围 1–11。多角色总产能 = Σ 各角色实际槽位，不是角色数 × 11。
- **时间修正**：制造按 Industry / Advanced Industry；反应按 Reactions / Advanced Reactions；发明暂按 ×1.0。同一任务在不同角色上耗时不同，技能高不等于一定选它。
- 技能读取失败时每类按 1 条保守估算；未选择角色时使用默认角色 11/11/11（按满技能估算）。

### 已保存计划与库存仓库
- **已保存计划**保存在 `Configs/IndustryPlans.json`，内容包括目标（TypeID × 数量）、完整参数快照（位置、税、ME/TE、建筑加成、解密器、角色、仓库选择、手动决策、黑名单、虚拟挂机库等），以及保存时的计算结果树（每个节点的参考单价、采购/自建成本、任务费、数量、收入、利润等）和排产快照（角色槽位、任务分配、开始/结束时间）。
- 结果快照中的价格属于计算时刻，不会随市场自动更新；需要最新价格时点「执行计划」重算。
- 同名保存会更新已有计划；「覆盖选中计划」用于把当前参数与当前结果写回左侧选中的计划。
- **库存仓库**在「工业 → 库存」中管理（多仓库、角色资产导入、搜索添加、CSV 导入导出）。
- 在「角色与市场 → 使用库存仓库」勾选后，计算时按勾选的仓库合并 TypeID 数量，并与角色资产一起抵扣材料；仓库的勾选状态随计划保存。
- 「抵扣角色资产」只控制角色资产；仓库是否参与由仓库勾选控制，两者互不替代。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 提示缺少本地库 | SDE 主库未载入 | 检查 `Resources/Database/main.db` 是否为新版 |
| 任务费用为 0 | 未选星系或成本指数未取到 | 选择星系后重算；确认网络可用 |
| 材料数量与游戏内不一致 | ME/TE、建筑改装件、反应材料规则或解密器不同 | 按实际蓝图 / 结构 / 解密器调整参数 |
| 利润为负或为空 | 未拉取详细订单 / 无买单 | 勾选「拉取详细订单 / 盈利」并先「刷新市场」 |
| 市场参考显示「无详细订单」 | 未拉取详细订单，或该物品在所选星域没有买卖单 | 勾选「拉取详细订单 / 盈利」；无订单时只能按平均价估算 |
| 物品名还是英文 | 本地化数据库未启用 / 该物品不在本地库 | 在设置中启用本地化数据库；缺译条目回落英文 |

## 限制与已知问题 {#limits}
- 设施税、空间加成、建筑加成可保存为多套「建筑档案」，但单次计算仍只使用当前应用的一套；不做每个产物独立建筑/并行多建筑。
- 成本指数取所选位置的星系；选星域时使用该星域的第一个星系，尚无「最便宜星系」对比。
- 一次计划只能选一个成本指数位置和一个价格市场；不做每个产物独立星系 / 多星系对比。产物列表不再单独显示星系。
- 概况的采购清单按该产物子树统计，已扣除库存/在制/上游剩余；全部采购清单按整个计划汇总。
- BOM / 成本卡片底部的细条是「成本占比」：该节点（含子树）全量成本 / 整个计划全量成本；底部只保留细条，不显示文字，悬浮提示说明「占计划总成本」；不是生产进度。节点详情里的三条才是采购材料/任务费用/库存抵扣的成本构成。
- 生产详情内部只有「BOM / 成本」页签显示节点详情；进入该页签时右侧任务详情面板会隐藏，排程/步骤/工位/关系页签则只显示任务详情。任务详情面板与内层 Tab 内容区顶部对齐，不再与 Tab 标题齐平。
- 价格市场默认沿用成本指数位置；可在「角色与市场」单独选择。只有拉取详细订单后才会拉取该市场的订单，未拉取时回退 CCP 全局平均价。旧设置文件首次加载会迁移到「详细订单开、挂卖单」的新默认值；已保存计划保留其自身参数。
- 买 / 建对比与利润优先使用详细订单（最低卖价 / 最高买价），未拉取时回退平均价，仅供量级参考。立即卖出会按可见买单档位逐档成交；超出可见买单量的部分会标黄提示“超出可见买单成交量”，挂卖单也会用买单总量做成交量警告。
- 详细订单来自公开星域订单，不含建筑订单；首次拉取整星域会较慢。
- 建筑页左侧是建筑档案列表，档案名称双击列表项内联编辑；右侧标题显示当前档案名，四个加成纵向排列，保存/删除在卡片底部。材料/时间与蓝图 ME/TE 相乘；费用按 `EIV × (成本指数 × 结构费用倍率 + 设施税 + SCC)` 计算，结构费用只作用于成本指数部分。结构/建筑改装件等来源需自行折算进三个总加成。
- BOM 展开制造(1)、反应(11)、发明(8)、行星开发(100)；T3 逆向在 SDE 中就是发明(8)：relic 30752（Intact Hull Section）产物为 T3 BPC，概率 0.26、20 runs，relic 按每次尝试消耗计入采购。复制/研究是蓝图 job，不是物料配方；回收/压缩是站点服务计算，不是 BOM 作业。
- 角色自有蓝图区分 BPO / BPC：BPO 无限流程；BPC 消耗剩余流程，节点详情会显示剩余与不足。蓝图 ME/TE 继续在「工艺」中手动设置；复制/研究任务入口暂时隐藏，不参与 BOM。T2 BPC 通过发明获得，BPC 不能研究。
- 利润按净收入计算：销售税必扣；默认「挂卖单」按最低卖价并再扣经纪人费，「直接卖给买单」按最高买价且不计经纪人费。
- 回收 / 压缩当前未开放入口（计算代码保留），不进入制造 BOM。
- 行星产物会进入独立的「行星」产线排程（不占制造/发明/反应槽位）；POCO 出口税默认 5%，可在「建筑」中修改。当前只有一个全局税率/一条行星线，没有殖民地、发射台和多行星物流。
- 在制任务会占用角色槽位并显示在甘特图中；跨角色的在制输入可用时间尚未建模，仍按库存抵扣处理。
- BOM 节点超过 6000 上限时会在概况显示截断警告。
- 多角色只聚合个人资产/任务/蓝图/技能，不含军团资产。
- 已保存计划包含结果快照，大型 BOM（数千节点）会明显增大计划 JSON；快照价格不会自动刷新。
- 调度器是启发式（关键路径 + 多优先级贪心），不保证全局最优；最低成本目前没有逐角色建筑/税系数，成本模式主要用于并列展示。
- 工位改派目前使用右侧候选角色按钮，尚未接入拖拽；手动 pin 锁角色，具体槽位由调度器选择。
- 旧保存结果没有排产快照，载入后需要重新计算才能看到调度。
- 库存按 TypeID 汇总，不区分地点/容器；一个仓库可包含多个角色的资产。
- BOM / 成本是扁平缩进卡片树，不是可拖拽节点图；超过一定节点数会截断。
- 工业页已支持中英文切换（切语言即时生效）；已保存计划快照里生成的旧文本与本地化库提供的物品 / 行星名不随语言重写，重新计算或重新保存后更新。
- 目标 Tab 的左侧常驻树只列出有制造 / 反应 / 行星开发配方的产物；目标数量在右侧目标列表里设置。
- 目标数量是“要造多少”，单次产出可能大于目标（如导弹一次 5,000 发）；结果标题显示 `×请求 → 产出`，收入按实际产出计算。
- 库存覆盖会区分来源：角色资产显示「库存」（绿），其他节点多产出的显示「上游剩余」（黄），在制显示「在制」；
  覆盖后不再展开 0 数量材料，这是抵扣，不是配方缺失。
- 纯采购节点如果资产已完全覆盖，也显示「库存」，采购数量为 0；详情的「总成本」会改称「库存市值」。
- 若想忽略库存强行生产，在节点详情点「强制制造」；强制制造会按需求排流程，不再扣库存。
