# 工业 · 制造计划

## 一句话 {#tldr}
把多个「要造什么」递归展开成完整物料清单：哪些自己做、哪些直接买、要多少材料、任务费用多少，
并用全宽可折叠生产链展示每层节点、成本构成、库存抵扣与参考利润。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**制造计划**」。
- 右上角有悬浮「计算制造计划」按钮；下面用 Tab 分区：**目标 / 工艺 / 建筑与 rig / 角色与市场 / 概况 / 生产链**。
- 概况与生产链各占整页宽度：概况负责全部产品总览与多产物对比，生产链负责逐层 BOM 和节点详情。

## 前置条件 {#prereq}
- 需要本地 SDE 主库（蓝图 / 材料 / 产物 / 技能 / typeDogma 表）已随程序更新。
- 任务费用需要成本指数与调整价；首次计算会联网下载并缓存 1 小时。
- 角色抵扣（资产 / 在制任务 / 自有蓝图 ME-TE / 发明技能）需要已登录角色与对应权限；
  不选角色时只做数量展开与公开价格。
- 「市场深度 / 盈利」会拉取「价格市场」所在星域的公开订单，首次较慢，之后按 10 分钟缓存。
- 拉取市场深度时，页面右下角会显示「第 X/Y 页」和进度条，不会锁住整个界面，可以继续切换 Tab 或操作其他功能；缓存命中时只显示阶段文案。
- 「成本指数位置」（工艺 Tab）与「价格市场」（角色与市场 Tab）相互独立：前者决定任务费用指数，后者决定市场深度、参考价与收入。
- 启用本地化数据库时，生产链与配方里的物品名会显示本地化名称。

## 操作步骤 {#steps}
1. 在「目标」Tab 左侧的常驻物品树里搜索/展开分类、物品组；默认全部收起，输入搜索词会自动展开匹配项。
2. 点产物行尾的 `+` 加入右侧目标列表；在右侧数字框填写数量（可用上下箭头微调），同一物品会合并数量。
3. 在「工艺」Tab 设置 ME/TE、成本指数位置、设施税、空间加成、发明解密器、发明尝试次数/成功率/BPC 每张流程、反应规则。
4. 在「建筑与 rig」Tab 设置全局建筑改装件的材料/时间效率，或按物品分类（Category）添加 rig。
5. 在「角色与市场」Tab 勾选参与角色，以及资产 / 在制 / 自有蓝图 / 技能；需要按某市场算价格时启用「市场深度 / 盈利」并选择「价格市场」（默认沿用成本指数位置）。
6. 点右上角「计算制造计划」：自动切到「概况」Tab。顶部是全部产品总览（总成本/利润/收入/现金/库存抵扣/任务费用/直接购买/体积），左侧是产物列表，右侧是选中产物的成本利润与采购清单。
7. 概况里可对单个产物「复制本产物采购 / 导出本产物 CSV」，也可以「复制全部采购 / 导出全部 CSV」；采购清单已扣除库存/上游剩余。
8. 切到「生产链」Tab，点节点左侧的箭头展开/收起；选中节点后右侧查看成本构成、发明数据、市场参考。
9. 生产链节点详情可「强制制造 / 强制采购 / 加入黑名单」。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 决策 | 该节点自制还是采购 | 有蓝图即可造；黑名单 / 环 / 深度限制 / 手动决策会覆盖 |
| 需要 | 本节点要交付的数量 | 件的数量，已含父节点需求 |
| 产出 | 实际产出 | 每流程产出 × 流程数 |
| 流程 | runs | `ceil(需要 / 每流程产出)` |
| 采购 | 仍需购买的数量 | 需要扣除库存（角色资产 / 在制 / 上游剩余）后的差额 |
| 任务费用 | Job Cost（任务费用） | `EIV × 成本指数 × (1 + 设施税)`；已包含在总成本/现金支出中 |
| 总成本 | 同口径自建成本 | 材料全量市值（含库存）+ 任务费用 |
| 现金支出 | 实际现金支出 | 需购买材料（扣库存）+ 任务费用 |
| 库存抵扣 | 库存材料市值 | 总成本 − 现金支出 |
| 参考收入 | 目标产物参考收入 | 实际产出数量 × 参考单价（优先最高买价，回退最低卖价 / 平均价） |
| 利润 / 利润率 | 参考利润 | 收入 − 总成本；利润单位 ISK，括号内为利润率（%） |
| 材料缩减 | ME 与 rig | `floor(qty × runs × (1−0.01ME) × (1−rigME))`，下限为流程数 |
| 建筑改装件（rig） | 材料/时间折扣 | 实际值 = 输入百分比 × 空间加成；按物品分类命中时优先于全局值 |
| 发明 | 成功率 / BPC run / ME-TE | 基础概率 × 加密学 × 数据核心技能 × 解密器；失败尝试也计成本；BPC 可复用；工艺页可覆盖尝试次数 / 成功率 / BPC 每张流程（0 自动） |
| 反应 | 是否套 ME/rig | 默认不套 ME/材料 rig；可手动打开 |

## 发明成本自定义 {#invention}
- **尝试次数**：0 = 自动 `ceil(BPC 需求 / 成功率)`；>0 手动。自动与手动都按每次尝试消耗数据核心 / 解密器 / T1 蓝图（未拥有时）。
- **成功率覆盖**：0 = 按加密学、数据核心技能、解密器计算；1–100% 手动覆盖。
- **BPC 每张流程**：0 = SDE 发明产物数量 + 解密器 run 修正；>0 手动。BPC 可多次使用，需求张数 = `ceil(生产流程 / 每张流程)`。
- 节点详情会显示尝试次数、BPC 需求 × 每张 run、期望成功数；手动次数不足时给出警告。

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关读取蓝图 / 工业任务等原始数据，复杂计算请在页面完成。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 提示缺少本地库 | SDE 主库未载入 | 检查 `Resources/Database/main.db` 是否为新版 |
| 任务费用为 0 | 未选星系或成本指数未取到 | 选择星系后重算；确认网络可用 |
| 材料数量与游戏内不一致 | ME/TE、rig、反应套用规则或解密器不同 | 按实际蓝图 / 结构 / 解密器调整参数 |
| 利润为负或为空 | 未启用市场深度 / 无买单 | 勾选「市场深度 / 盈利」并先「刷新市场」 |
| 市场参考显示「无市场深度」 | 未启用市场深度，或该物品在所选星域没有买卖单 | 勾选「市场深度 / 盈利」；无订单时只能按平均价估算 |
| 物品名还是英文 | 本地化数据库未启用 / 该物品不在本地库 | 在设置中启用本地化数据库；缺译条目回落英文 |

## 限制与已知问题 {#limits}
- 设施税、空间加成仍是全局一份；rig 已支持按物品分类，但还没有多套「建筑档案」。
- 成本指数取所选位置的星系；选星域时使用该星域的第一个星系，尚无「最便宜星系」对比。
- 一次计划只能选一个成本指数位置和一个价格市场；不做每个产物独立星系 / 多星系对比。产物列表不再单独显示星系。
- 概况的采购清单按该产物子树统计，已扣除库存/在制/上游剩余；全部采购清单按整个计划汇总。
- 生产链卡片底部的细条是「成本占比」：该节点（含子树）全量成本 / 整个计划全量成本；不是生产进度。节点详情里的三条才是采购材料/任务费用/库存抵扣的成本构成。
- 价格市场默认沿用成本指数位置；可在「角色与市场」单独选择。只有启用市场深度后才会拉取该市场的订单，未启用时回退 CCP 全局平均价。
- 买 / 建对比与利润优先使用市场深度（最低卖价 / 最高买价），未启用时回退平均价，仅供量级参考。
- 市场深度来自公开星域订单，不含建筑订单；首次拉取整星域会较慢。
- BOM 只展开制造(1)、反应(11)、发明(8)；复制(5)、研究(2/3/4)、T3 逆向工程(7)、行星开发、回收/压缩尚未进入 BOM。
- T1 蓝图自有时按 BPO 简化处理（视为可无限复制），暂不区分 BPC 剩余流程。
- 多角色只聚合个人资产/任务/蓝图/技能，不含军团资产。
- 生产链是扁平缩进卡片树，不是可拖拽节点图；超过一定节点数会截断。
- 新版工业页的部分静态文案（Tab/卡片标题等）仍是中文硬编码，英文界面待补语言键；物品/分组结果名已走本地化库。
- 目标 Tab 的左侧常驻树只列出有制造/反应蓝图的产物；目标数量在右侧目标列表里设置。
- 目标数量是“要造多少”，单次产出可能大于目标（如导弹一次 5,000 发）；结果标题显示 `×请求 → 产出`，收入按实际产出计算。
- 库存覆盖会区分来源：角色资产显示「库存」（绿），其他节点多产出的显示「上游剩余」（黄），在制显示「在制」；
  覆盖后不再展开 0 数量材料，这是抵扣，不是配方缺失。
- 纯采购节点如果资产已完全覆盖，也显示「库存」，采购数量为 0；详情的「总成本」会改称「库存市值」。
- 若想忽略库存强行生产，在节点详情点「强制制造」；强制制造会按需求排流程，不再扣库存。
