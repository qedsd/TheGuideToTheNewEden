# 工业 · 行星开发

## 一句话 {#tldr}
从目标 P4 产物或蓝图直接材料反推行星开发：需要哪些 P1 提取殖民地、P2/P3/P4 工厂殖民地、每个殖民地多少工厂/提取头，以及周期、建造/进口成本、日产和回本天数；同时可查看多角色殖民地。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**行星开发**」。
- 顶层页签：**我的殖民地 / 计划设置 / 计划详细 / 已保存计划**；打开页面默认显示「我的殖民地」。
  - 我的殖民地是左侧角色（只列有殖民地的角色，底部显示角色/殖民地总数）→ 中间该角色的殖民地列表（底部显示该角色统计）→ 右侧殖民地头部 + **产能 / 布局 / 设施 / 物流 / 引脚** 内嵌页签；页面本身不滚动，列表/表格各自滚动；
  - 计划设置含：**需求 / 行星选择 / 角色与产能 / 价格与税**；
  - 计划详细包含：概况、产物链（按配方依赖展开的节点树，带展开/收起）、殖民地分配、外购输入（各自独立页签，列表占满剩余高度）；
  - 已保存计划保存参数 + 计算结果快照，载入时不重新计算。

## 前置条件 {#prereq}
- 需要本地 SDE 主库中的 `planetSchematics` / `planetSchematicsTypeMap` 行星配方。
- 市场价格来自「价格与税」中选择的市场；首次拉取详细订单可能较慢，之后缓存。
- P0 资源与行星类型的对应关系是固定的领域表（8 类行星），不依赖当前本地 SDE 的 Equinox 行星资源表。
- 行星半径影响 CPU/PG 容量；本地 SDE 主库的 `mapDenormalizes.Radius` 已带每颗行星的真实半径（米）。在「行星选择」里加入候选行星后，每颗殖民地按它所在行星的真实半径算容量；不选候选行星时退回按手动半径（0 = 2000 km 估算）并明确标注。精确引脚/模板属于后续阶段。
- 「我的殖民地」需要角色授权包含 `esi-planets.manage_planets.v1`。

## 操作步骤 {#steps}
1. 在「计划设置 → 需求」的「直接选择行星产物」里搜索 P1–P4，填写数量后点「添加」。
2. 也可以搜索蓝图，填写目标制造数量后点「导入」；页面会取该蓝图的**直接材料中的行星产物**并按流程数合并到已选需求。成功导入不显示状态文字（右侧「已选需求」就是结果）；只有该蓝图没有行星产物等异常情况才在右下角弹出提示。
3. 在右侧「已选需求」设置需求周期（默认 7 天）和生产方式：
   - **自给自足**：P1 从 P0 提取，P2/P3/P4 逐层建工厂；
   - **进口模式**：只排目标工厂，配方输入全部外购并计进口税；
   - **混合模式**：自给生产，并先用「我的殖民地」已读取的工厂日产出抵扣输入需求；未刷新殖民地时不抵扣。
4. 在「行星选择」左栏用悬浮选择器搜索星系（中/英文、虫洞 J 编号都能搜；**包含虫洞/特殊星系**）：选中后该星系全部行星进入右栏；可以继续加别的星系，在右栏逐颗移除或一键清空。**右栏把某个星系的行星删空时，左栏该星系会自动消失**。每颗行星最多安排一个殖民地。
5. 在「角色与产能」勾选参与角色，设置每个角色的 CCU 和可用行星位；**未勾选角色时不限角色数量**，自动按「角色1、角色2…」分配（每个占默认行星位）。这里的「行星半径」只在**未选择候选行星**时生效（0 = 2000 km 估算）。
6. 在「价格与税」选择价格市场、POCO 税、销售税和经纪人费；可关闭市场价/设施建造成本。
7. 点右上角「执行行星计划」；计算期间右下角显示加载卡，右上角**只显示「停止」**（「执行行星计划」暂时隐藏），完成后自动切到「计划详细」并弹出结果提示。
8. 在「计划详细」查看产物链、殖民地分配和外购清单；提示区会列出候选行星不足、角色位不足、容量不足、价格缺失等风险。
9. 打开页面先在「我的殖民地」点右上角「刷新」：按勾选角色读取行星、提取器、工厂、库存和当前进出口；**读取期间「刷新」会被「停止」替换**，完成后按钮自动换回。左侧选角色，中间选殖民地，右侧查看完整详情（提取器/工厂、产能曲线、引脚位置图、库存与进出口、引脚明细）。
10. 执行计划**不会**自动保存计划：在「计划详细」里子页签（概况/产物链/殖民地分配/外购）header 的最右侧点「保存计划」才保存（默认名带时间，重名会自动加序号）；到「已保存计划」选中后「载入 / 删除」，**双击名称可重命名**。载入结果快照不会重新联网计算。

## 字段与口径 {#fields}
- PI 层级按配方依赖推断（不写死 ID）；P4 直接吃 P1 的特例正常展开。
- P1 提取按 CCP 衰减折算产出；周期影响产率。
- P2/P3 使用 Advanced Factory；P4 使用 High-Tech Factory，且只允许 Temperate / Barren。
- 工厂/提取头数量来自 CCU + 半径容量；按最低 CCU 估算，行星位逐角色检查；不算精确 pin/link。
- **半径只影响 CPU/PG 容量**：越大→链路开销越高→单殖民地可放设施越少（影响殖民地数、固定成本与回本）；不影响配方/周期/衰减/税/价格。常见行星差异小，5 万 km 以上才明显。
- 半径来源：本地库 `mapDenormalizes.Radius`；选行星按各自半径，未选用手动值（0 = 2000 km）。
- 候选行星决定可排范围：池里逐颗分配（提取需匹配 P0，P4 工厂需温带/贫瘠），一颗行星一个殖民地；不够时提示缺口，并按实际工厂折算下级输入。
- 「行星选择」两栏：左栏星系（带行星数）、右栏该星系行星；右栏删空后左栏同步移除。
- 选择器包含虫洞/特殊星系（J 编号、席拉）；与「价格市场」不同。
- 未勾选角色时自动命名「角色1、角色2…」（按默认行星位递增）；勾选后按真实角色名。
- 建造成本按设施参考价估算；收入按目标产物卖价，挂单再扣销售税 + 经纪人费。
- 外购模式只建目标工厂；其下输入按参考价采购，不生成提取/工厂殖民地。

### 计划详细
- **产物链**：按配方依赖展开的节点树（同制造计划 BOM），目标为根、配方输入逐层挂子节点；计划内生产的标「自产」，未安排生产的外购标「外购」、P0 标「提取」。
- 节点可展开/收起，右上角有「展开全部/收起全部」；卡片显示层级、需求/产出、工厂与殖民地数、行星类型、建造费用与每周期输入。
- 同一中间产物被多个目标共用时在各分支下各显示一次，数量仍是计划总需求。
- **殖民地分配 / 外购**：新增「行星」「半径 km」列；**缺匹配类型时该行仍显示（行星名留空、整行标红），数据按默认估算**；首列宽度自适应。
- **计划提示**：物品/行星名按本地化库显示，不混用 SDE 英文名。

### 我的殖民地
- 左栏：有殖民地的角色名称 + 殖民地数量，底部显示「N 个角色 · M 个殖民地」；未选择角色时中/右栏为空。
- 中栏：选中角色的殖民地简表（行星名、星系/类型/CCU/引脚数、提取/工厂摘要），底部显示该角色的殖民地/提取器/工厂统计。
- 加载中在页面右下角显示非阻塞进度卡（与制造计划一致）；完成后右下角提示成功/失败/取消。
- 读取失败、令牌失效、缺少 `esi-planets.manage_planets.v1` 权限等错误合并为一条右下角全局通知，不再显示顶部常驻警告条。
- 右栏：固定头部（行星/星系/CCU/引脚/提取器/工厂组摘要）+ 五个页签：
  - **产能估算**：提取器按 CCP 衰减估算未来 7 天（已停止按 0 计）；工厂单独显示理论满产上限，ESI 不提供工厂启停/输入库存，实际可能停产；
  - **设施清单**：不还原游戏内经纬度布局，也不画关系连线；ESI link 只是网络连接、不代表上下级，因此逐引脚平铺展示设施卡（角色、设施类型、Pin、连接数）；
  - **生产明细**：提取器程序与按配方合并的工厂组，显示周期、产量、输入；两个列表各自滚动；
  - **库存与物流**：库存/进口/出口；
  - **引脚明细**：引脚角色/类型/编号明细，列表自身滚动。
- 殖民列表缓存 5 分钟，单殖民布局缓存 2 分钟；「刷新」会强制刷新。
- 本地进口 = 工厂输入中不是本殖民地已生产/已提取的产品；出口 = 工厂产出中没有被本地工厂继续消费的产品。
- 设施清单不推断上下级；ESI link 不用于层级展示，也不渲染 3D 行星或位置图。ESI 没有写殖民布局接口，本页只读。

### 已保存计划
- 保存入口：「计划详细」子页签 header 最右侧的「保存计划」按钮（执行计划不会自动保存）；默认名带时间，重名加序号，新计划在最前。
- 列表里选中后可「载入 / 删除」，**双击名称可直接重命名**（会立即写盘）。
- 保存内容：目标、周期、生产方式、角色 CCU/行星位、价格参数、提取周期、半径、设施成本开关、当前产出抵扣开关，以及完整 `PlanetaryPlan` 结果快照。
- 结果快照保存产物链、殖民地分配、外购清单、KPI 与提示；载入后直接显示，不重新计算。
- 保存文件：配置目录 `Configs/IndustryPlanetaryPlans.json`（可保存多份、手动载入）。
- **页面参数会自动保存**：需求周期、生产方式、默认 CCU / 行星位、半径、提取周期、税率、价格市场、角色勾选与每个角色的 CCU/行星位都会在修改后约 0.4 秒自动落盘到 `Configs/PlanetaryPlanSetting.json`，重开页面沿用；执行计划时也会再存一次。

## AI 能替你做什么 {#ai}
- 可以用自然语言让你把“某个 P4 产物 / 某个蓝图需要多少 PI”整理成目标清单，但页面本身不暴露 AI 写工具。
- 读取结果、解释产物链/成本/缺口时，可把页面上的目标、周期、生产方式和结果快照一起提供给助手。
- 「我的殖民地」涉及角色授权数据；助手不会自动读取未在页面刷新出来的角色殖民。

## 常见失败与处置 {#errors}
- **P4 找不到工厂殖民地**：检查是否选择了 Temperate / Barren；其他行星没有 High-Tech 工厂。
- **角色位不足**：增加角色或提高每个角色的行星位；结果会把无法分配的殖民地标为「未分配」并提示。
- **没有价格/利润为 0**：先在「价格与税」刷新价格，或勾选「使用市场参考价」；没有订单时回退平均价，再缺失则明确提示。
- **我的殖民地显示“需要重新授权”**：在「角色」中移除该角色并重新授权，确保勾选 `esi-planets.manage_planets.v1`。
- **混合模式没有抵扣**：先到「我的殖民地」刷新；抵扣只使用工厂日产出，不使用角色资产库存。
- **蓝图导入为空**：该蓝图的直接材料里没有行星产物；请确认选择的是制造蓝图（回收 / 压缩入口当前未开放）。

## 限制与已知问题 {#limits}
- 阶段 1 只到殖民地产能级，不生成精确 CPU/PG/link/pin 文件，也没有 3D 行星/引脚。
- 候选行星模式已经按"每颗行星各自的真实半径"算容量，但仍是**殖民地级**排布：不落到具体引脚/链接，也不按游戏内行星资源丰度挑 P0（P0 与行星类型的对应是固定领域表）。
- 候选行星用尽仍未满足需求时，方案会保留已排部分并给出缺口提示（不会自动扩大候选池或改用未选行星）。
- 蓝图模式取蓝图**直接材料**中的行星产物，不递归展开成完整舰船 BOM。
- 「我的殖民地」只读；ESI 没有写殖民布局接口，不能从页面修改游戏内殖民地。
- 当前产出抵扣只使用实时工厂日产出，不使用角色资产库存。
