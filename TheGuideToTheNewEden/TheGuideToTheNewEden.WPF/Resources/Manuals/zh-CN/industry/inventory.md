# 工业 · 库存

## 一句话 {#tldr}
多仓库库存管理：从角色资产导入、搜索物品手动添加、CSV 导入/导出，并在制造计划中按仓库抵扣材料。

## 在哪打开 {#where}
- 左侧导航「**工业**」→「**库存**」。
- 左侧是仓库列表与新建/重命名/删除；右侧是「添加 / 导入」和「库存明细」。

## 前置条件 {#prereq}
- 数据保存在数据目录的 `Configs/IndustryInventory.json`，不依赖 SDE 数据库是否更新。
- 角色导入需要已登录角色与资产权限（`esi-assets.read_assets.v1`）。
- 物品名称本地化取决于本地化数据库是否启用；未启用时显示英文。

## 操作步骤 {#steps}
1. 新建仓库：在左下角输入名称 → 「新建仓库」。可创建多个仓库（例如「吉他」「驻地」「军团」）。
2. 手动添加：在「搜索物品」输入中英文名称 → 搜索 → 在结果列表选中 → 填数量 → 「添加到仓库」；同一物品会累加。
3. 角色导入：勾选右侧「从角色导入资产」中的角色 → 「合并导入」累加到当前仓库，或「覆盖导入」先清空当前仓库；多个角色的资产会按 TypeID 汇总。
4. CSV 导入：支持 `TypeId 或名称, 数量`（逗号/制表符/分号均可），自动跳过头行；名称无法唯一匹配的行会被跳过并计数。
5. CSV 导出：导出当前仓库为 `TypeId,Quantity,Name`（UTF-8 BOM），便于备份/编辑后再导入。
6. 修改数量：在「库存明细」选中一行 → 填数量 → 「设置数量」（设为 0 等同移除）；移除用「移除选中物品」。
7. 在「制造计划 → 计划设置 → 角色与市场 → 使用库存仓库」勾选要参与抵扣的仓库；计算时这些仓库的物品种类/数量会与角色资产合并。

## 字段与口径 {#fields}
| 项 | 含义 | 口径 |
|---|---|---|
| 仓库 | 一组 TypeID → 数量 | 多个仓库互不自动合并，计划里按勾选合并 |
| 摘要 | 仓库规模 | 物品种类数 · 总件数 |
| 数量 | 库存件数 | 同一 TypeID 累加；添加/合并导入都是加法（覆盖导入除外） |
| 体积 | 打包体积 | `打包体积 × 数量`；缺打包体积时回退单位体积 |
| CSV | 交换格式 | 首列 TypeId 或名称，次列数量；导出为 `TypeId,Quantity,Name` |
| 计划抵扣 | 库存如何参与 BOM | 勾选仓库的物品与角色资产合并后，用于扣减各层材料需求 |

库存本身不触发计算；只在「制造计划」勾选仓库后参与扣减。「抵扣角色资产」只控制角色资产，仓库是否参与由「使用库存仓库」控制，两者互不替代。覆盖导入会清空当前仓库，不确定时用「合并导入」或先导出 CSV 备份。

## AI 能替你做什么 {#ai}
- 本页暂无专用工具；可用 `esi_*` 通用网关读取角色资产，或在制造计划页查询计算结果。

## 常见失败与处置 {#errors}
| 现象 | 原因 | 处置 |
|---|---|---|
| 导入后数量不对 | 合并导入会累加 | 需要干净数据时用覆盖导入，或先删除仓库重建 |
| CSV 大量行被跳过 | 名称不唯一 / 数量列不是数字 | 改用 TypeId；检查分隔符与数量列 |
| 角色列表为空 | 未登录角色 | 先在角色页登录 |
| 计划没有扣库存 | 未勾选仓库，或未重新计算 | 在「角色与市场 → 使用库存仓库」勾选后重算 |

## 限制与已知问题 {#limits}
- 仓库不区分地点/容器，只按 TypeID 汇总；不做逐地点库存。
- 角色导入为一次性快照，不会自动刷新；需要最新资产时重新导入。
- CSV 只支持「一个物品一行」的简单格式，不支持游戏内多级容器导出。
- 数量按长整数存储；超过 `long` 的极端值会被截断。
- 仓库与角色资产都不含军团资产。
