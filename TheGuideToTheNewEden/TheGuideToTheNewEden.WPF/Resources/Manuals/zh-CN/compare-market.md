# 商业 · 比价

## 一句话 {#tldr}
把一批物品放到**多个市场**（星域 / 星系 / 建筑）比现价：卖出组找「在哪卖到手最多」，买入组找「在哪买最便宜」，并算出「分散到各自最优」比「全挤在一个市场」多赚多少——判断这批货值不值得分地卖。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**比价**」（排在倒货与估价之间）。
- 左栏四个页签「**市场 / 卖出物品 / 买入物品 / 价格**」，底部是「**开始计算**」按钮；右栏自上而下是汇总条、警告条与结果区（外层按卖出 / 买入分组，内层「全部 + 各市场」）。
- 取数等待只盖住本页（居中卡片：进度文案 + 「**取消**」按钮），结束 / 失败 / 取消走右下角通知；切去别的页面再回来，结果还在。

## 前置条件 {#prereq}
- 星域 / 星系市场**不需要登录**（匿名 ESI）；**建筑市场**需要角色授权且对该建筑有市场访问权，否则该市场取数失败。
- 至少要有一个市场，上限 **12 个**；市场越多取数越慢。
- 卖出 / 买入是**两张独立清单**，同一物品可以同时在两组；市场清单、两组物品、口径与税费会自动存档，下次进来恢复。

## 操作步骤 {#steps}

### 配市场
1. 「市场」页签 →「**添加市场**」→ 在选择器里选星域 / 星系 / 建筑；每个市场一行，行尾可删除。
2. 页签里有提示「**提示：市场越多获取越慢**」；重复添加提示「**该市场已在列表中**」，超上限提示「**最多可添加 12 个市场**」。

### 备清单
1. 切到「**卖出物品**」或「**买入物品**」页签 →「**添加物品**」：弹出物品树，标题写明加到哪一组，勾选后点标题行的「**加入清单**」。
2. 或点「**粘贴导入**」：粘入游戏里复制的多行清单后点「**导入**」，提示「**导入 X 行，识别 Y 件物品**」；识别不了的行会单独列出。
3. 清单里「**数量**」可直接改（物品与体积只读）；行右键可「**从清单移除**」或移到另一组。

### 定口径
1. 「**价格**」页签：**卖单**口径与**买单**口径各三选一（前 5% 均价 / 最低价·最高价 / 按数量吃单的均价）。
2. 「**卖出方式**」（挂卖单 / 直接卖给买单）与「**买入方式**」（从卖单买入 / 挂买单）决定每侧用哪种价；默认「挂卖单 + 从卖单买入」。
3. 「**卖出税费 %**」默认 0：填销售税 + 经纪费合计，**只作用于卖出侧到手价**（矩阵里的市场价仍是原始价）。

### 开始计算与读结果
1. 点「**开始计算**」：本页遮罩显示逐市场进度（形如「市场 1/3：伏尔戈 — 12/40 物品」）；完成通知「**比价完成：X 件物品，用时 Y 秒（错误 n / 信息 n）**」。
2. 「**全部**」页签是完整价格矩阵：固定列（物品 / 数量 / 体积 / 最优市场 / 最优单价 / 较次优优势% / 小计）+ **每个市场一列**——卖出组显示该市场的到手价（已扣税）、买入组显示成本价；无价显示「—」。列宽自适应，超宽出横向滚动条。
3. 其余市场页签是「该市场为最优」的物品简表（物品 / 数量 / 体积 / 单价 / 小计 / 较次优优势%）——直接回答这批货该运到哪、该在哪收。
4. 每组结果底部一行「**分散 vs 单一市场（某市场）**」+ 金额 + 百分比：分散到各自最优比全挤进这一个最优市场多赚多少；该市场覆盖不全时附「市场名 · 覆盖数/总数」。
5. 只选 1 个市场时会提示「**只选了 1 个市场，比较不出地点差异。**」

### 改数量后重算
1. 市场 / 物品集合 / 口径都没变时（例如只改数量），再点「开始计算」走**内存重算**，无需重新取价。
2. 「按数量吃单」口径下改数量只重算金额、价格不变，并提示「**数量或价格口径已变化，请重新比价以刷新价格。**」——再点一次「开始计算」才会重新取价。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 最优市场 | 本组口径下价格最好的市场 | 卖出组取到手价最高、买入组取成本价最低；每组只显示自己一侧的最优 |
| 最优单价 | 最优市场的成交单价 | 按所选口径与成交方式计算；卖出侧已扣税费 |
| 较次优优势% | 最优与次优的差距 | 相对次优价格的百分比；没有次优报价时显示「—」 |
| 小计 | 最优单价 × 数量 | 与最优单价同口径 |
| 各市场列 | 该物品在这个市场的价 | 卖出组 = 到手价（扣税后）、买入组 = 成本价；取数失败或无单显示「—」 |
| 成交方式 | 每侧用哪侧订单算价 | 挂卖单 → 卖单侧价；直接卖给买单 → 买单侧价；从卖单买入 → 卖单侧价（吃单成本，**不是**该市场的买单报价）；挂买单 → 买单侧价 |
| 汇总 · 总收入 / 总支出 / 净额 | 卖出组合计、买入组合计与差额 | 按各自清单数量与最优价汇总 |
| 汇总 · 总体积 / 无报价 | 清单总体积与取不到价的物品数 | 体积按物品打包体积 |
| 分散 vs 单一市场 | 集中度结论 | 只在「能处理全部物品」的市场之间比较（覆盖优先）；比较对象只含各自有报价的物品 |

## AI 能替你做什么 {#ai}
- `compare_analyse`（**重型分析，执行前需要你确认**）：按比价页**已配置的市场清单**对给定物品做完整比价，返回每个物品的最优市场、与次优的差 %，以及集中度结论（覆盖几件、分散可差多少）。参数：`items`（必填）、`side`（sell / buy，默认 sell）、`top`（默认 10、上限 20）。**每件物品按 1 件计**，不按你清单里的数量。
- `trade_spread`（只读、无需确认）：轻量的现价利差快照，一次 1–5 件物品：各市场最低卖 / 最高买与可成交量，以及「在哪买 + 在哪卖」的最优组合（含税费净利与回报率）。市场限定在比价设置里（可用 `markets` 参数筛选，最多取前 8 个）；买入成本 = 最便宜的 N 件卖单加权均价，卖出收入 = 最高的 N 件买单加权均价 ×（1 − 税率）。
- 推荐问法：「按我比价页的市场比一下三钛合金在哪卖最划算」「三钛合金现在从哪买、倒到哪卖最赚」。
- **做不到**：不能替你改比价页的市场 / 清单 / 口径设置；两个工具都读不到页面右侧已有的结果；`compare_analyse` 是多市场取数、较慢，且结果以它自己取的数为准。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先添加至少一个市场 | 还没配市场 | 「市场」页签添加 |
| 该市场已在列表中 | 重复添加 | 换一个市场 |
| 最多可添加 12 个市场 | 超出上限 | 先删再加 |
| 清单为空，请先挑选或粘贴物品 | 要算的清单还没有物品 | 添加或粘贴物品 |
| 请先在物品树里勾选物品 | 弹层里没勾就点了加入 | 勾选后再点「加入清单」 |
| 粘贴内容为空或无法解析 | 粘贴文本解析不出物品 | 检查内容后重新导入 |
| N 个市场取数失败：… | 网络 / ESI 限流 / 建筑无授权 | 建筑市场先确认「设置 → 玩家建筑」与角色访问权；其余稍后重试 |
| 数量或价格口径已变化，请重新比价以刷新价格。 | 「按数量吃单」口径下改了数量 | 再点一次「开始计算」重新取价 |
| 只选了 1 个市场，比较不出地点差异。 | 市场太少 | 添加更多市场 |

## 限制与已知问题 {#limits}
- **只比订单现价**：没有历史口径，也不做倒货的推荐度 / 波动 / 饱和度等指标；结果是一次性快照，不做导出与自动刷新。
- **清单与设置改动后结果过期**：警告条提示「清单或设置已修改，点「开始计算」更新结果。」，重算后恢复；警告条可关闭。
- **建筑市场**：整建筑全量拉取、需要角色访问权，首次明显较慢（REFACTORING §8-9）。
- **同一星域下选多个星系市场会按物品重复取单**（未按星域去重），选多个星系会成倍变慢。
- **每个市场选择器各自加载星域 / 星系列表**：市场多时首次准备稍慢（异步，不阻塞界面）。
- **窗口很宽时结果表右侧留白**：列宽按内容自适应（无星号列），以保证内容超宽时能出横向滚动条。
- **取消只能来自遮罩上的「取消」按钮**：切走页面不会中断正在跑的比价，切回结果仍在。
