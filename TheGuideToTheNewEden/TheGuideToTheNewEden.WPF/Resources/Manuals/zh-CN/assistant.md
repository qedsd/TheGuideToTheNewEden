# AI 助手

## 一句话 {#tldr}
用自然语言提问，助手会调用软件内的工具去查真实数据（市场、角色、星图、倒货、任意 ESI 接口），并能直接跳转对应页面；会改配置的操作先弹卡片等你确认，回答按 Markdown 渲染。

## 在哪打开 {#where}
- 左侧导航栏**页脚**的「**AI 助手**」：常驻入口，排在「设置」上方，不随菜单滚动、导航折叠成图标时也在。
- 默认从页脚、主页快捷输入、主页磁贴打开都进**独立工具窗口**（可置顶、显示在任务栏、可 Alt+Tab 切换，重复打开只激活同一个窗口）；勾选「设置 → AI → 行为 → 在主窗口中显示 AI」后改为显示在主窗口里。
- 主页品牌条右侧的**快捷输入框**：物品价格 / KB / 星系这类简单查询回车直达对应页面，复杂问题自动转给助手——转给助手会**新开一个对话**，不续在上一轮里。
- 全局快捷键默认**不启用**；启用后在任意程序按组合键即可弹出助手窗口、再按一次收起。

## 前置条件 {#prereq}
- **先配置 AI 端点**：到「设置 → AI → 模型」填协议 / 服务地址 / API Key / 模型名（助手与 AI 翻译共用这一份端点，支持 OpenAI 兼容 / Azure OpenAI / Anthropic / Gemini）。未配置时打开助手是一整页引导：标题「先配置 AI 端点」，可点「去配置」（直达模型节）或「重新检测」。
- **查角色数据**（钱包 / 技能 / 订单 / 邮件等）需要已授权登录的角色；问「我的……」用哪个角色由「设置 → AI → 行为 → 默认角色」决定（填角色全名；留空 = 第一个角色，填错也回落第一个角色）。
- **ESI 按授权过滤**：网关只列出并允许调用当前角色已授权 scope 的端点；缺权限时不发请求，直接说明缺哪个 scope、去哪重新授权。
- 对话与记录保存在本地明文文件（配置目录的 `Configs/AiAssistantHistory.json`）。

## 操作步骤 {#steps}

### 管理对话（左栏）
1. 左栏「**对话**」列表每项显示标题、最近一句预览与更新时间；点左栏**右上角的 +** 开新对话，新对话插在列表最前。
2. 右键某条对话：**重命名对话 / 删除对话 / 清空当前对话**；**双击右上角的会话标题**也能改名（标题悬停提示「双击标题可重命名」；回车确认、Esc 取消）。
3. 还没有对话时，列表中央显示两行提示「还没有对话 / 点右上角 + 新建」。
4. 左栏顶部（对话区左上角）有个「**收起对话列表**」按钮：点一下把左栏收起来、对话区变宽，同一个按钮变成「**展开对话列表**」；**这次的选择会被记住**，下次打开还是这个状态。

### 提问（底部输入区）
1. 输入需求后**回车发送、Shift+回车换行**（占位提示「描述你的需求…」），或点「**发送**」。
2. 可以连发：**不等上一条结束**，每条各自一个请求、各自转圈；会话标题旁显示「正在处理 N 条…」，点「**停止**」会取消全部在跑的请求。
3. 「**带上上下文**」（输入框内、与「发送」同一行的勾选框）：**默认打开**。打开后本对话每次提问都带上此前的**完整记录**——包括当时的工具调用与工具返回的原始数据（所以追问「刚才那第二条的到期时间」助手能直接答，不必重新查一次）。**把鼠标停在勾选框上**可看到说明与当前用量（如「已带 12 轮 · 86k / 200k 字符」）。**记忆只存在于单个对话**：换一个对话就是重新开始，不同对话之间不共享，也没有跨对话的长期记忆。
4. 输入框里没有「清空」按钮：要清空输入直接全选删除即可；要清掉当前对话的全部记录，用左栏右键的「清空当前对话」。
5. 空对话时中间会给出一句话说明与**三枚示例**（巨神兵级在吉他的价格 / 吉他到多美怎么走 / 帮我分析倒货），点一下即当作提问发出。

### 读回答（右侧记录）
- 你的提问靠右，是一个浅色圆角块（鼠标悬停可看发出时间），超长折叠、可「展开 / 收起」。
- 回答**不套气泡**、直接落在页面底色上，自上而下：
  1. **工具调用**：每次一行暗色小字 = 成功 / 失败图标（悬停显示「完成 / 失败」）+ 工具中文名 + 参数摘要（悬停看结果摘要）+ 耗时（秒）；重型工具另有实时进度行。
  2. **确认卡片**：只有需要确认的操作才出现（见下一节）。
  3. **回答正文**：按 Markdown 渲染（表格 / 加粗 / 列表 / 代码块等），默认折叠约五行高，点「展开 / 收起」看全文；流式生成时边回答边刷新。
  4. **meta 行**：`时间 · 模型名 · 耗时 · 输入 X / 输出 Y token · 工具 N 次`。
  5. **复制回答**（右下角图标）：复制的是 Markdown 原文（便于粘贴到笔记 / 编辑器）。
- 正文位置也可能显示「正在处理…」「已停止」或红色错误文本。

### 确认写操作
1. 需要确认的操作**不会立即执行**：回答气泡里出现「**需要确认的操作**」卡片（「以下操作会修改软件配置，确认后才会执行：」），逐条列出将要发生什么。
2. 点「**应用**」才执行并继续回答；点「**拒绝**」不执行，按“用户未确认”继续。
3. 这类操作包括：ESI 写操作、跳桥新增 / 删除 / 导入、用户术语表写入、市场收藏、倒货购物车，以及倒货分析 / 比价分析这类重型管线。
4. 「设置 → AI → 行为 → 写操作需要确认」关闭后**不是免确认**：助手会直接拒绝写操作并说明原因。
5. ESI 写操作即使开了「允许 ESI 写操作」，每次仍要确认；「禁止调用的路径」黑名单命中的端点确认也绕不过。

### 独立窗口与快捷键
- 输入框内、与「发送」同一行的「**弹窗**」图标：在独立窗口打开 / 收起对话（开 / 关切换）；在独立窗口里这个图标会隐藏。页面与独立窗口**共用同一份对话**，两边实时一致。
- 全局快捷键：在「设置 → AI → 行为 → 全局快捷键」填组合键（如 Alt+Q / Ctrl+Alt+A，输入框占位提示为 Alt+Q）并保存后即时生效。
- 组合键非法或被其它程序占用时只记一条日志、应用照常启动；换一个组合键即可。

## AI 能替你做什么 {#ai}
- **常驻工具**（每次提问都随请求声明给模型）：
  - `esi_search` / `esi_describe` / `esi_read` / `esi_write`：ESI 通用网关四件套，覆盖 ESI 全部 197 个操作（检索端点 → 查参数说明 → 只读调用 → 写调用；写需确认，结果里的 ID 自动补成「名称 (id)」）；
  - `search_sde`（名称检索）、`translate`（翻译）、`character_list`（角色清单）。
- **按需声明的专用工具**（与提问意图相关的组，最多再带两组）：商业（市场订单 / 历史 / 走势 / 收藏 / 估价 / 倒货分析与设置 / 比价 / 利差 / 订单 / 购买文本 / 购物车）、角色（概览 / 钱包 / 技能 / 邮件 / 合同 / 工业 / 位置 / ZKB）、星图（路径 / 星系详情 / 跳桥 / 图层）、频道（名单统计 / 术语 / 链接）、通用（测速 / 任务资料）；看不出意图时声明全部。可在「设置 → AI → 工具开关」逐个停用。
- 推荐问法：「巨神兵级在吉他的价格」「吉他到多美怎么走」「帮我分析倒货」「我的资产汇总」（走 ESI）。
- **做不到**：不开放订阅型功能（频道预警 / 监控 / 查价、日志监控、击杀流）与多开控制；不开放“写本软件设置”；**记忆只存在于单个对话内**（不跨对话、不跨角色，也没有长期记忆）；不支持截图（视觉输入）。
- 回答里的数字一律来自工具结果（内置提示词要求“数字以工具为准、查不到就说查不到”），不要采信对话里的旧数字。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 助手未配置：请在「设置 → AI 助手 → 模型与翻译」里填写服务地址、API Key 与模型名（翻译与助手共用这一份端点设置） | AI 端点未配置 | 到「设置 → AI → 模型」填写并保存，或点引导页「去配置」；完成后「重新检测」 |
| 请输入内容 | 空内容就点了发送 | 输入后再发送 |
| 没有返回内容 | 模型没有返回文本 | 重发一次；必要时检查「设置 → AI → 模型」的模型名与参数 |
| 请求超时或中断 | 请求超时或网络中断 | 稍后重发；检查服务地址可用性 |
| 模型返回的工具调用标记不完整（很可能被「最大输出 token」截断）。请在 设置 → AI 助手 调大该值后重试。 | 模型把工具调用写成文本标记，且被输出上限截断 | 到「设置 → AI → 模型」调大「最大输出 token」（或设 0 交给服务端默认）后重试 |
| 模型这次把工具调用写成了 DSML 文本（服务端没有转成标准 function calling），已拦截不显示原文 | 上游模型的工具调用标记漏进正文（DeepSeek 系已知问题） | 按提示把这句话重发一次，通常就能正常调用 |
| 已按设置直接拒绝这次写操作（「设置 → AI 助手」里关闭了写操作确认） | 「写操作需要确认」被关闭 | 如需助手执行写操作，在「设置 → AI → 行为」重新打开该开关 |

## 限制与已知问题 {#limits}
- **ESI 网关边界**（§8.66）：只能调用内置索引里登记的操作、不接受任意网址；默认只取第 1 页，全量翻页受「一次最多取几页」限制（默认 10）——整星域订单那种量级请用市场 / 倒货页；剩余错误配额低于阈值（默认 10）时停止调用，防止被 ESI 临时封禁；军团级端点还需要角色有军团职位，否则 403。
- **上下文有预算**：带上的是完整历史（含工具结果），所以长对话的输入会明显变长；超过「设置 → AI → 行为 → 上下文预算（字符）」（默认 **200000**，0 = 不限制）时**先省略中间较早的轮次**——**最早一轮与最新一轮优先保留**（最新一轮即使超预算也会压缩它的工具结果后保留）；底栏显示「已带 N 轮 · X / Y 字符」，发生省略时追加「· 省略 M 轮」。接本地小窗口模型（如 32k 窗口）时请把这个值调小。
- **会话有上限**：最多 40 个对话、每对话 200 条，超出丢最久未更新的；**未确认的写操作不落盘**——关掉应用前没点「应用」的确认会丢失，需重新提问。
- **工具轮数有上限**：单次提问最多连续 8 轮工具（可调 1–30），到顶后不再继续调。
- **DSML 泄漏**（DeepSeek 系模型）：偶发把工具调用写成文本标记漏进正文；界面会拦截并提示重发，不会显示原始标记。
- **「恢复默认」的范围**：只重置助手参数（轮数 / 默认角色 / 确认 / 快捷键 / 上下文预算 / 提示词 / ESI / 工具开关 / 显示位置），**不动模型端点与 API Key**。
