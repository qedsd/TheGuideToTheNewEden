# 商业 · 订单

## 一句话 {#tldr}
列出某个角色**未结的个人或军团市场订单**，逐单标出「**订单状态**」（正常 / 被压单 / 未知）与「**与市场价差**」，并把被压单的行一键变成游戏里可粘贴的**批量购买文本**。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**订单**」。
- 页面只有一屏，自上而下三块：**工具栏**（角色 / 订单类型 / 来源 / 刷新 / 状态文字）→ **错误或提示行**（无内容时不占位）→ **订单表**（10 列，带右键菜单）。
- 首次进入会**自动选中第一个已授权角色**并开始取数，不需要先手选角色。

## 前置条件 {#prereq}
- **必须先有已授权角色**：角色在「设置 → 角色」里完成授权后，才会出现在工具栏的角色下拉里；没有任何角色时取数会直接给出「未选择角色」。
- **查个人订单**只要求该角色本身的授权。
- **查军团订单**（来源 = 军团）要求该角色在游戏里有**军团订单权限**；没有权限时 ESI 会拒绝，页面给出明确提示而不是空表。
- **「与市场价差」与状态列需要市场参考价**：页面会按物品去读星域订单做对比，订单多时这一步明显更慢（状态文字会显示「计算与市场价差…」）。参考价取不到时状态列显示「未知」。
- **「在游戏中查看」需要额外的 ESI 权限**：授权里要勾选 `esi-ui.open_window.v1`，否则该动作失败并给出提示。

## 操作步骤 {#steps}

### 取一次订单
1. 进入页面后确认工具栏「**角色**」下拉里是你想查的角色（未手选时已自动选第一个）。
2. 选「**来源**」：**个人**（该角色自己的未结订单）或**军团**（该角色所属军团的未结订单）。
3. 选「**订单类型**」：**卖单**或**买单**。
4. 若自动取数不是你要的时机，点「**刷新**」重新取一次。
5. 观察状态文字：取订单时是「获取订单中...」，接着在算价差时是「计算与市场价差…」，两项都结束后清空。此时表格即为结果。

### 三个过滤器怎么配合
- **角色**：换角色会立即重新取数（并清空旧表）。
- **来源**：换来源会立即重新取数（个人与军团是两套不同的接口与权限）。
- **订单类型**：只做**本地筛选**——卖单与买单是同一批订单的两个方向，切换时不再请求网络，因此来回切换很快。
- **刷新**：按当前角色 + 当前来源重新取一次，并重算价差。

### 看懂状态与价差
1. 「**订单状态**」列有三种取值，且按状态着色：**正常**（正向色）、**被压单**（警示色）、**未知**（次要色，无参考价时）。
2. 「**与市场价差**」列是该订单价格与参考价的**差值大小**（两位小数），方向由状态列表达：
   - **买单**：价格**不低于**参考的最高买价 = 正常，**低于** = 被压单；
   - **卖单**：价格**不高于**参考的最低卖价 = 正常，**高于** = 被压单。
3. 只想看需要处理的行时，直接按「订单状态」列排序（表头可点）或用滚动条逐行扫，被压单的行是警示色，很容易认。

### 复制为游戏批量购买订单
1. 在表里**选中若干行**（表格按整行多选，按住 Ctrl / Shift 可多选）。
2. 在表上点**右键** → 「**复制为游戏批量购买订单**」。
3. 只有**被压单 / 未知**的行会被复制，每行形如 `物品名 1`；成功时提示「复制成功！在游戏批量购买界面粘贴即可」，然后到游戏里的批量购买界面粘贴即可。
4. 选中的行里一条符合的都没有时，提示「无物品可复制（仅复制"被压单/未知"的行）」，剪贴板不被改动。

### 在游戏中查看
1. 选中某一行，点右键 → 「**在游戏中查看**」。
2. 成功时提示「操作成功（已请求游戏客户端打开市场详情）」，游戏客户端会打开该物品的市场详情。
3. 失败时提示「操作失败：请确认已勾选 esi-ui.open_window.v1 权限」，去授权里补上该权限再试。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 物品 | 订单对应的物品名 | 本地数据库解析名称 |
| 数量 | 订单**剩余**未成交数量 | 千分位显示；不是下单时的总量 |
| 价格 | 该订单的单价 | 千分位 + 两位小数 |
| 订单状态 | 正常 / 被压单 / 未知 | 由该单价格与市场参考价比较得出；取不到参考价时为未知；三态各有独立颜色 |
| 与市场价差 | 该单价格与参考价的差值 | 显示差值大小（两位小数），方向看状态列 |
| 位置 | 挂单地点（空间站 / 建筑名） | 本地解析；解析不到时显示原始地点 ID |
| 星系 | 该地点所在星系 | 由本地数据库补齐 |
| 范围 | 订单可覆盖范围 | 原样显示 |
| 过期时间 | 订单剩余有效时间 | 形如 `dd.hh:mm:ss`（天数.时:分:秒） |
| LocationId | 挂单地点的原始 ID | 最右一列，便于和别处的地点数对照 |
| 角色 | 要查哪个角色的订单 | 工具栏下拉，选项来自已授权角色 |
| 订单类型 | 卖单 / 买单 | 本地筛选，不重新请求 |
| 来源 | 个人 / 军团 | 换来源会重新请求 |
| 参考价 | 做价差比较用的星域订单价 | 买单比最高买价、卖单比最低卖价 |

## AI 能替你做什么 {#ai}
- 工具：`character_orders`（未结订单 + 状态 + 价差，可只列被压单行）、`build_buy_order_text`（按订单页同一口径生成「物品名 1」批量购买文本）、`market_orders`（查某物品在某星域的市场价，用来判断该不该调价）。
- 三个工具都是**只读**，不需要你确认；AI 也不会替你在游戏里下单、改单或撤单。
- 推荐问法：「我有哪些未结订单」「哪些订单被压单了」「帮我把被压单的生成补货购买清单」「巨神兵级在伏尔戈现在什么价，我这单该不该改」。
- AI 回答里的价格、价差与状态一律来自上面的工具，**不要采信对话里的旧价格**。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 未选择角色 | 角色下拉为空，或原本选中的角色已被移除 | 去「设置 → 角色」完成授权后回到本页，或在下拉里选一个角色 |
| 该角色没有未结订单 | 接口调用成功，但该角色当前没有未结订单 | 正常情况下无需处理；确认订单类型 / 来源过滤器是否把结果挡掉了 |
| 军团订单获取失败：角色可能没有军团订单权限 | 该角色没有军团订单权限，或无军团归属 | 换有军团订单权限的角色，或把来源切回「个人」 |
| 获取订单中... 停留较久 | 订单量大，或军团订单需要逐页取 | 等待；必要时点「刷新」重试 |
| 计算与市场价差… 停留较久 | 每个物品都要取星域参考价 | 等待完成；订单多时这一步比取订单本身更慢 |
| 无物品可复制（仅复制"被压单/未知"的行） | 选中的行里没有被压单或未知状态的行 | 只选被压单 / 未知的行，或先照状态列排序再选 |
| 操作失败：请确认已勾选 esi-ui.open_window.v1 权限 | 授权里缺少在游戏内打开窗口的权限 | 到角色授权里补勾 `esi-ui.open_window.v1` |
| 复制成功！在游戏批量购买界面粘贴即可 | 已写入剪贴板（提示，非失败） | 切到游戏批量购买界面粘贴 |

## 限制与已知问题 {#limits}
- **不是实时盯盘**：表格只在进入页面、换角色 / 换来源、点「刷新」时更新；游戏里改了价，页面上仍是上一次取到的数据。
- **订单类型过滤器只筛当前已取到的数据**，不会因为切换卖单 / 买单去重新取数；要看最新状态请点「刷新」。
- **建筑（结构）订单的状态恒为「未知」**：参考价只对空间站订单计算，结构订单拿不到对应星域的参考价，价差与状态列因此没有可比数值。
- **「与市场价差」只体现差值大小，不体现方向**，方向要看「订单状态」列。
- **「数量」列显示的是剩余未成交量**，不是下单总量，因此和游戏里刚挂上去时看到的数字可能不同。
- **批量购买文本每行固定为 `物品名 1`**：不带数量、不带价格，纯粹是一份要补的清单；同名的多行会各占一行。
- **军团订单依赖权限**，没有军团订单权限时无法查看，页面只给提示不给部分数据。
- **表头「数量」与工具栏的「订单类型 / 来源」同名但含义不同**：前者是订单剩余量，后者是过滤器。
- 表格不支持按列过滤与分组小计，只支持点表头排序；列宽超出可视区时用横向滚动条查看。
- **「在游戏中查看」是请求游戏客户端打开市场详情**，客户端没运行或没有对应权限时只会失败并提示。
