# 星图 · 星系详情与图层

## 一句话 {#tldr}
星图配套的四个查询 / 设置窗：星系详情（主权、资源、击杀统计、天体、邻接）、一跳覆盖（旗舰一跳能圈到哪些星系）、行星资源清单、主权分组（给联盟自定义分组与配色）。

## 在哪打开 {#where}
- **星系详情**：图上点选星系 → 右下信息卡「**详情**」。内容是打开那一刻选中的星系；换星系要点新星系再点一次「详情」（窗口按新星系重建）。
- **一跳覆盖 / 行星资源清单 / 主权分组**：顶栏「**工具**」下拉的三个入口，均为独立工具窗口，已开着时再次点击只会前置。
- 一跳覆盖窗的**中心星系**取打开（或重新点入口）时选中的星系。

## 前置条件 {#prereq}
- 星系详情：统计页签的击杀 / 通行来自 ESI（需联网）；行星资源 / 天体 / 设施升级 / 邻接来自本地数据库，无需登录。
- 行星资源类数据**只覆盖安等 ≤ 0 的星系**（00 与负安等），高安星系这些页签为空或 0。
- 一跳覆盖需要先在图上选中一个中心星系，结果只列 **00 星系**。
- 主权分组需要能访问 ESI 主权接口；装载失败时状态栏提示「主权数据装载失败，请检查网络后重试。」，可「**重新拉取**」重试。

## 操作步骤 {#steps}

### 查星系详情
1. 窗口顶部是星系名与安等，下面一行汇总：**ID、星域、主权、产能、人力、岩浆气、超离子冰**（资源数据尚未装载时会按该星系自动补一次）。
2. 五个页签：
   - **统计**：舰船击杀 / 逃生舱击杀 / NPC 击杀 / 通行量（与信息卡同源的 ESI 数值）。
   - **设施升级**：各项设施升级要求的四项资源（名称 + 产能 / 人力 / 岩浆气 / 超离子冰）。
   - **行星资源**：该星系**含资源的行星**列表（行星名 / 行星 ID / 四项资源）。
   - **天体**：全部天体（名称 / 类型 / 天体 ID）。
   - **邻接**：星门邻居（星系 / 星域 / 安等 / 主权），按星系名排序。
3. 装载期间有「正在装载星图数据…」遮罩，稍候即出。

### 算旗舰一跳覆盖
1. 「工具 → **一跳覆盖**」：窗口顶部「**中心星系**」搜索框可直接输入星系名或 ID 设为中心；也可在星图选中星系后点「**从星图取中心**」。未设置时输入框为空，不会预填提示文字。
2. 选**旗舰**型号，选择 **跳跃引擎校准 / 跳跃燃料节约** 等级（默认 4）；选到战略货舰时多出「**战略货舰操作**」一栏。顶部实时给出**最大跳距**与**每光年燃料**。
3. 点「**计算覆盖**」：结果表按**距离由近到远**列出可达星系（序号 / 星系 / 星域 / 安等 / 距离(ly) / 燃料 / 主权），同时星图上画出**虚线覆盖圈**。
4. 点「**清除覆盖**」清空结果并抹掉圈。
5. 口径：最大跳距 = 船型基础光年 ×（1 + 20% × 跳跃引擎校准）；每光年燃料按跳跃燃料节约每级减 10%（战略货舰先按「战略货舰操作」技能每级减 10%）；燃料 = 每光年燃料 × 距离。

### 看行星资源清单
1. 「工具 → **行星资源清单**」：打开即开始装载（要遍历全部 00 星系做本地库查询，首次稍慢）。
2. 三个页签：**星域汇总**（星域 + 四项合计）、**星系汇总**（星系 / 星域 / 安等 + 四项）、**设施升级**（名称 + 四项要求）。
3. 顶部**右侧**搜索框可按**星系名 / 星域名 / 星系 ID**实时过滤当前表格。表格只列出有资源的星系，不再提供开关。
4. **双击星系行或星域行**：切回星图并定位到该星系 / 星域；底部小字有提示。
5. 顶部不显示数量统计；需要重新计算时关闭窗口后重新打开。

### 给主权联盟分组配色
1. 「工具 → **主权分组**」：左列**全部联盟**（搜索框过滤；每行色块 + 联盟名 + 星系数）、中列**分组**、右列**分组详细**（选中分组的成员）。
2. 「**新建分组**」后在中列直接改分组名、点「✕」删除；左列点「**加入**」把联盟划入选中分组，右列点「**移出**」退出。
3. 点任意**色块**打开颜色选择器（ARGB 滑杆与数值 + HEX 输入，点「**确定**」生效）：可改分组色，也可给未分组的单个联盟覆盖自动配色。
4. 「**保存**」写回配置并立即刷新星图的主权着色与主权聚合；「**重新拉取**」绕过缓存重取主权数据。
5. 首次使用会预置几个主权联盟的默认分组，可自由改名、改色、增删；未分组的联盟独立展示（自动配色）。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 产能 / 人力 / 岩浆气 / 超离子冰 | 四项行星资源值 | 本地数据库，只统计安等 ≤ 0 的星系；设施升级要求读内置资源表 |
| 舰船 / 逃生舱 / NPC 击杀、通行量 | 星系统计 | 与星图信息卡、热度图层同源（ESI） |
| 距离(ly) | 该星系到中心星系的直线距离 | 三维坐标换算，结果按距离升序 |
| 燃料 | 该星系一跳的预计燃料 | 每光年燃料 × 距离（公式见上节） |
| 最大跳距 | 一跳能到的光年上限 | 船型基础光年 ×（1 + 20% × 跳跃引擎校准） |
| 主权 | 星系归属联盟 | 取主权数据缓存；分组后按分组名与颜色展示 |
| 星系数 | 联盟在图上的星系规模 | 主权分组窗左列每行显示 |

## AI 能替你做什么 {#ai}
- 工具：`map_system_info`（按星系名回报安等、星域、有无跳桥、主权联盟与资源行星数）、`map_route`（计算星门 / 旗舰路线并画到图上）。
- 推荐问法：「吉他详情」「XX 有没有跳桥」「YY 是谁的领土」「从 A 到 B 画条路线」。
- **可以改星图配置**：`config_read` / `config_write`（name=`map`）可读写 `MapSettings.json` 里的主权分组与配色（含 `Sov` 分组）；写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`map`）在下次进入星图时生效。
- **做不到**：不能替你点本窗的「保存」按钮；读不到详情窗里的天体、邻接明细；也不会替你算一跳覆盖——请在本窗点「计算覆盖」。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先在星图上选中一个星系 | 一跳覆盖没有中心星系就点「计算覆盖」 | 回星图点选一个星系，再点「工具 → 一跳覆盖」 |
| 主权数据装载失败，请检查网络后重试。 | ESI 主权接口拉取失败 | 稍后点「重新拉取」重试；期间只影响主权相关显示，其余功能正常 |
| 行星资源清单装载很慢 | 首次要遍历全部 00 星系（本地库查询） | 属正常，等装载完成；之后重开直接用已装载数据 |
| 详情窗四项资源全为 0 | 该星系无资源数据，或资源清单还没装载过 | 打开一次「行星资源清单」，或重开详情窗（会自动补一次单星系资源） |

## 限制与已知问题 {#limits}
- **行星资源只到 00**：安等 > 0 的星系不参与统计与清单；一跳覆盖同样只列 00 星系。
- **详情窗不跟随选中**：内容定格在打开时选中的星系，换星系需重新点「详情」重建窗口。
- **主权数据有内存缓存**：失败只影响主权相关显示（着色 / 聚合 / 分组窗数据），可用通知里的「重试」或窗内「重新拉取」。
- **设施升级只列要求**：表中是各项升级的四项资源要求，不做"够不够用"的判定显示。
- **主权分组语义**：分组色只在「主权」着色模式下体现；热力主权聚合按分组（而非单联盟）合并晕染。
