# 星图 · 情报面板

## 一句话 {#tldr}
把频道情报与 ZKB 击杀汇成一张实时表格，同时在星图上给相关星系画红圈与攻方舰船图标——巡图时一眼看出哪里正在打、谁在打，点击即可定位。

## 在哪打开 {#where}
- 星图页顶栏「**工具**」→「**情报**」。它是**独立工具窗口**，标题栏只有最小化与关闭，与主窗口互不牵连（主窗口最小化不会把它一起收起）。
- 从工具菜单打开时若还没在监听，会**自动开始监听**；窗口已开着时再次点击只会把它前置。
- 窗口分「**实时数据** / **过滤** / **设置**」三个页签；底部状态栏有「**开始监听 / 停止监听**」「**清空情报**」与「监听角色：…」「共 N 条情报」。
- 点标题栏 X 是**真关闭**：销毁窗口、保存设置并停止监听；切到星图以外的页面时，窗口与监听都保留。

## 前置条件 {#prereq}
- **频道情报**要求先在「频道预警」页启动至少一个角色的预警；没有会话时窗内提示「需先在"频道预警"页启动预警」。
- **ZKB 击杀不依赖会话**：没有频道会话也能用，此时只收 ZKB（把设置里的「**ZKB 击杀**」开关打开即可）。
- 频道情报读的是**本地游戏日志**，无需联网；**ZKB 击杀需要联网**（第三方服务）。

## 操作步骤 {#steps}

### 看实时情报
1. 「**实时数据**」页签是滚动表格：**时间**（下方小字为相对时间，自动刷新）｜**星系**｜**星域**｜**受害方**（舰船 + 角色头像 + 势力徽标）｜**攻方**｜**来源**（ZKB 或频道名）｜**内容**。
2. 单击一行定位到该星系；**右键**一行同样定位。点星系名定位星系，点星域名适配到该星域。
3. 名字与图标可点击：舰船图标打开 KB 击杀详情，角色头像打开该角色的 KB 实体页，势力徽标打开势力页；悬停显示名称（星系 / 星域显示 ID；一时解析不到的名字先显示 ID，补到名字后自动换）。
4. 攻方格悬停显示规模摘要（共 N 名攻方 · N 种舰船 · N 个势力）。

### 过滤掉不关心的情报
1. 「**过滤**」页签左右两栏：「**排除项**」与「**包含项**」，都用实体搜索框添加（**角色 / 军团 / 联盟 / 星系 / 星域 / 物品类型**六类）。
2. 命中任一排除实体的情报直接丢弃；包含项非空时只保留命中任一包含实体的情报，**某类实体为空就不限制该类**。
3. 列表项悬停显示 ID，多选后点「**删除**」移除；改动**运行中即时生效**并落盘。
4. 过滤范围：ZKB 按星系与攻方（角色 / 军团 / 联盟 / 舰船类型）判定，**受害方不参与**；频道消息只按星系判定。

### 调整保留与清怪行为
1. 「**设置**」页签：「**ZKB 击杀**」开关、「**保留(分)**」（ZKB）、「**频道情报保留(分)**」、「**最大攻方数（超出按舰船/势力聚合）**」、「**情报列表上限**」、「**收到"清怪"时连 ZKB 一起清**」。
2. 「**频道**」区块列出频道预警里已启动会话的监听者：勾选哪些频道进星图情报，未配置时默认全收；点「**刷新频道**」重新读取。
3. 所有设置**运行中可改、即时生效**。
4. 情报随时间过期：频道情报与 ZKB 击杀分别按各自保留分钟从表格和主图上消失；频道出现"清怪"类消息时清空该星系的频道情报（是否连 ZKB 一起清由开关决定）。

### 看主图上的红圈与图标
1. 有情报的星系画**红圈**，圈的大小反映该星系情报的多少（综合攻方舰船数与频道消息条数）。
2. 频道情报的圈下方有一行标注：条数 + 最早一条是多久前的（图上用广播、时钟两个符号前缀）。
3. 放大后逐个画出攻方舰船图标（带 ×数量角标）：**每星系最多 8 个**，超出折成 `+N`；更大倍率下再显示"多少分钟前"；缩小时只显示 `+舰船数(情报数)`。
4. 图标放不下或会压到别的星系节点时会折叠或让位；不同星系的图标之间不做避让，密集星域仍可能视觉重叠。

### 停止与清空
- 底部「**开始监听 / 停止监听**」切换监听：停止会清空列表与图上红圈；「**清空情报**」只清当前表格内容。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 时间 | 情报 / 击杀的入库时间 | 相对时间随过期计时刷新 |
| 星系 / 星域 | 事件所在星系与所属星域 | 悬停显示对应 ID；点击定位 |
| 受害方 | 被击杀方的舰船、角色与势力图标 | 无数据时整格隐藏 |
| 攻方 | 攻方舰船 + 角色头像 + 势力徽标 | 人数 ≤「最大攻方数」逐个显示（表格最多 2 条）；超出按舰船 / 势力聚合成 ×N |
| 来源 | ZKB 或频道名 | 频道名 = 频道预警里的监听者 |
| 内容 | 频道原文或击杀摘要 | ZKB 行保留一行可读摘要（受害方与最后一击） |
| 排除项 / 包含项 | 按实体过滤情报 | 六类实体；ZKB 判星系与攻方，频道只判星系 |
| 保留(分) | 情报在表与图上的存活时长 | 频道情报与 ZKB 各自一份，单位分钟（1–180） |

## AI 能替你做什么 {#ai}
- 工具：`zkb_entity`（查角色 / 军团 / 联盟在 ZKB 的危险值、抱团比例、击杀 / 损失与 ISK 效率）、`map_layer`（把星图切到击杀 / 通行热度等着色，或开关跳桥层）。
- 推荐问法：「情报里出现的 XXX 危险吗」「把星图切成击杀热度看看哪里最热」。
- **可以读 / 改情报面板设置**：`config_read` / `config_write`（name=`map`）读写 `MapSettings.json` 里的情报开关、保留时长、排除 / 包含项等；写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`map`）在下次进入星图时生效。
- **做不到**：AI 读不到实时情报内容（表格与红圈不经 AI），不能替你开关监听，也不会在收到情报时提醒你——要声音 / 弹窗报警请用频道预警。
- 想评估某个实体：把表里看到的名字交给 `zkb_entity` 查危险度，再自行决定要不要接近。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 需先在"频道预警"页启动预警 | 频道预警页没有已启动的预警会话 | 去频道预警页启动至少一个角色；只用 ZKB 也可以（保持「ZKB 击杀」开启） |
| 开始监听后一直没有频道情报 | 未勾选频道，或全被过滤 | 「设置」页签点「刷新频道」并勾选；检查排除 / 包含项是否过严 |
| ZKB 击杀不出圈 | 「ZKB 击杀」开关未开，或 ZKB 服务不可用 | 检查设置里的开关；ZKB 为第三方服务，偶发限流或中断属正常 |

## 限制与已知问题 {#limits}
- **只展示、不报警**：本面板是星图侧的展示；声音 / 气泡报警属于「频道预警」。
- **筛选不影响情报**：星域 / 安等筛选只灰化显示，被灰化的星系照样收情报、照样画圈。
- **图标重叠**：每星系图标上限固定（超出折成 `+N`），压到其它星系节点时会让位，但不同星系的图标之间不互相避让。
- **时长按分钟**：保留时长单位是分钟（由设置数字框限定范围）。
- **频道情报有前置**：频道情报依赖频道预警会话；ZKB 不依赖，没有会话也能开面板。
- **运行中可改设置**：保留分钟、过滤、频道勾选在监听中修改都即时生效并落盘。
