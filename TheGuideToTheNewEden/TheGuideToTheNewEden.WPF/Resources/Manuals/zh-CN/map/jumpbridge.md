# 星图 · 跳桥

## 一句话 {#tldr}
把自己联盟架设的玩家跳桥（Ansiblex，俗称 ANS 桥）登记进星图：图上画成点线，星门寻路把桥当 1 跳走，规划航线时自动抄近道。

## 在哪打开 {#where}
- 星图页顶栏「**工具**」→「**跳桥设置**」（独立工具窗口；已开着时再次点击只会前置）。
- 窗口从上到下：「**在星图上显示跳桥**」开关、说明文字、添加行（「**星系 1**」「**星系 2**」输入框 +「**添加**」按钮）、跳桥列表（星系 1 ｜ 星系 2 ｜ 删除）。状态栏显示「共 N 组跳桥」。
- 星图页顶栏「**更多**」→「**跳桥**」复选框与这里的显示开关是**同一个开关**（写同一份配置）。
- 配置存在 `Configs/JumpBridgeSetting.json`。

## 前置条件 {#prereq}
- 无需登录、无需联网：跳桥是纯本地配置，打开即用。
- 显示与寻路都不需要授权角色。

## 操作步骤 {#steps}

### 添加与删除
1. 在「**星系 1**」「**星系 2**」里分别输入桥两端的星系：**星系名或数字 ID** 都可以（名称精确匹配优先，其次取模糊搜索的第一条）。
2. 点「**添加**」：成功后列表新增一行，状态栏计数更新，图上（显示开关开着时）立即出现这条点线。窗内提示原文：「输入星系名或 ID 添加一组跳桥；跳桥在星门寻路里按 1 跳计算（在图上画为点线）。」
3. 失败时状态栏说明原因：**星系未找到** ／ **两端不能是同一个星系** ／ **该星系已有一组跳桥**（每个星系只能连一条跳桥，任一端被占用都会被拒）。
4. 不要的桥点该行右侧「**删除**」；删除不区分两端顺序。

### 显示与寻路
1. 「**在星图上显示跳桥**」（或顶栏「更多 → 跳桥」）只控制**画不画**：关掉显示，寻路仍会走桥。
2. 「工具 → **导航**」按星门寻路时，跳桥按 **1 跳** 计入；结果里该跳的「本跳类型」显示**跳桥**，概览行单独统计「跳桥 N」。
3. 旗舰跳路线按光年直线计算，**不经过跳桥**。

### 批量导入（让 AI 代劳）
1. 想一次登记整套桥网，把清单发给 AI 助手即可（工具 `map_jumpbridge_import`）：支持**每行一组**「A ↔ B」（兼容 `-`、`→`、`←`、`,` 分隔）、**JSON 数组**（`System1` / `System2` 字段，值可为星系名或 ID）与**两列 CSV**；也可以给一个本机文件路径代替文本。
2. 导入只添加「两端都空闲」的组；**冲突**（任一端已被占用）与**未识别**的组会跳过，并在结果里分类列出（最多展示前几条，超出按条数汇报）。
3. 逐条增删也可以全交给 AI（见下节）。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 星系 1 / 星系 2 | 桥两端的星系 | 无向连线；列表里显示解析后的星系名 |
| 状态栏 | 当前配置条数 | 「共 N 组跳桥」 |
| 在星图上显示跳桥 | 是否绘制点线 | 只影响绘制，不影响寻路；与顶栏「更多 → 跳桥」同一配置 |
| 寻路口径 | 星门寻路里桥 = 1 跳 | 导航结果「本跳类型」为「跳桥」，概览行单独计数 |

## AI 能替你做什么 {#ai}
- 工具：`map_jumpbridge_list`（列出当前配置，每行「A ↔ B」）、`map_jumpbridge_add` / `map_jumpbridge_remove`（按星系名增删一组）、`map_jumpbridge_import`（从文本或文件批量导入）。
- **确认机制**：`list` 是只读，直接执行；**`add` / `remove` / `import` 都是写操作，会写盘并影响寻路，AI 会先说明要做的事、你确认后才会执行**。添加成功立即生效并自动重绘星图。
- 推荐问法：「现在配了哪些跳桥」「把 X 和 Y 之间的跳桥加上」「删掉 X 到 Y 的桥」「把这份桥网清单导入：……」。
- 另外可以用 `map_layer` 直接开关跳桥的图上显示（见 [星图](map)）。
- **做不到**：读不到游戏内实际架设的桥网，只能按你给的清单登记；导入时识别不了的行只会跳过并汇报，不会猜。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 星系未找到 | 输入既不是有效 ID，也匹配不到星系 | 用确切的星系名或数字 ID 重填 |
| 两端不能是同一个星系 | 两个框填了同一星系 | 换成桥另一端的星系 |
| 该星系已有一组跳桥 | 该星系已连着一条桥（每星系限一条） | 先删旧桥再加新的 |
| 添加成功但图上看不到 | 显示开关关着，或点线太细没注意到 | 勾选「在星图上显示跳桥」，放大视图确认点线 |
| 导入结果出现「冲突跳过」 | 该组任一端已被其它跳桥占用 | 按结果里列出的星系先删旧桥再重导 |

## 限制与已知问题 {#limits}
- **每个星系只能连一条跳桥**：任一端被占用即拒绝；导入时这类组自动跳过并汇报，不会覆盖旧配置。
- **跳桥只参与星门寻路**：旗舰跳路线按光年计算，不走桥。
- **显示与寻路独立**：关闭「在星图上显示跳桥」只是不画，寻路仍走桥。
- **名称解析**：添加框接受星系名或 ID；模糊名称取第一条命中，重名 / 近名星系建议直接用 ID。
- **重复导入安全**：已存在的组会按「端已占用」跳过，不会重复添加。
