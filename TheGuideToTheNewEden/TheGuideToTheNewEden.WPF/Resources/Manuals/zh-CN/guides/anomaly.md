# 攻略 · 异常

## 一句话 {#tldr}
第一个页签是**全宽对照表**：每条战斗异常（以及虫洞站点）的档位、势力、能升级成哪个站点都在同一行里，
筛完整表铺开；点一下就在**本页新开页签**看正文，不再跳走。

## 在哪打开 {#where}
- 左侧导航「**攻略**」→「**战斗异常**」。
- 第一个页签「所有异常」就是一张表，**没有左右分栏**：筛选在卡片右上角，下面是表格。
- 点站点名或「远征」列 → 在右侧新开页签显示正文（页签头有 `✕` 可关）。

## 前置条件 {#prereq}
- 无需登录角色、无需联网，数据随程序内置。
- 收录 126 条战斗异常 + 76 个虫洞站点（共 **202** 行），离线快照、不会自动跟随 wiki 更新。
- 虫洞站点的「势力」列显示**冬眠者**，「出现空间」列显示**虫洞**。

## 操作步骤 {#steps}

### 筛选（右上角）
1. **搜索框**：输入中文名或英文名（如「藏身处」「Haven」），输入即筛（300ms 防抖）。
2. **势力**下拉：不限 / 无人机 / 天蛇 / 血袭者 / 萨沙 / 天使 / 古斯塔斯。
3. **档位**下拉：不限 / `T1` … `T10`。
4. 三个条件叠加生效；筛选结果**整张表**一起刷新，没有分页。

### 看表格
| 列 | 含义 |
|---|---|
| 中文名 | 官方中文名，**不带难度后缀**（「隐秘的天使藏身处」，不是「隐秘的天使藏身处（难度1）」）；难度看下一列 |
| 英文名 | 站点英文名 |
| 难度 | `T8·3` = 8 档第 3 级 |
| 势力 | 该异常属于哪个海盗势力 |
| 远征 | 这个异常能升级成哪个站点：**蓝字**=有明确目标，可点；灰字=wiki 只标了档位（`8/10`、`?`），没有具体站点 |
| 出现空间 | 高安 / 低安 / 00（可多选） |

### 看详细攻略（本页页签）
- 点**中文名**（蓝字）：打开**这个异常自己**的详细页。
- 点**「远征」列里的蓝字**：打开它升级成的那个站点。
- **双击整行** = 点中文名（打开异常自己）。
- 三种跳转都会切到「死亡远征」页并选中目标，回来时本页的筛选条件还在（页面常驻缓存）。

## 界面说明 {#ui}
- 卡片标题「异常 → 远征对照表」，右侧是三个筛选控件（搜索 + 势力 + 档位）。
- 底部状态行只有一个条数：「共 N 个异常」，搜索时变成「搜索到 N 项」。
- 表格滚动交给表格自己（不套外层滚动条），行数多的时候按行滚动。

## 常见问题 {#faq}
### 为什么有些行的「远征」是灰字、点不动？
wiki 的异常矩阵里，一部分格子只写「4/10」「8/10」这种**档位**，或者干脆写「?」，
没有指向任何站点页。这些没法可靠对应到某个站点，所以只显示文字、不做链接。

### 为什么同一个异常只有一行，但有些势力有好几个异常？
表按「档位 → 级 → 势力」排序，同一档的同势力异常会挨在一起，方便横向对比。

### 清单里没有我遇到的异常？
本页只收 wiki 矩阵里有的 126 条；三神裔、化学实验室、遗迹等不算"异常"，去「死亡远征」按分类看。

## 相关功能 {#related}
- **死亡远征**：全部 391 条战斗站点的详细攻略（本页跳转的目标）。
- **任务攻略**：按任务名查流程。

## 已知限制 {#limits}
- 升级目标由构建期按 wiki 页名写死（`CombatSite.EscalationId`），wiki 没给链接的格子无法补。
- 只覆盖常规战斗异常，不含活动副本。
