# 攻略 · 死亡远征

## 一句话 {#tldr}
离线查阅**全部战斗站点**（DED 评级复合体、无评级复合体、远征、旗舰远征、战斗异常、化学实验室、战斗遗迹、三神裔、特殊站点）：
按分类 / 势力 / 难度或站名找到目标，右侧直接看中文打法与每层怪表，不用另开网页翻 wiki。

## 在哪打开 {#where}
- 左侧导航「**攻略**」→「**死亡远征**」。
- 页面分左右两栏：左栏是搜索框 + 站点列表 + 底部三个筛选下拉（分类 / 势力 / 难度）与状态行；右栏是选中站点的中英标题、元信息行与正文。

## 前置条件 {#prereq}
- 无需登录角色、无需联网：资料随程序内置在本地数据库里，打开即可查。
- 「Wiki 数据」是离线快照（EVE University Wiki 抓取并翻译成中文），不会自动跟随 wiki 更新。

## 操作步骤 {#steps}

### 选一个站点
1. 进页后默认「全部分类 / 全部势力」，列表加载完会自动选中第一项，右侧直接出正文。
2. 列表每项显示：英文名、中文名、**分类**、势力、**难度徽标**（`6/10`、`T8·3`、`远征`、`9/10` 等）。
3. 点中任意一项，右侧显示标题、元信息与正文。

### 按分类筛选
1. 底部第一个下拉：全部分类 / DED 评级复合体 / 无评级复合体 / 远征 / **旗舰远征** / 战斗异常 / 化学实验室 / 战斗遗迹 / 三神裔站点 / 特殊站点。
2. **难度下拉会跟着分类变**：
   - 选「DED 评级复合体」→ `1/10` … `10/10`
   - 选「无评级复合体」→ `未定级` / `9/10`
   - 选「战斗异常」→ `T1` … `T10`
   - 其它分类没有难度概念，这条下拉会自动隐藏。

### 关于「旗舰远征」
- 单独一档，共 12 条：5 个势力的**旗舰集结地**（`Capital Staging`）+ **护盾加强母星**（`Shielded Starbase`），
  外加无人机的**旗舰机巢**（`Capital Hive`）与**被侵袭的母星**（`Infested Starbase`）。
- 官方描述明确建议**用旗舰打**，普通战列舰很吃力。
- 这批站点的**中英文名与描述取自游戏官方 SDE**（`dungeons.jsonl`，与客户端内显示一致，不是机翻）；
  wiki 的 Combat site 页没有把它们列成条目，所以没有逐层怪表。
- 触发点 wiki 只记了三处（天蛇的隐秘集会点 / 中枢、无人机的组群），其余标注为"未记载"。

### 按势力筛选
1. 第二个下拉：全部势力 / 无人机 / 天蛇 / 血袭者 / 萨沙 / 天使 / 古斯塔斯。

### 按名称搜索
1. 在顶部搜索框输入站名关键字（中英文均可，也支持搜"可升级为谁"）。
2. 输入有短暂防抖，出结果后状态行显示「搜索到 N 项」；清空搜索框即回到当前筛选条件的完整列表。
3. 没有命中时列表区显示「没有匹配的 DED 空间」。

### 读正文
1. 正文用应用内置的 Markdown 渲染：标题、列表、表格、粗体 / 斜体、引用块都会成排版。
2. 正文可以像网页一样拖选一段再复制（Ctrl+C 或右键复制）。
3. 正文里的外链点击会用系统浏览器打开；图片不加载，降级成链接显示。

### 社区攻略 / Wiki 数据
- 很多站点有两份正文，此时右上会出现两个页签：
  - **社区攻略**：本站整理的中文实战经验（打法、翻车点、赏金/掉落的总量）。
  - **Wiki 数据**：从 EVE University Wiki 抓取并翻译成中文的结构化资料（每层 NPC 波次表、建筑、战利品估值）。
- **只有一侧有内容时不会显示页签栏**，直接铺满整块区域。
- 打开某条时默认停在有内容的那一侧（优先社区攻略）。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 英文名 / 中文名 | 站点的两个标题 | 与游戏内英文名一致；中文名沿用社区习惯译法 |
| 分类 | 站点类型 | 8 类，与 EVE University Wiki 的分类一致 |
| 势力 | 站点所属海盗势力 | 无人机 / 天蛇 / 血袭者 / 萨沙 / 天使 / 古斯塔斯 |
| 难度徽标 | 该站点的难度 | 评级复合体显示 `n/10`；战斗异常显示 `T档·级`；远征/其它显示类别 |
| 最大船型 | 允许进入的最大舰船级别 | 取自 wiki 的 ship limit；未知则不显示 |
| 出现空间 | 高安 / 低安 / 00 | 取自 wiki 的 location |
| 可升级为 | 这个异常/复合体可能升级成哪个站点 | 战斗异常最有用：直接告诉你"打完可能出哪个 DED" |
| 触发来源 | 这个远征由哪个无评级复合体触发 | 远征才有 |

> **关于「9/10」**：CONCORD 体系里**没有 9/10 这一档**，`<势力> 舰队集结点`（Fleet Staging Point）
> 严格说属于无评级复合体。但游戏里玩家一直按 9/10 叫它，所以这里**刻意**把它显示成 `9/10`
> 并归在「无评级复合体」分类下——这是有意的口径，不是数据错误。

## AI 能替你做什么 {#ai}
- 工具：`ded_info`。可按关键词 / 势力 / 分类 / 评级 / 异常档位查询，返回类别、难度标签、船型、出现空间、
  升级关系与正文要点摘要。
- 推荐问法：「DED 6/10 怎么打」「天使有哪些战斗异常」「古斯塔斯 10/10 的要点」「天蛇集结点怎么走」
  「T8 的异常有哪些」。
- **做不到**：返回的是正文摘要（超长会截断），看完整排版与怪表还是要到本页；AI 也不会替你进游戏打副本。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 没有匹配的 DED 空间 | 关键字或筛选条件组合下没有数据 | 放宽条件：切「全部分类」或清空搜索框 |
| 加载失败：… | 本地数据库读取异常 | 重启应用；仍失败时确认程序目录里的数据库文件完整 |
| 该站点暂无攻略正文 | 该站点的 wiki 页面缺失（红链）且没有社区攻略 | 换其它条目，或到 EVE University Wiki 查原页面 |

## 限制与已知问题 {#limits}
- **Wiki 数据是离线快照**：抓取于 2026-11-17（wiki revision 230825），不联网更新；游戏改版后细节可能滞后。
- **少数站点 wiki 没有页面**：这类条目只有基本信息，正文会明确写出"暂无独立页面（红链）"。
- **NPC 名以本地 SDE 的中文名为准**：SDE 里查不到的（多为废弃建筑、加速轨道）保留英文原名。
- **图片不加载**：正文里的图片一律降级为链接，点击去浏览器看原图。
- **非绝对地址的链接不可点**：正文里少数写法不规范的链接只作普通文本显示。
