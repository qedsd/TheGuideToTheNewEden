# 攻略 · 任务

## 一句话 {#tldr}
按**分类 / 等级 / 势力**筛出任务，右边直接看它的目标、奖励、电子战、船型限制与打法——
**1721 条**任务：中文名用客户端 SDE 的**官方译名**，攻略正文来自 EVE University Wiki，离线可查。

## 在哪打开 {#where}
- 左侧导航「**攻略**」→「**任务**」。
- 左栏：搜索框 + 任务列表 + 底部三个筛选（分类 / 等级 / 势力）与状态行；右栏：中英标题、元信息、正文。

## 前置条件 {#prereq}
- 无需登录角色、无需联网，数据随程序内置（`static.db` 的 `Mission` 表）。
- 数据是 EVE University Wiki 的离线快照（2026-11-17 抓取），不会自动跟随 wiki 更新。

## 操作步骤 {#steps}

### 找任务
1. 搜索框输入**中文名或英文名**（如「眼中」「Damsel」），输入即筛（300ms 防抖）。
2. 底部三个下拉：
   - **分类**：全部分类 / 安全任务 / 运输任务 / 采矿任务 / 故事线任务 / 史诗任务 / 异常任务 / COSMOS / 研发任务 / 职业代理人 / Circle 任务。
   - **等级**：不限 / `L1` … `L5`。
   - **势力**：不限 / 无人机 / 天蛇 / 血袭者 / 萨沙 / 天使 / 古斯塔斯 / **艾玛帝国 / 加达里合众国 / 盖伦特联邦 / 米玛塔尔共和国**（后四个是"打四大种族"的任务，如「腹背受敌」）。
3. 三个条件叠加生效；状态行显示「共 N 项」，搜索时变成「搜索到 N 项」。

### 看正文
右栏自上而下：
- **中英标题**（都能拖选复制）+ 元信息行（分类 · 等级 · 类型 · 势力 · 任务线）。
- **任务目标**：一行说清要干什么（例：「摧毁所有敌舰」「交付 4 箱单体电池」）。
- **属性**：电子战 / 反跳点、船型限制、推荐船型、奖励、声望损失、备注。
- **简报**：代理人接任务时说的那段话（1176 条任务有官方中文简报）。
- **正文小节**：攻略、打法、掉落、提示等。
- **NPC 表**：舰型 / 数量 / 名称 / 备注。名称列是**中英对照**（`血袭者哨站炮塔（Blood Raider Sentry Gun）`），约 70% 能对上客户端官方译名，其余保留英文；备注里点名的舰名同样会补中文。

## 常见问题 {#faq}
### 任务名是哪来的？
优先用 **SDE（客户端静态数据）里的官方译名**——就是游戏里显示的名字，89% 的任务能对上；
对不上的用旧版工具里玩家惯用的译名，再不行才是 wiki 标题的直译。所以搜「腹背受敌」「危难中的少女」
「人·畜」「抢救矿冶设施」这些游戏内叫法都能命中。

### 为什么有些任务的正文是英文？
**任务名、目标、属性、小节标题**都已经译成中文；wiki 上大段叙述性的 walkthrough 段落**暂时保留英文原文**——
这部分总量约 100 万字符，翻译要分很多批次，会陆续补。结构信息（打什么、用什么船、有什么电子战）已经够用来决策。

### 为什么有些任务点开只有标题和目标？
运输任务和部分采矿任务在 wiki 上本来就只有一条交付要求，没有逐段攻略。这类条目正文很短是正常的。

### 同名任务有两个条目？
同一个 wiki 页面常包含多个等级版本（如 `A Humble Gift` 同时有 L1 和 L3），
本页会把它们拆成两条，中文名后面用「（L1）」「（L3）」区分。

### 分类里的「异常任务」和导航里的「异常」是同一个吗？
不是。导航里的「**异常**」是战斗异常点（cosmic anomaly，扫出来的），
这里的「异常任务」是 **Anomic / 燃烧者** 任务（L4 代理人给的精英单挑任务）。

## 相关功能 {#related}
- **死亡远征**：DED 复合体与战斗异常点（要扫出来再跳进去打的那种）。
- **异常**：异常点 → DED 的升级对照表。

## 已知限制 {#limits}
- 长 walkthrough 段落仍是英文（见上）。
- 不覆盖活动任务、限时活动副本。
- 代理人具体空间站只在 wiki 写明时才记入「地点」，很多条目为空。
