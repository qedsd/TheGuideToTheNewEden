# 角色 · 技能

## 一句话 {#tldr}
看这个角色会什么、还在练什么：技能点总 / 未分配、训练队列的逐条进度，以及按技能组展开的已训练技能明细（支持搜索）。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**技能**」。
- 页面自上而下三块：「**技能点 / 未分配**」汇总卡（两栏并排）、标题「**技能队列**」的队列列表、标题「**技能**」的分组列表（右上角是搜索框）。

## 前置条件 {#prereq}
- 需要已登录角色，且授权范围含技能读取（`esi-skills.read_skills.v1`）；没勾时数据取不到。
- 技能数据有短时缓存：切走再切回不会重新请求；要立刻取新值，点工作区子页区右上角的「**刷新**」。

## 操作步骤 {#steps}

### 看技能点汇总
1. 顶部汇总卡两栏并排：左栏大字是**总技能点**（标签「**技能点**」），右栏大字是**未分配技能点**（标签「**未分配**」，悬停提示「未使用技能点」）。
2. 数字都是千分位整数；没取到数据时显示 `-`。

### 看训练队列
1. 「**技能队列**」区逐条列出训练计划：状态图标 + 技能名 + 目标等级数字。
2. 状态图标四种，悬停显示状态文字：**已完成**与**进行中**为绿色、**已暂停**为橙色、**等待中**为普通文字色（与总览页的绿色不同）。
3. 非暂停条目的第二行是**剩余时间**（`天d 小时h 分钟min`）与**起止时间**（本地时间 `开始 - 结束`）；已暂停条目只显示橙色状态文字。
4. 队列为空时显示「**暂无数据**」。

### 搜技能
1. 「**技能**」区右上角的搜索框（占位文字「**搜索技能**」）输入技能名关键字：列表**即时过滤**，只保留名字匹配的技能；组名保留，没有命中的组隐藏。
2. 清空搜索框即恢复全部分组。

### 展开技能组
1. 「**技能**」区按技能组分块，每组一个折叠块：标题是**组名**，右侧是**组内技能个数**（悬停提示「组内技能个数」）。
2. 展开后逐行列出已训练的技能：技能名 / 已掌握的等级（悬停提示「已掌握的等级」）/ 已训练的技能点（千分位、右对齐，悬停提示「已训练的技能点」）。
3. 列表只包含**已训练**的技能：没训练过的技能不显示；一个技能都没练过的组不显示；整页无数据时显示「**暂无数据**」。

### 刷新
- 工作区子页区右上角「**刷新**」绕过缓存重取全部三块数据。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 总技能点 | 角色累计技能点 | 千分位整数 |
| 未分配 | 尚未分配的技能点 | 千分位整数；悬停提示「未使用技能点」 |
| 队列 · 目标等级 | 本条训练完成后达到的等级 | 数字 |
| 队列 · 状态 | 已完成 / 进行中 / 等待中 / 已暂停 | 缺任一时间为已暂停；结束时间已过为已完成；开始时间未到为等待中；其余为进行中；已完成 / 进行中为绿色、已暂停为橙色、等待中为普通文字色 |
| 队列 · 剩余时间 | 进行中按"结束 − 现在"，其余按"结束 − 开始" | `天d 小时h 分钟min` |
| 队列 · 起止时间 | 训练开始与结束时间 | 本地时间 |
| 组内技能个数 | 该组已训练的技能条数 | 口径偏窄：是本地物品库与账号数据都命中的条数（§8 第 7 条），不是该组全部技能数 |
| 等级 | 该技能已掌握的等级 | 0–5 |
| 技能点 | 该技能累计投入的技能点 | 千分位整数 |

## AI 能替你做什么 {#ai}
- 工具：`character_skills`（只读）——报总技能点 / 未分配、训练队列**条数**，并可按**技能组名或技能名关键字**过滤明细（命中的组最多 5 个、每组列最多 10 条技能，含等级与技能点）。
- 推荐问法：「我技能点多少」「学没学 XX 技能」「XX 组里有哪些技能」。
- **做不到**：不能替你开始 / 暂停训练或调整技能队列（要在游戏里操作）；AI 只报队列条数，不报每条练到哪、还剩多久——要看进度请到本页；单次回答也只列前几个组、每组前几条，完整明细以本页为准。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 三块都显示 `-` 或「暂无数据」 | 技能数据没取到（ESI 不可用、令牌失效或没勾技能权限） | 点「刷新」重试；确认「设置 → 权限选择」勾了技能权限 |
| 刚训练完但数字没变 | 命中短时缓存 | 点「刷新」绕过缓存 |
| 搜不到某个技能 | 该技能从未训练过（列表只含已训练技能） | 属预期；未训练的技能不在本页 |
| AI 回答「技能数据获取失败（ESI 不可用或限流）。」 | 技能接口请求失败 | 稍后重试；确认角色已登录且网络可用 |

## 限制与已知问题 {#limits}
- **「组内技能个数」口径偏窄**（§8 第 7 条）：组标题右侧的个数是"本地物品库与账号数据都命中"的技能数，不是该技能组的全部技能数（旧版显示全部）。
- **技能名没有悬浮说明**（§8 第 8 条）：技能名不显示物品描述提示；等级与技能点的提示已有。
- **数据有短时缓存**：切换标签回来不重新请求；「刷新」绕过缓存。
- **队列起止时间与总览页口径不同**：本页直接显示本地时间；总览页按游戏时间（UTC）显示、悬停为本地时间。
