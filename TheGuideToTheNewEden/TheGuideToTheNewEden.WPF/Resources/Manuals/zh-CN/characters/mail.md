# 角色 · 邮件

## 一句话 {#tldr}
按标签浏览角色的 EVE 邮件，看未读数、读正文；打开一封邮件就会把它标记为已读。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**邮件**」。
- 页面左右两栏：左栏是**标签列表**（顶部是「**全部邮件**」伪标签，下面是游戏里的各标签，右侧有未读数圆点徽标）；右栏是**邮件列表**（每行是未读圆点 + 主题 + 发件人 + 本地日期）。
- 点一封邮件会打开**独立的详情窗口**（非模态，可以同时开多封）。

## 前置条件 {#prereq}
- 需要已登录角色；读邮件需要邮件读取权限（`esi-mail.read_mail.v1`）。
- **标记已读**还需要邮件整理权限（`esi-mail.organize_mail.v1`）：没这权限时详情仍能打开，但未读状态不会写回服务器，列表里的未读点也不会消失。
- 标签与未读数有约 2 分钟缓存；邮件列表每次切换标签都现取。

## 操作步骤 {#steps}

### 浏览邮件
1. 左栏点「**全部邮件**」看所有邮件，或点某个标签只看该标签下的邮件。
2. 右栏每行显示：**未读圆点**（悬停提示「未读」）、**主题**（无主题显示 `(no subject)`）、**发件人**（解析不到显示原始 ID）、**日期**（本地时间 `yyyy-MM-dd HH:mm`）。
3. 列表加载中会显示「**正在加载…**」。

### 读一封邮件
1. 点邮件列表里的一行，弹出**详情窗口**：标题栏与首行是主题，下面是**发件人**（圆形头像 + 名称，头像加载失败时显示首字母占位）、**日期**、**收件人**、**标签**，正文按 HTML 原样渲染。
2. 未读邮件在详情**成功加载后自动标记为已读**（写回服务器），列表里该邮件的未读点随之消失；左侧标签上的未读数徽标要等下次重新读取标签后才更新（点工作区「**刷新**」可立即重取）。
3. 正文里的**远程图片不会加载**（离线与隐私取向），固定像素字号的强制排版也被移除。

### 刷新
- 工作区子页区右上角「**刷新**」：绕过缓存重新读取标签与当前标签下的邮件列表。

## 字段与口径 {#fields}

| 位置 / 字段 | 含义 | 口径 |
|---|---|---|
| 全部邮件 | 顶部的伪标签 | 显示**所有**邮件（不限标签）；自身不计未读数 |
| 标签行 | 游戏内邮件标签 | 右侧圆点徽标 = 未读数，悬停提示「未读邮件」；超过 99 显示 `99+` |
| 未读圆点 | 该邮件未读 | 悬停提示「未读」 |
| 主题 | 邮件主题 | 无主题显示 `(no subject)` |
| 发件人 | 发件者名称（角色 / 军团 / 联盟 / 邮件列表） | ESI 批量解析；解析不到显示原始 ID |
| 日期 | 邮件时间 | ESI 的 UTC 统一转本地时间（`yyyy-MM-dd HH:mm`） |
| 收件人 | 详情窗口里的收件人列表 | 多人用「; 」连接；解析不到显示原始 ID |
| 标签 | 详情窗口里该邮件的标签 | 多个用「; 」连接；未解析到的标签不显示 |

## AI 能替你做什么 {#ai}
- 工具：`character_mail`（只读）——先报各标签的未读合计与列表，再列出某标签下邮件的**标题、发件人、时间与已读状态**（可指定标签与条数，默认 12 条、最多 40 条）。
- 工具：`character_navigate`——打开指定角色的**工作区**（不会直接落到「邮件」子页，需要再点一下「邮件」页签）。
- 推荐问法：「我有多少未读邮件」「最近谁给我发邮件」。
- **做不到**：读不到邮件**正文**（工具只给邮件头列表）；**不会**替你标记已读（读列表不改变已读状态）；不能发邮件、转发或删除邮件；取不到数据时会说「邮件获取失败（ESI 不可用、缺少邮件权限或限流）。」

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 列表为空且无提示 | 没有邮件（正常空态），或取数失败（ESI 不可用、令牌失效、权限不足）——页面失败时静默为空 | 点「刷新」重试；确认授权里有邮件权限 |
| 详情窗口主题显示 `-` | 邮件正文没取到 | 关掉窗口重开一次 |
| 已读邮件的未读点不消失 | 缺少邮件整理权限，或标记已读的请求失败 | 确认授权里有 `esi-mail.organize_mail.v1` |
| 标签未读数与实际不符 | 标签与未读数有约 2 分钟缓存 | 点「刷新」立即重取 |

## 限制与已知问题 {#limits}
- **正文里的链接不可点击**（§8 第 1 条）：正文是离线渲染的 HTML，链接有样式但点了没有反应；要打开链接请回游戏或网页端。
- **正文图片不显示**：远程图片被有意剥离（离线与隐私取向），不是加载失败。
- **打开即标记已读**（与旧版一致）：点开一封未读邮件就会写回服务器，不可撤销；不想标已读就不要点开。
- **标签未读徽标不实时**：徽标来自约 2 分钟的标签缓存，读完邮件后要等重新读取标签才更新。
- **邮件列表每次现取**：切换标签都会重新请求，邮件多时会稍慢。
- **无搜索、无排序**：列表只按接口返回顺序展示，本页没有搜索框。
