# 角色 · 合同

## 一句话 {#tldr}
翻看角色的**个人合同**与**军团合同**：谁发布的、什么类型、多少钱、起止在哪、到期没有，按页翻阅，用来清点还没处理的合同。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**合同**」。
- 页面是「**个人** / **军团**」两个页签，各一张表格 + 底部**分页条**（上一页 / 页码 / 下一页）。
- 表格列宽超出可视区时，用表格下方 / 外层的滚动条横向查看，右侧列不会被裁掉。

## 前置条件 {#prereq}
- 需要已登录角色；个人合同需要合同读取权限（`esi-contracts.read_character_contracts.v1`）。
- 军团页签需要军团合同权限（`esi-contracts.read_corporation_contracts.v1`）；没权限时表格为空。
- 个人 / 军团两个页签的**首页**有约 2 分钟缓存（翻页与「刷新」不走缓存）；页签首次选中时才加载数据。

## 操作步骤 {#steps}

### 看合同列表
1. 「**个人**」页签列出与该角色相关的合同；「**军团**」页签列出所在军团的合同（首次切过去才请求）。
2. 两个页签列完全相同，共 16 列（顺序见「字段与口径」）。
3. 表格只读、可点选行；账号没有合同时表格为空，属正常空态。

### 翻页
1. 底部分页条点「**下一页**」/「**上一页**」翻页；翻页会重新请求。
2. ESI 无法预知总页数：当前页取到数据就提供「下一页」，翻到空页后「下一页」不可用。

### 刷新
- 工作区子页区右上角「**刷新**」：当前页签回到第一页并绕过缓存重新取。

## 字段与口径 {#fields}

| 列 | 含义 | 口径 |
|---|---|---|
| 标题 | 合同标题 | 未填标题显示 `-`；超宽省略号截断 |
| 类型 | 合同类型 | 显示为「物品交换 / 拍卖 / 快递」等本地化文本（`Loan` 类型保留英文） |
| 价格 | 合同金额 | 两位小数 |
| 发布人 | 发布者（角色 / 军团）名称 | ESI 批量解析；解析不到显示原始 ID |
| 发布于 | 发布时间 | 本地时间（`yyyy-MM-dd HH:mm:ss`） |
| 过期于 | 到期时间 | 同上；可空 |
| 接收人 | 已接受者名称 | 无接收人显示 `-`；解析不到显示原始 ID |
| 起始位置 | 出发地（空间站 / 建筑名） | 按 ID 分流解析；解析不到显示原始 ID |
| 状态 | 合同状态 | ESI 原文（如 `outstanding`），未本地化 |
| 军团合同 | 是否军团合同 | 直接显示 `True` / `False` |
| 一口价 | 一次性买断价 | 两位小数 |
| 体积 | 合同总体积 | 两位小数 |
| 奖励 | 合同报酬（如快递运费） | 两位小数 |
| 押金 | 快递押金 | 两位小数 |
| 结束位置 | 目的地（空间站 / 建筑名） | 同「起始位置」 |
| 完成天数 | 允许完成的天数 | 整数 |

## AI 能替你做什么 {#ai}
- 工具：`character_contracts`（只读）——按页报合同列表摘要（状态 / 类型 / 标题 / 价格 / 发布人 / 发布与到期时间 / 接受者），可指定角色、查军团合同、翻页与指定条数（默认 12 条、最多 40 条）。
- 推荐问法：「我有没有没处理的合同」「军团合同里有哪些在等」「看看 XX 的合同」。
- **做不到**：不能替你接受、拒绝或创建合同；读不到合同里的**物品清单**（工具只给列表摘要）；取不到数据时会说「合同获取失败（ESI 不可用、缺少合同权限或限流）。」或「军团合同获取失败（需要军团合同权限，或 ESI 不可用/限流）。」

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 表格为空 | 没有合同（正常空态），或数据没取到（ESI 不可用、令牌失效） | 点「刷新」重试 |
| 军团页签一直为空 | 该角色没有军团合同权限 | 确认授权里包含军团合同权限 |
| 起始 / 结束位置显示一串数字 | 位置名称解析不到（结构位置只查本地结构列表） | 属预期回退，显示的是原始 ID |
| 发布人 / 接收人显示一串数字 | 该名称不在本地名单与 ESI 解析结果里 | 属预期回退 |

## 限制与已知问题 {#limits}
- **合同详情窗口未实现**（§8 第 2 条）：旧版点击合同行会打开详情，这里点击行只是选中；要看物品清单得回游戏或网页端。
- **起止位置的结构名解析范围有限**（§8 第 5 条）：合同地点若是玩家建筑（结构），名称只查**本地结构列表**（在「设置 → 玩家建筑」等处解析过的），解析不到回退显示原始 ID。
- **表格只有排序 / 列宽 / 列重排等标准能力**（§8 第 3 条）：旧版表格的分组、列筛选与分组合计行没有平替。
- **分页没有总页数**：取到数据就提供「下一页」（与钱包日志页一致）。
- **首页有约 2 分钟缓存**，翻页与「刷新」不走缓存。
- **状态列是 ESI 原文**，未做中文映射；「军团合同」列显示布尔原文。
