# 角色 · 工业

## 一句话 {#tldr}
看这个角色**正在跑的工业任务**：什么蓝图、产出什么、还剩多久完成、在哪个设施，用来安排取货和排下一批活。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**工业**」。
- 页面是一张单表格（没有页签、没有分页），列宽超出可视区时用表格下方 / 外层的滚动条横向查看。

## 前置条件 {#prereq}
- 需要已登录角色；需要工业任务读取权限（`esi-industry.read_character_jobs.v1`），没权限时表格为空。
- 任务列表有约 5 分钟缓存，「刷新」会绕过缓存重新取。
- 表格里没有任务时为空表，属正常空态。

## 操作步骤 {#steps}

### 看工业任务
1. 表格一行一个任务，共 10 列（顺序见「字段与口径」）：**蓝图 / 产品 / 状态 / 流程 / 成功率 / 开始时间 / 项目周期 / 完成时间 / 项目费用 / 位置**。
2. 「状态」是本地化文本：**完成 / 运行中 / 已取消 / 已交付 / 已暂停 / 准备 / 已恢复**；已到期但接口仍报「运行中」的任务会显示为「完成」。
3. 「完成时间」已过去的任务即为可取货；「项目周期」是该任务的总时长，不是剩余时间。

### 刷新
- 工作区子页区右上角「**刷新**」绕过缓存重新取任务列表。

## 字段与口径 {#fields}

| 列 | 含义 | 口径 |
|---|---|---|
| 蓝图 | 使用的蓝图名 | 本地物品库解析；查不到显示原始 ID |
| 产品 | 该任务的产物名 | 本地物品库解析；无产物的任务显示 `-` |
| 状态 | 任务状态 | 本地化文本（完成 / 运行中 / 已取消 / 已交付 / 已暂停 / 准备 / 已恢复）；未知状态显示原文 |
| 流程 | 该任务的流程数（runs） | 整数 |
| 成功率 | 任务成功概率 | 两位小数；接口不给概率的任务（如制造）显示 `0.00` |
| 开始时间 | 任务开始时间 | 本地时间（`yyyy-MM-dd HH:mm:ss`） |
| 项目周期 | 任务总时长 | 格式为 天.时:分:秒（不足一天为 时:分:秒） |
| 完成时间 | 预计完成时间 | 本地时间（同上）；可空 |
| 项目费用 | 任务费用 | 两位小数 |
| 位置 | 所在设施（空间站 / 建筑名） | 按 ID 分流解析；解析不到显示原始 ID |

## AI 能替你做什么 {#ai}
- 工具：`character_industry`（只读）——报任务列表摘要（状态 / 蓝图 → 产物×流程 / 成功率 / 完成时间 / 剩余时间 / 设施 / 成本），可指定角色与条数（默认 10 条、最多 30 条）。
- 推荐问法：「我有哪些活还在跑」「XX 什么时候能造完」。
- **做不到**：不能替你暂停、取消或交付任务；读不到蓝图的材料清单与产物详情；也查不到**军团**的工业任务（工具只查角色个人）；取不到数据时会说「工业任务获取失败（ESI 不可用、缺少工业权限或限流）。」

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 表格为空 | 当前没有工业任务（正常空态），或数据没取到（ESI 不可用、令牌失效） | 点「刷新」重试 |
| 位置显示一串数字 | 设施名称解析不到（结构位置只查本地结构列表） | 属预期回退，显示的是原始 ID |
| 成功率显示 `0.00` | 该类任务接口不返回概率（如制造） | 属正常显示，不代表会失败 |
| 刚完成的任务状态没变 | 列表有约 5 分钟缓存 | 点「刷新」绕过缓存重取 |

## 限制与已知问题 {#limits}
- **表格只有排序 / 列宽 / 列重排等标准能力**（§8 第 3 条）：旧版表格的分组、列筛选与分组合计行没有平替。
- **位置的结构名解析范围有限**（§8 第 5 条）：设施若是玩家建筑（结构），名称只查**本地结构列表**（在「设置 → 玩家建筑」等处解析过的），解析不到回退显示原始 ID。
- **无分页**：任务列表一次取回，没有分页条。
- **数据有约 5 分钟缓存**，不是实时的；「刷新」绕过缓存。
- **成功率列的 `0.00`** 表示接口未给概率（如制造任务），不是失败率。
- **时间是本地时间**：ESI 的 UTC 时间统一转成本地时间显示。
