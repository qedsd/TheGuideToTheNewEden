# 角色 · 总览

## 一句话 {#tldr}
在角色工作区里速览这个角色"现在怎么样"：军团与联盟、当前舰船与所在地点、在线状态与最近上线，以及技能队列还要练多久。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 右侧子页签「**总览**」（七个子页的第一个，默认打开）。
- 页面是一列**信息卡片**，占满整个内容区宽度，自上而下：军团、联盟、舰船与地点、在线状态、技能队列。

## 前置条件 {#prereq}
- 需要先在「角色」页添加并登录角色（工作区要在某个角色的标签里打开）。
- 各卡片数据来自 ESI 授权：所在地点与当前舰船需要位置权限、在线状态需要在线权限、技能队列需要技能权限；对应权限没勾或令牌失效时，相应卡片不显示或显示占位。
- 军团、联盟、舰船与地点三张卡**取到数据才显示**；在线卡与技能队列卡始终显示。
- 军团 / 联盟徽标与舰船图从官方图源在线加载，下载失败时只显示底色框。

## 操作步骤 {#steps}

### 看军团与联盟
1. 军团卡是**圆形徽标 + 军团名 + 代号**；加入联盟时，下面还有一张同样式的联盟卡。
2. 徽标按当前游戏服务器自动取官方头像，先出文字、图片随后异步补上。

### 看舰船与地点
1. 卡片第一行是**所在地点**：`地点名 (安全等级 星系名)`——安全等级保留两位小数，星系名用主题色强调。
2. 第二行是**当前舰船**：`舰船名 (船型名)`；舰船名是这艘船的个体名称，游戏里重命名过就显示重命名的名字。
3. 卡片左侧是舰船图像。

### 看在线状态
1. 卡片左侧圆点：绿色 = 在线，红色 = 离线；悬停圆点显示「**在线** / **离线**」文字。
2. 右侧两行：「**最近上线**」是距上次登录的时长（年 / 月 / 天 / 小时 / 分钟逐级降档，如 `2d 3.5h`），悬停显示精确的本地登录时间；「**上线次数**」是累计登录次数。

### 看技能队列
1. 卡片顶部是「**技能队列**」标题，下面逐条列出训练计划：状态图标 + 技能名 + 目标等级数字。
2. 状态图标四种，悬停显示状态文字：**已完成**（绿）、**进行中**（绿）、**等待中**（绿）、**已暂停**（橙）。
3. 非暂停条目的第二行是时间与**起止时间**（`开始 - 结束`）：起止时间按游戏时间（UTC）显示，悬停是本地时间；已暂停的条目只显示橙色的「**已暂停**」字样。
4. 队列为空时显示「**未在训练**」。

### 刷新
- 工作区子页区右上角「**刷新**」重新拉取本页（绕过缓存）；军团 / 联盟 / 技能等数据有短时缓存，切走再切回不会重新请求。

## 字段与口径 {#fields}

| 卡片 / 字段 | 含义 | 口径 |
|---|---|---|
| 军团卡 | 军团徽标 + 名称 + 代号 | 有军团名才显示 |
| 联盟卡 | 联盟徽标 + 名称 + 代号 | 加入联盟才显示 |
| 地点 | 所在空间站 / 建筑名 | 空间站名走本地数据库；建筑名通过 ESI 解析；解析不到时该行只显示星系部分 |
| 安全等级 | 所在星系的安全等级 | 两位小数 |
| 星系 | 所在星系名 | 主题色强调 |
| 当前舰船 | 舰船个体名 + 船型名 | 个体名可被游戏内重命名 |
| 最近上线 | 距上次登录的时长 | 年 / 月 / 天 / 小时 / 分钟逐级降档；悬停为精确本地时间 |
| 上线次数 | 累计登录次数 | — |
| 队列 · 目标等级 | 本条训练完成后达到的等级 | 数字 |
| 队列 · 时间 | 进行中为剩余时间，其余为"结束 − 开始"的间隔 | `天d 小时h 分钟min` |
| 队列 · 起止时间 | 训练开始与结束时间 | 按游戏时间（UTC）显示，悬停为本地时间 |

## AI 能替你做什么 {#ai}
- 工具：`character_overview`（报出生日期、技能点总 / 未分配、忠诚点、安全等级、个人与公司钱包、军团（联盟）与技能队列**条数**）、`character_navigate`（**动作类**：打开角色页并进入该角色的工作区；找不到角色时只回原因、不跳转）。
- 推荐问法：「我的角色什么情况」「XX 现在在哪个军团」「打开 XX 的角色页」。
- **做不到**：`character_overview` 不返回所在地点、当前舰船与在线状态，也只报队列条数、不逐条报每项技能与剩余时间——这几块要看本页卡片与「技能」页；AI 也不能替你在游戏里换舰船、跳空间站。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 军团 / 联盟 / 舰船地点卡不显示 | 对应数据没取到（ESI 不可用、令牌失效或权限没勾） | 点子页区右上角「刷新」重试；确认「设置 → 权限选择」勾了相关权限 |
| 「最近上线」显示 `-` | 取不到上次登录时间 | 刷新重试 |
| 徽标 / 舰船图只显示底色框 | 官方图源下载失败 | 网络恢复后点「刷新」重取 |
| 技能队列显示「未在训练」 | 队列为空，或技能数据没取到 | 到游戏里给角色安排技能；或刷新重试 |
| AI 回答「角色概览获取失败（ESI 不可用或限流）。」 | 概览接口请求失败 | 稍后重试；确认角色已登录且网络可用 |

## 限制与已知问题 {#limits}
- **每次进入自动回到页面顶部**：页面实例常驻，滚动位置不跨"进入"保留（不会停在技能队列底部）。
- **队列起止时间按游戏时间（UTC）显示**：与「技能」页的本地时间不同（沿用旧版行为）；要看本地时间请悬停。
- **技能名没有悬浮说明**（§8 第 8 条）：队列条目的技能名不显示描述提示；状态图标与起止时间可以悬停查看。
- **技能组口径相关限制**（§8 第 7 条"组内技能个数"）在「技能」页，见 [角色 · 技能](characters/skills)。
- **图像在线加载**：徽标与舰船图每次都重新下载（不落盘缓存），网络慢时图片会晚一点出现。
