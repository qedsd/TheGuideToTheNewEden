# 角色 · 钱包

## 一句话 {#tldr}
看这个角色的 ISK 去向：个人与军团的**钱包日志**（每笔资金变动的合计与余额）与**市场交易**（买卖的物品、价格、对手方与地点），按页翻阅历史。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**钱包**」。
- 页面是四个页签：「**个人-日志**」「**个人-交易**」「**军团-日志**」「**军团-交易**」。
- 两个日志页签底部有**分页条**（上一页 / 页码 / 下一页）；两个交易页签一次取回，没有分页条。
- 军团两个页签的右上有「**钱包**」编号选择框。

## 前置条件 {#prereq}
- 需要已登录角色；个人页签需要钱包读取权限（`esi-wallet.read_character_wallet.v1`）。
- 军团页签需要角色的军团财务权限（`esi-wallet.read_corporation_wallets.v1`）；没权限时表格为空。
- 个人两个页签的首页有短时缓存（翻页与刷新直接请求）；军团两个页签每次都现取。
- 页签首次选中时才加载数据，四个页签不会一次性全部请求。

## 操作步骤 {#steps}

### 看个人钱包日志
1. 切到「**个人-日志**」页签：表格逐行列出每笔资金变动，列为**时间 / 合计 / 钱包余额 / 描述 / 类型 / 原因**。
2. 「合计」按正负着色：收入为绿、支出为红；「钱包余额」是该笔之后的余额。
3. 表格只读、可点选行（可多选）。
4. 底部分页条点「**下一页**」/「**上一页**」翻页，页码显示「第 N 页」；翻页会重新请求（不走缓存）。
5. ESI 无法预知总页数：取到数据就提供「下一页」，没有数据的那一页「下一页」不可点。

### 看个人市场交易
1. 切到「**个人-交易**」页签：列为**时间 / 物品 / 单位价格 / 数量 / 总价格 / 客户 / 位置 / 交易类型**。
2. 「总价格」着色：**买入**为绿、**卖出**为红；「交易类型」列直接显示「**买入** / **卖出**」。
3. 「客户」是对手方名称：新对手方第一次出现时会发一次解析请求（页签会短暂等待），之后命中本地名单直接显示；解析不到时显示原始 ID。
4. 「位置」是交易发生的空间站 / 建筑名；解析不到时显示原始 ID。
5. 交易一次取回，没有分页条。

### 看军团钱包
1. 切到「**军团-日志**」或「**军团-交易**」页签，列与个人侧相同。
2. 右上角「**钱包**」编号框选 1–7，对应军团的不同钱包部门；改变编号后立即重新取数（日志会回到第一页）。
3. 军团-日志页签同样有分页条；军团-交易一次取回。

### 刷新
- 工作区子页区右上角「**刷新**」重新取当前页签：日志回到第一页并绕过缓存，交易重新取全量。

## 字段与口径 {#fields}

日志列（个人 / 军团相同）：

| 列 | 含义 | 口径 |
|---|---|---|
| 时间 | 该笔发生时间 | 本地时间（`yyyy-MM-dd HH:mm:ss`） |
| 合计 | 该笔金额 | 正=收入（绿）、负=支出（红）；两位小数 |
| 钱包余额 | 该笔之后的余额 | 两位小数 |
| 描述 | 交易附言 | 原样显示 |
| 类型 | 流水业务类型 | ESI 原文 |
| 原因 | 该笔的原因字段 | 原样显示，可为空 |

交易列（个人 / 军团相同）：

| 列 | 含义 | 口径 |
|---|---|---|
| 时间 | 交易发生时间 | 本地时间（同上） |
| 物品 | 交易物品名 | 按本地物品库解析 |
| 单位价格 | 单价 | 两位小数 |
| 数量 | 成交数量 | 整数 |
| 总价格 | 单价 × 数量 | 买入为绿、卖出为红 |
| 客户 | 对手方（角色 / 军团 / 联盟）名称 | ESI 批量解析；解析不到显示原始 ID |
| 位置 | 交易地点（空间站 / 建筑名） | 按 ID 分流解析；解析不到显示原始 ID |
| 交易类型 | 买入 / 卖出 | — |

## AI 能替你做什么 {#ai}
- 工具：`character_wallet`（只读）——报钱包**余额**与近期流水摘要（时间 / 类型 / 金额正负）；流水条数可指定（默认 10 条、最多 30 条）。
- 推荐问法：「我钱包里有多少钱」「最近收支怎么样」。
- **做不到**：只覆盖**个人**钱包——读不到军团钱包的日志与交易（要看本页的军团页签）；也读不到交易的**对手方与地点明细**（工具只给摘要）；不能替你转账或做任何资金操作。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 表格为空 | 数据没取到（ESI 不可用、令牌失效），或该页签确实没有数据 | 点「刷新」重试；空表属正常空态 |
| 军团页签一直为空 | 该角色没有军团财务权限 | 确认「设置 → 权限选择」勾了军团钱包权限；没有权限就取不到 |
| 客户 / 位置显示一串数字 | 该名称解析不到（不在本地名单与结构列表里） | 属预期回退；显示的是原始 ID |
| 切到交易页签时短暂等待 | 首次出现的新对手方需要发一次名称解析请求 | 等待即可；之后命中本地名单不再请求 |
| AI 回答「钱包流水获取失败（ESI 不可用或限流）。」 | 流水接口请求失败 | 稍后重试 |

## 限制与已知问题 {#limits}
- **表格只有排序 / 列宽 / 列重排等标准能力**（§8 第 3 条）：旧版表格的分组拖放区、列筛选与「分组合计 ISK」分组合计行没有平替。
- **交易不分页**：个人与军团的交易都是单次取回（ESI 单页返回），超出部分看不到。
- **分页没有总页数**：日志分页条只显示上一页 / 页码 / 下一页，取到数据就提供「下一页」；军团-日志以"取到数据"判断可否翻页。
- **列宽超出时横向滚动**：表格底部有横向滚动条，右侧列不会被压缩截断。
- **个人侧首页有短时缓存**，军团侧每次现取；「刷新」绕过缓存。
- **时间是本地时间**：ESI 的 UTC 时间统一转成本地时间显示。
