# 角色 · 克隆

## 一句话 {#tldr}
看这个角色的克隆状态：基地在哪个空间站、上次变更与上次远克的时间、一共有几个克隆，以及当前激活克隆与每个跳跃克隆里装了哪些脑插。

## 在哪打开 {#where}
- 左侧导航「**角色**」→ 点角色卡片进入工作区 → 子页签「**克隆**」。
- 页面自上而下：一张**汇总卡**（基地 / 上一次变更 / 克隆数量 / 上一次远克 四格）、「**当前激活克隆**」卡、**跳跃克隆**列表（每个克隆一个折叠块）。

## 前置条件 {#prereq}
- 需要已登录角色，且授权范围含克隆读取（`esi-clones.read_clones.v1` / `esi-clones.read_implants.v1`）；没勾时页面保持空白。
- 克隆信息有短时缓存：切走再切回不会重新请求；要立刻取新值，点工作区子页区右上角的「**刷新**」。

## 操作步骤 {#steps}

### 看汇总
1. 汇总卡四格：「**基地**」是当前激活克隆所在地点名（悬停显示全文）、「**上一次变更**」是上次变更基地的时间、「**克隆数量**」、「**上一次远克**」是上次跳跃克隆的时间。
2. 时间都是本地时间（`yyyy-MM-dd HH:mm`）；没有记录时显示 `-`。
3. 「**克隆数量**」**包含当前激活克隆**（跳跃克隆数 + 1）。

### 看当前激活克隆
1. 「**当前激活克隆**」卡标题右侧是「**脑插数量**」与数值。
2. 卡内先显示「基地」与所在地点名；下面逐行列出**脑插名称**，悬停显示该脑插的**描述**。
3. 没有任何脑插时显示一条占位横线 `-`。

### 看跳跃克隆
1. 跳跃克隆列表里每个克隆一个折叠块：标题是**地点名**（悬停显示全文）+ 克隆名（起过名才显示），右侧是**脑插数量**（悬停提示「脑插数量」）。
2. 展开后逐行列出该克隆的**脑插名称**，悬停显示描述。

### 刷新
- 工作区子页区右上角「**刷新**」绕过缓存重取本页全部内容。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 基地 | 当前激活克隆所在的地点 | 空间站 / 建筑名按 ID 解析（结构 ID 只查本地结构列表）；解析不到时显示原始 ID；没有记录显示 `-` |
| 上一次变更 | 上次变更基地的时间 | 本地时间；无记录 `-` |
| 克隆数量 | 跳跃克隆数 + 当前激活克隆 | 与旧版口径一致 |
| 上一次远克 | 上次跳跃克隆的时间 | 本地时间；无记录 `-` |
| 当前激活克隆 · 地点 | 取自基地 | 与汇总卡的「基地」同值 |
| 当前激活克隆 · 脑插 | 角色当前安装的植入体 | 名称按本地物品库解析（解析不到显示原始 ID）；悬停为描述 |
| 跳跃克隆 · 地点名 | 该克隆所在的空间站 / 建筑 | 同「基地」的解析口径 |
| 跳跃克隆 · 脑插 | 该克隆内安装的植入体 | 同上 |
| 克隆名 | 跳跃克隆的自定义名称 | 起过名才显示 |

## AI 能替你做什么 {#ai}
- 克隆页**没有专属 AI 工具**：助手没有为克隆信息封装的查询工具，"我的脑插是什么""基地在哪"这类问题默认答不了。
- 助手可以打开角色页（`character_navigate`），但进入后仍需要你自己在「克隆」页签里看。
- **做不到**：读不到本页展示的克隆与脑插明细；不能替你远克、变更基地或摘装脑插（这些都是游戏内操作）。若确实要让 AI 读原始克隆数据，只能走 ESI 全量网关的只读调用（返回原始数据、需要自行解读，且要求授权范围含克隆读取权限）。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 页面一直是空的 | 克隆数据没取到（ESI 不可用、令牌失效或没勾克隆权限） | 点「刷新」重试；确认「设置 → 权限选择」勾了克隆相关权限 |
| 基地 / 地点名显示一串数字 | 该地点名称解析不到（不在本地名单与结构列表里） | 属预期回退；显示的是原始地点 ID |
| 脑插名显示一串数字 | 该脑插不在本地物品库 | 属预期回退；显示的是原始类型 ID |
| 上一次变更 / 上一次远克显示 `-` | 该角色没有对应记录 | 属预期 |

## 限制与已知问题 {#limits}
- **数据有短时缓存**：克隆信息变化慢，切走再切回不重新请求；「刷新」绕过缓存。
- **地点名解析范围有限**（§8 第 5 条同源）：普通 ID 走名称服务，玩家结构只查本地结构列表；都不命中时回退显示原始 ID，不会为单个名称额外发请求。
- **当前激活克隆的"地点"就是基地**：卡上的地点名取自基地，不单独显示激活克隆的位置。
- **脑插只有名称与描述**：不显示所在插槽位置。
