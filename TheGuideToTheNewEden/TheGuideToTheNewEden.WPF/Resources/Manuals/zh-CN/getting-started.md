# 快速上手

## 一句话 {#tldr}
首次启动到能用起来的最短路径：选好数据目录、语言与主题 → 添加第一个角色 → 告诉软件游戏日志在哪 → 固定主页磁贴。做完这些，其余功能按需再配。

## 这份手册讲什么 / 从哪开始 {#where}
- 这是一篇**横切手册**，不对应单独页面：把「设置」「角色」「主页」里首次使用要碰的入口串成一条最短路径，按下方「最短上手路径」从上往下做即可。
- 覆盖六件事：数据目录（配置与日志放在哪）、语言与主题（设置 → 一般）、添加角色（欧服自动回调 / 国服四步向导）、游戏日志目录（设置 → 游戏日志）、主页快捷方式（固定到主页）、托盘与关闭行为。
- 单个功能的完整细节看对应手册（文末「相关手册」）；本文只写"第一次用要动哪些"。

## 前置条件 {#prereq}
- 语言 / 主题 / 主页磁贴：无需登录，打开就能改。
- 添加角色需要能联网的默认浏览器：欧服（Tranquility）授权回调走本地回环，回调地址须与 EVE 开发者后台登记的 Callback URL 一致（一般装好即用，出问题看「设置 → 测试 → 回环回调」）；国服（Serenity）授权后需手动粘贴网址 / code。
- 频道预警 / 频道监控 / 频道查价 / 频道翻译依赖游戏日志：游戏里打开过频道才有文件可读。

## 最短上手路径 {#steps}

### 第 1 步：语言与主题
1. 左侧导航「设置」→「一般」。
2. 「外观 → 语言」选中文 / English（立即生效）；「主题」选亮 / 暗；「主题色」点色块选一个颜色。
3. 看到什么算成功：界面文字与配色即看即变，不需要重启。

### 第 2 步：添加角色（欧服 Tranquility）
1. 左侧导航「角色」，空态点「登录 EVE 账号」，或网格末尾的「添加角色」卡。
2. 软件用默认浏览器打开 EVE 授权页；选好角色并确认授权。
3. 浏览器停在本地回调页，显示「授权成功」并提示可以关闭该页面返回应用。
4. 看到什么算成功：回到软件，卡片页自动出现新角色（头像、SP、ISK、技能队列）。
5. 浏览器没跳回来或弹「登录失败」：到「设置 → 测试 → 回环回调」点「检测」，按提示核对回调地址（见 [疑难排查](troubleshooting)）。

### 第 3 步：添加角色（国服 Serenity）
1. 「设置 → 一般 → 游戏服务器」切到 Serenity，弹「已切换游戏服务器」提示（无需重启）。
2. 「角色」页点「添加角色」→ 弹「新增国服玩家角色授权」四步向导：**登出**浏览器已登录的账号 → 打开网易授权页并选角色授权 → 把授权后空白页的**整条网址或 code** 粘进输入框 → 点「校验授权」。
3. 看到什么算成功：显示「校验授权成功，请点击关闭按钮完成授权」；点「关闭」后卡片页刷新出该角色。

### 第 4 步：设置游戏日志目录
1. 「设置 → 游戏日志」，在「游戏日志路径」粘贴 EVE 的 **logs 目录**完整路径（默认「文档\EVE\logs」；输入框没有浏览按钮，需自己在资源管理器定位后复制）。
2. 点输入框外任意位置即写入；「聊天频道文件有效天数」（默认 7）与「日志显示数量」（默认 100）先用默认值。
3. 看到什么算成功：频道预警 / 频道监控等页面能列出频道（前提是游戏里打开过频道）。

### 第 5 步：主页快捷方式
1. 在左侧导航任意条目上**右键 →「固定到主页」**；角色卡片右上角「⋯ → 固定到主页」同样有效。
2. 磁贴的添加 / 排序 / 宽窄切换统一在「设置 → 主页」编辑，上限 24 个。
3. 看到什么算成功：回到「主页」，「快捷方式」网格里出现磁贴，单击即打开对应功能。

### 第 6 步：托盘与关闭行为
1. 「设置 → 一般 → 外观」打开「关闭窗口时最小化到托盘」：关主窗口后程序驻留后台，从托盘图标恢复。
2. 若从受限目录（目录被打上低完整性标签）运行，托盘图标会被系统拒绝创建——表现为托盘没有图标、关窗口后程序直接退出（软件会退回"直接退出"，不会把窗口藏起来）。处置见 [疑难排查](troubleshooting)。

### 第 7 步：数据目录、配置与日志在哪
- **数据目录**（设置、登录令牌、各功能配置与缓存的根目录）：默认 `%LocalAppData%\TheGuideToTheNewEden\V4`（`V4` = 主版本 4.x）。「设置 → 一般 → 其他 → 数据目录」显示当前路径，可「打开 / 更改… / 恢复默认」；更改在下次启动生效。
- **配置文件**：`<数据目录>\Configs`（默认 `%LocalAppData%\TheGuideToTheNewEden\V4\Configs`）；主页「打开配置目录」直达，「数据目录 → 打开」打开的是它的上级目录。里面各文件的用途见下表。
- **软件日志**：固定写在 `%LocalAppData%\TheGuideToTheNewEden\Logs`（与数据目录无关），按日期一个 `.txt`；「设置 → 一般 → 其他」的「App日志」点「查看」直达，主页品牌条「打开日志」一样。
- **首次运行**：如果检测到旧版本留下的配置，会先弹「选择配置保存位置」：默认「使用新目录（推荐）」（可把旧配置与登录信息复制到 `V4`，不复制缓存），也可选「沿用旧目录（与旧版本共用）」。选一次后会记住。

## 常用位置速查 {#fields}

| 位置 | 里面有什么 | 怎么打开 |
|---|---|---|
| 数据目录（默认 `%LocalAppData%\TheGuideToTheNewEden\V4`） | 配置根目录；由**根目录**的 `datapath.json` 记录当前选择，可改为旧目录或自定义目录 | 「设置 → 一般 → 其他 → 数据目录」的路径与「打开」按钮 |
| 配置目录 `<数据目录>\Configs` | `settings.json`（设置）、`ESILicense.txt`（可选：开发/覆盖用；发布版通常已内置，第 2 行是回调地址）、`ESIScopes.txt`（权限勾选）、`Auth.json` / `Auth_Serenity.json`（两套服务器的角色授权）、`HomeShortcuts.json`（主页磁贴）、市场缓存目录（建筑 / 星域 / 历史） | 主页「打开配置目录」直达；「数据目录 → 打开」打开的是它的上级目录 |
| 软件日志 `%LocalAppData%\TheGuideToTheNewEden\Logs` | 按日期命名的 `.txt`，含启动、异常与托盘 / 授权的诊断行；多版本共用 | 「设置 → 一般」的「App日志 → 查看」；主页「打开日志」 |
| EVE 游戏日志 | EVE 自己写的日志；软件在其下 `Chatlogs`（聊天）与 `Gamelogs`（游戏日志）找文件 | 「设置 → 游戏日志」的「游戏日志路径」（默认「文档\EVE\logs」） |

## AI 能替你做什么 {#ai}
- 上述**设置与授权步骤大多没有可以直接代做的 AI 工具**：AI 不能替你点「更改…」选目录、完成浏览器授权或固定磁贴；但它可以读 / 改白名单内的配置文件（`config_read` / `config_write`，写入需确认、可回滚），例如日志路径、语言、主题、托盘等 `settings.json` 里已存在的非密钥键（部分设置需重启才完全生效）。
- AI 能帮你**核对第 2 / 3 步**：问「我登录了哪些角色」，`character_list` 列出**当前服务器**已登录的角色；一个都没有，说明该服务器还没添加过角色。
- 让 AI 用同一口径：问句带上口径词（「5% 均价」「最近一个月走势」「共几跳」），AI 的数字一律来自工具结果、查不到会明说（见 [术语与口径](concepts)）。
- **做不到**：读不到你的游戏日志正文；回环回调「检测」、重新授权这类动作也不能代点。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 点「添加角色」弹「登录失败」 | 授权没成功，且没有更具体原因可显示 | 重试；到「设置 → 测试 → 回环回调」点「检测」，确认监听成功且地址与 EVE 开发者后台登记一致 |
| 「无法监听授权回调地址 …（端口可能已被占用）」 | 回调端口被其它程序占用 | 关掉占用该端口的程序后重试 |
| 「当前游戏服务器不是国服（Serenity）：请先到"设置 → 一般"把服务器切换为国服，再进行国服授权。」 | 在非国服下走国服向导 | 先切服务器，再重新走向导 |
| 托盘没有图标，关窗口后程序直接退出 | 运行位置的完整性级别过低，系统拒绝创建托盘图标 | 复制到普通安装位置运行（见 [疑难排查](troubleshooting)） |
| 频道列表是空的 | 游戏日志路径不对，或游戏里没打开过频道 | 核对路径指向 EVE 的 logs 目录；进游戏打开一次目标频道 |
| 启动时先弹「选择配置保存位置」 | 检测到旧版本配置且还没有 `datapath.json`（新版本第一次运行） | 按推荐选「使用新目录」并勾选复制；选一次后会记住 |
| 数据目录已更改但本次运行没生效 | 数据目录设计为下次启动生效 | 按提示立即重启，或下次手动启动 |

## 限制与已知问题 {#limits}
- **「语言」卡片描述是旧文案**：界面仍写"修改语言后，需要重启应用程序"，实际语言切换已即时生效。
- **低完整性运行位置**（REFACTORING §8-62）：托盘图标、打开目录、写配置都可能被系统拒绝；表现与规避见 [疑难排查](troubleshooting)。
- **欧服授权只走本地回环**（§8 环境/协作注意）：回调地址必须与 EVE 开发者后台登记的 Callback URL 完全一致、不支持通配端口；旧的自定义协议 / 注册表通道已删除，不要按旧资料配置。
- **国服没有自动回调**（§8 计划内未做）：只能按向导手动粘贴网址 / code，不像国际服自动收回调。
- **设置默认不再与旧版 WinUI 共用**：4.0 起默认使用按大版本隔离的 `V4` 数据目录；只有首次运行或「数据目录 → 更改…」主动选「沿用旧目录」时才共用，冲突风险由你承担（REFACTORING 阶段 186）。
