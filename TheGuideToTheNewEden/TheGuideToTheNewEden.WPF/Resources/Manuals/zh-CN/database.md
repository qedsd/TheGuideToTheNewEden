# 数据库

## 一句话 {#tldr}
按名称或 ID 查本地 SDE 静态库（物品、分类、星系、星域、空间站与缓存 ID-名称），用来回答「这个 ID 是什么 / 这个名字对应哪个 ID」。AI 助手的名称搜索与本页同源。

## 在哪打开 {#where}
- 左侧导航「**数据库**」。
- 单张卡片：顶部是类型下拉 + 搜索框（占位「输入名称或 ID 搜索」）+ 右侧结果计数；中部为结果表格；底部是状态行（截断 / 失败提示）。

## 前置条件 {#prereq}
- 使用本地静态数据库（SDE），离线可用；数据库未就绪时搜索会在底部状态行报「搜索失败：」加具体原因。

## 操作步骤 {#steps}

### 搜索
1. 下拉选类型：**物品 / 分类 / 星系 / 星域 / 空间站 / 缓存ID名称**。
2. 输入名称片段做模糊匹配，或直接输入数字 ID 精确查询——ID 命中会置顶显示（已出现过的移到最前，不产生重复行）。
3. 输入即自动搜索（有短暂防抖），按回车立即搜索；搜索中显示「搜索中…」转圈，期间可继续输入。
4. 切换类型后会用当前关键词自动重查。
5. 「**缓存ID名称**」是软件积累的 ID→名称对照（含角色 / 军团 / 联盟等），适合反查一个 ID 对应的名字。

### 看结果
1. 表格列随所选类型自动生成（六种实体字段各不相同），列头为可读标题；文本列超长省略，数值列右对齐。
2. 列宽超出可视区时，用表格外层的横向滚动条查看。
3. 未搜索时中央显示引导文案；无命中显示「无匹配结果」。
4. 结果过多时只保留前一部分，底部状态行提示「结果过多，仅显示前 N 条，请细化关键词」。

## 字段与口径 {#fields}

| 类型 | 数据内容 | 说明 |
|---|---|---|
| 物品 | 物品类型表 | 名称、ID 与该表的全部字段列 |
| 分类 | 物品分组表 | 分组名 / ID 等 |
| 星系 | 星系表 | 名称、ID、安全等级等 |
| 星域 | 星域表 | 名称、ID 等 |
| 空间站 | 空间站表 | 名称、ID、所属星系等 |
| 缓存ID名称 | ID→名称对照缓存 | 含角色 / 军团 / 联盟等动态实体 |

## AI 能替你做什么 {#ai}
- 工具：`search_sde`（只读、离线、无需确认）——按名称片段搜物品 / 星系 / 星域 / 空间站 / 角色 / 军团 / 联盟，可限定类别（物品 / 星系 / 星域 / 空间站四档，不选则全查），返回名称、类别与 ID，单次最多 25 条。
- 推荐问法：「搜一下叫什么来着」「XX 在哪个星系」「把这个名字的 ID 查出来」。
- AI 与本页**走同一套本地静态库**，查到的名称 / ID 一致。
- **做不到**：AI 只拿到「名称 / 类别 / ID」三样，看不到本页的完整字段表格；单次最多 25 条、不能翻页；也不含市场行情（行情请用市场类工具）。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 搜索失败：{具体原因} | 本地静态库读取异常 | 按提示原因检查；持续失败请连同日志反馈 |
| 结果过多，仅显示前 N 条，请细化关键词 | 关键词太宽，命中过多 | 细化关键词，或先选类型缩小范围 |
| 无匹配结果 | 名称或 ID 没有命中 | 核对拼写；ID 只支持常规整数 |

## 限制与已知问题 {#limits}
- **结果截断**：底层搜索没有条数上限，页面统一只展示前几百条（当前为 500），避免一次渲染数万行。
- **ID 范围**：输入超出常规整数范围的数字时不会按 ID 精确查询（避免误查），只做名称匹配。
- **列随类型变化**：六种实体字段不同，表格列由数据自动生成。
- **离线数据**：只反映本地静态库的内容，不含游戏内的实时状态与价格。
