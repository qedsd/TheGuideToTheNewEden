# 商业 · 倒货 · 购物车

## 一句话 {#tldr}
把「分析推荐」里看中的候选收进一张清单：改价改量、实时看合计的本金 / 净利润 / 回报率，一键复制成游戏批量购买文本，成交后用游戏个人订单回填剩余数量，最后存一条购物记录。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**倒货**」→ 第 2 个页签「**购物车**」（壳页三个页签：倒货 / 购物车 / 记录）。
- 左侧是「**统计**」卡片：合计指标 + 底部三个图标按钮（复制 / 导入 / 保存，悬停显示名称）与最近一次操作的提示文字；右侧是明细表。
- 购物车与倒货页、记录页**共用同一份数据**：在倒货结果表右键「**添加到购物车**」的行会出现在这里（数量取该行的目标销量）。

## 前置条件 {#prereq}
- 纯本地功能：**不需要登录角色**，也不联网。
- 购物车内容**不落盘**：关闭软件即清空；要留底请点「**保存购物车列表**」。

## 操作步骤 {#steps}

### 编辑物品
1. 明细表**双击**一行，或选中后右键 →「**编辑**」：弹出独立小窗口，标题是物品名。
2. 窗口里改「**买入价格**」「**卖出价格**」「**数量**」：回报率(%) 与净利润**随输入实时回显**；点「**确定**」写回并刷新左侧统计，点「**取消**」不改动。
3. 选中一行或多行 → 右键 →「**删除**」直接移除。

### 复制为游戏批量购买订单
1. 点统计卡片下方的复制按钮：整张购物车被复制成每行「物品名 数量」的文本。
2. 到游戏里的批量购买界面粘贴即可；成功后提示「**已复制列表，在游戏批量购买界面粘贴即可**」。

### 从游戏个人订单导入并更新相关物品数量
1. 游戏里已买入一部分后，复制**个人订单**的「多件物品」列表。
2. 回来点导入按钮：应用按物品 ID 匹配购物车条目，用剩余数量**扣减**对应行的数量，扣到 0 的行自动移除。
3. 提示「**已更新 N 个物品**」或「**无物品需要更新**」。

### 保存购物车列表
1. 点保存按钮，把当前购物车整体存成一条购物记录（提示「**保存成功**」）；购物车为空时提示「**购物车为空**」。
2. 记录在「记录」页签查看、删除或加回购物车（见 [商业 · 倒货 · 记录](scalper/records)）。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 物品 | 条目对应的物品 | — |
| 回报率(%) | 单件利润率 | （卖出价格 − 买入价格）÷ 买入价格 × 100 |
| 净利润 | 这一行能赚的 ISK | （卖出价格 − 买入价格）× 数量 |
| 源市场买入价格 / 目的市场卖出价格 | 两个单价 | 加入时取自倒货分析结果，可编辑 |
| 数量 | 物品数量 | 可编辑；从倒货结果加入时 = 该行的目标销量 |
| 体积 | 该行总体积 | 数量 × 物品打包体积 |
| 统计 · 回报率(%) | 全车利润率 | 合计净利润 ÷ 合计本金 × 100 |
| 统计 · 净利润 / 本金 | 合计 | 净利润逐行相加；本金 = Σ（买入价格 × 数量） |
| 统计 · 体积 | 合计体积 | 逐行相加 |
| 统计 · ISK/跳、ISK/单位体积 | 效率参考 | 各行指标的**平均值**（不是总和）；跳数取自加入时两市场的跳数 |
| 统计 · 数量 | 购物车里的**物品种类数** | 不是物品件数 |

## AI 能替你做什么 {#ai}
- `shopping_cart`（**写操作，需要你确认**）：把物品加进购物车，或按物品名 / 行号移除；加入必填物品名与数量，买入 / 卖出单价、跳数可选。同一物品重复加入按**数量累加**，不产生重复行。它**不自己取价**——价格取自其它分析工具（如 `scalper_analyse`、`trade_spread`、`market_orders`）的结果。
- `build_buy_order_text`（只读）：把某角色 / 军团**被压单**的未结订单转成可粘贴的批量购买文本（每行「物品名 1」，与订单页「复制为游戏批量购买」同口径）——这是订单补货场景，**不是**购物车内容。
- `scalper_settings`（只读）：报出源市场、目的市场、目标物品数与取数线程。
- 推荐问法：「把三钛合金 100 万个加进购物车」「把这几样加进倒货购物车」。
- **做不到**：不能保存购物车记录、也不能从记录恢复；对已在车里的条目**不能只改价不加量**（调价必然同时累加数量）；也读不到页面上当前的统计值。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 未识别到物品订单 | 剪贴板内容不是游戏「多件物品」订单复制的格式 | 在游戏里复制个人订单的多件物品列表后再点导入 |
| 无物品需要更新 | 复制的订单里没有与购物车匹配的物品 | 属预期；确认复制的是同一批物品的订单 |
| 购物车为空 | 空车点了保存 | 先加入物品 |

## 限制与已知问题 {#limits}
- **内容不落盘**：购物车只存在内存里，关闭软件即清空；跨会话保留请先保存成记录。购物车为空时复制按钮不会动作（保存才有提示）。
- **复制 / 粘贴 / 保存与编辑对话框未做实机全量核验**（REFACTORING §8-20）：导入解析按游戏「多件物品」列表的复制格式假定，其它文本会得到「未识别到物品订单」。
- **统计区的 ISK/跳 与 ISK/单位体积是各行平均**：想看整车效率请按合计净利润与总体积自行折算。
- **明细表只支持排序 / 列宽 / 列重排等标准表格能力**；统计随明细实时刷新，编辑窗口点「确定」后立即生效，「取消」不留痕迹。
