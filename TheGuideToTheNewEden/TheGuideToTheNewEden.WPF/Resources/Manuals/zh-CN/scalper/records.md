# 商业 · 倒货 · 记录

## 一句话 {#tldr}
购物车每次「保存」留下的快照：左侧按文件列出历史记录，右侧看这一单的物品明细；旧记录可删除，明细可整批加回购物车再倒一轮。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**倒货**」→ 第 3 个页签「**记录**」。
- 左卡「**所有记录**」：记录文件列表，标题行右侧是「**删除选中**」按钮；右卡「**记录详细**」：选中记录的明细表，标题行右侧是「**添加选中到购物车**」按钮。
- 记录存在应用配置目录的 `Configs/ShoppingRecords/` 下，按保存时间命名（形如 `2026.09.11_1`），列表里显示的就是文件名。

## 前置条件 {#prereq}
- 本地功能，不需要登录角色。
- 列表为空通常只是还没在购物车点过「**保存购物车列表**」。

## 操作步骤 {#steps}

### 查看记录
1. 左列表点一条记录，右侧明细表随即加载该单的全部物品。
2. 明细列与购物车一致：物品 / 回报率(%) / 净利润 / 源市场买入价格 / 目的市场卖出价格 / 数量 / 体积。
3. 列表支持多选，但明细始终显示**选中那一条**的内容；正在查看的记录被删后，右侧明细随之清空。

### 删除记录
1. 左列表选中一条或多条 → 点「所有记录」右侧的「**删除选中**」。
2. 弹出确认框「**是否确认删除 N 个记录？**」，确定后删除、取消不动。

### 加回购物车
1. 右侧明细表选中要恢复的行（可多选）→ 点「记录详细」右侧的「**添加选中到购物车**」。
2. 加入购物车的是明细的**副本**：之后在购物车里改价改量都不会影响这条记录。
3. 想整单恢复就把明细全选后再加回。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 文件名 | 记录的显示名（按保存时间命名） | 一次「保存购物车列表」= 一个文件 |
| 物品 | 该单收录的物品 | 保存时刻购物车的快照 |
| 回报率(%) / 净利润 | 单行利润指标 | （卖出价 − 买入价）÷ 买入价 × 100；净利润 =（卖出价 − 买入价）× 数量 |
| 源市场买入价格 / 目的市场卖出价格 | 保存时的两个单价 | 原样存档，不随行情更新 |
| 数量 / 体积 | 保存时的数量与体积 | 体积 = 数量 × 物品打包体积 |

## AI 能替你做什么 {#ai}
- 本页**没有专属工具**：AI 不能列出、读取或删除记录文件。
- `shopping_cart`（**写操作，需要你确认**）可以往购物车加行——想让 AI「照某条记录重建购物车」，需要你把记录里的物品名与数量 / 价格告诉它，逐条写入；写入同样只在内存，关闭软件即清空。
- `scalper_settings`（只读）报倒货的源 / 目的市场等配置，与记录内容无关。
- **做不到**：不能替你点「添加选中到购物车」，也不能把记录文件恢复、转存或改名。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 是否确认删除 N 个记录？ | 删除前的确认框 | 确定删除 / 取消不动 |
| 明细表是空的 | 没选中记录，或该记录本身为空 | 先在左列表点一条记录 |
| 删除按钮点了没反应 | 左列表没有选中任何记录 | 先选中要删的记录 |
| 购物车里出现重复行 | 同一条记录加了两次（记录加回**不做合并**） | 在购物车里右键删除多余行 |

## 限制与已知问题 {#limits}
- **记录是快照**：保存后购物车与倒货设置的任何变化都不会回写记录，行情变化也不会更新记录里的价格。
- **加回购物车不做同物品合并**：与 AI 的 `shopping_cart` 工具（数量累加）行为不同，重复加回会产生重复行。
- **删除不可恢复**：记录是本地文件，没有回收站。
- **列表没有搜索 / 过滤**：记录多时只能滚动查找。
