# 小工具 · 键盘

## 一句话 {#tldr}
全局监听一个按键，按「时间间隔」或「按键次数」统计通过数，攒够目标次数数字变红；开始后窗口自动缩成小挂机条，配合默认置顶长期显示。

## 在哪打开 {#where}
- 左侧导航「**小工具**」→「**键盘**」：弹出**独立工具窗口**（透明外壳、默认置顶、屏幕居中打开）。
- 固定到主页后，点主页磁贴打开同一个窗口；同一工具同时只有一个窗口；关掉再开是全新实例。
- 窗口可以缩得很小（透明背板适合挂在屏幕角落）；缩到放不下时页面内滚动。

## 前置条件 {#prereq}
- 监听按键本身不需要登录角色。
- 「角色」下拉与「定位游戏窗口」需要 EVE 客户端在运行（复用多开模块的客户端发现）；找不到客户端时会有提示。

## 操作步骤 {#steps}

### 配置并开始
1. 「**按键**」填要监听的键名（如 `F1`；不区分大小写与首尾空格）。
2. 「**模式**」二选一：
   - **时间间隔**：填「间隔（秒）」——按一次该键开始计时，每满一个间隔记一次通过，再按一次结束；
   - **按键次数**：填「次数」——每按一次记一次通过，攒够目标次数后从 1 重新计。
3. 「**角色**」下拉选一个客户端，或点刷新按钮重新查找；「**定位游戏窗口**」按钮把该窗口前置（会先还原最小化）。
4. 点「**开始**」：窗口自动缩成迷你挂机条——只有居中的大号「通过数 / 目标数」和底部一行「时长 │ 累计按键次数」，右侧红色停止按钮。
5. 通过数的颜色随状态变化，攒够目标次数后变红。
6. 点停止结束：窗口恢复开始前的尺寸并回到不透明（若你运行期间自己拉大过窗口，则保持你的尺寸）。

### 运行中调节
- 鼠标移入窗口会出现「**窗口透明度**」滑条，拖动即调窗口背板的透明度；移开自动隐藏。
- 透明度只在**运行态**生效：开始时按滑条值生效，停止后恢复不透明；设置态拖滑条没有效果。

## 字段与口径 {#fields}

| 显示 | 含义 | 口径 |
|---|---|---|
| 通过数 / 目标数 | 已记的通过次数与目标次数 | 时间间隔模式按间隔累计；次数模式按实际按键累计 |
| 时长 | 本次开始至今的运行时长 | 悬停有说明 |
| 累计按键次数 | 监听键被按下的总次数 | 含 Alt 等组合键里的该键；方向键 / 小键盘等扩展键按扩展位正确识别 |

## AI 能替你做什么 {#ai}
- **做不到**：没有对应的 AI 工具。AI 不能开始 / 停止监听、改参数，也读不到计数结果——这些都要在窗口里手动完成。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先填写要监听的按键（例如 F1） | 按键名为空 | 填键名再开始 |
| 目标次数需大于 0 | 次数模式参数非法 | 改成大于 0 的整数 |
| 间隔需大于 0 秒 | 间隔模式参数非法 | 改成大于 0 的秒数 |
| 未找到 EVE 客户端窗口 | 没有运行中的客户端，或进程关键词不匹配 | 启动客户端；检查多开设置的进程关键词；点刷新 |
| 未能前置该窗口 | 激活窗口失败 | 手动切换到游戏窗口 |

## 限制与已知问题 {#limits}
- 监听是**全局**的：游戏里、别的程序里按这个键都计数；不用时请停止或关窗（关窗即卸载监听）。
- 输入框内置取值范围：目标次数最多一万，间隔最多六百秒。
- 时间间隔模式的「通过」是按间隔累计的，不代表实际按键次数；实际按键数看「累计按键次数」。
- 自动缩成迷你条前的窗口尺寸只在"你没动过窗口"时恢复；运行期间手动调过的尺寸会被尊重。
- 透明度作用于窗口背板（背景半透明、文字按钮保持实色），而不是整个窗口变淡。
