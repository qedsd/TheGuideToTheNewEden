# 小工具 · 游戏延迟

## 一句话 {#tldr}
对 EVE 服务器做 TCP 连接测速：看当前 / 平均延迟与丢包率的档位，统计总次数与时长；窗口可缩成迷你挂机条，默认置顶长期监控。

## 在哪打开 {#where}
- 左侧导航「**小工具**」→「**游戏延迟**」：弹出**独立工具窗口**（透明外壳、默认置顶、屏幕居中打开；可以拉大也可以缩小）。
- 固定到主页后，点主页磁贴打开同一个窗口；同一工具同时只有一个窗口；关掉再开统计清零。
- 完整布局的标题栏有最小化与关闭；缩成迷你后标题栏自动收得只剩关闭。

## 前置条件 {#prereq}
- 不需要登录角色，能连上目标服务器即可。
- 预设了欧服与国服地址，端口默认是 EVE 客户端的 TCP 端口（26000），一般不用改。

## 操作步骤 {#steps}

### 完整布局测速
1. 「选择服务器」下拉可编辑：选欧服 / 国服预设，或直接输入任意主机名 / IP，右侧填端口。
2. 点「**开始测试**」：每秒对 host:port 做一次 TCP 连接；运行中地址与端口被锁定，先停止才能改。
3. 三个指标卡实时刷新：**当前延迟**（最近一次）、**平均延迟**、**丢包率**，各带颜色圆点与档位文字（极佳 / 良好 / 正常 / 较差 / 糟糕）。
4. 「**测试统计**」卡显示总测试次数 / 成功次数 / 失败次数 / 测试时长。
5. 底部一行是口径说明（每秒一次 TCP 连接测速）。

### 迷你挂机条
1. 点「**迷你**」按钮（或直接把窗口缩小到较小尺寸）：切换成迷你形态——标题栏收得只剩关闭按钮，只剩监控所需的信息。
2. 迷你形态三态互斥：未开始只显示 ▶ 开始；运行中且鼠标不在窗口内只显示延迟读数（**数字颜色即档位**）；运行中鼠标在窗口内显示 ■ 停止按钮与「**窗口透明度**」滑条。
3. 滑条调的是**窗口背板**的透明度（背景半透明、文字与按钮保持实色）；只在迷你形态生效，拉回完整布局恢复不透明（滑条值会记住）。
4. 把窗口拉大即回到完整布局，标题栏按钮恢复。

## 字段与口径 {#fields}

| 指标 | 含义 | 档位口径 |
|---|---|---|
| 当前延迟 | 最近一次成功连接的往返时间（ms） | 100 以内极佳、150 以内良好、250 以内正常、300 以内较差、以上糟糕 |
| 平均延迟 | 成功连接延迟的平均值 | 同上；成功次数为 0 时显示 `--` |
| 丢包率 | 失败（超时 / 连不上）次数占比（%） | 0 极佳、1% 以内良好、2% 以内正常、10% 以内较差、以上糟糕 |
| 测试统计 | 总次数 / 成功 / 失败 / 时长 | 失败按丢包计 |
| 无数据 | `--` | 尚未开始或尚无成功样本 |

## AI 能替你做什么 {#ai}
- 工具：`server_ping`——多采样 TCPing，返回平均 / 最低 / 最高延迟、丢包率与档位；不填主机时欧服与国服各测一次，采样次数默认 5 次（上限 10 次）。
- 推荐问法：「现在欧服卡不卡」「国服和欧服哪个延迟最低」「帮我测一下某服务器的丢包」。
- **做不到**：不能替你优化网络、修改路由，也控制不了测速窗口本身；延迟只反映到登录服务器的网络质量，不代表游戏内体验。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先填写服务器地址 | 地址为空就点了开始 | 填主机名或选预设 |
| 端口无效（应为 1-65535） | 端口超出范围 | 改回 26000 或其它合法端口 |
| 丢包率 100 / 延迟显示 `--` | 连不上（网络不通、被防火墙拦截、服务器不可达） | 换预设地址对比；检查本机网络 |

## 限制与已知问题 {#limits}
- 这是 TCP 连接测速，不是游戏内 ping：反映的是到服务器的连接质量，不代表帧率或游戏内手感。
- 单次连不上要等连接超时才计为丢包，所以丢包多的地址测速节奏会明显变慢。
- 迷你形态下置顶图钉也被收起，但窗口**仍是置顶**的；要取消置顶先拉回完整布局。
- 迷你 / 完整由窗口尺寸驱动（小到阈值自动切，拉大自动还原），没有额外开关。
- 透明度只作用于迷你形态的背板；完整布局始终是实心窗口。
- 关闭窗口重开是全新实例：统计与运行状态清零。
