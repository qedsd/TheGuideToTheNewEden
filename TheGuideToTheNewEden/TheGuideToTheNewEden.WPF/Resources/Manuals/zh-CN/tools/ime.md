# 小工具 · 快捷输入

## 一句话 {#tldr}
一边打字一边给 EVE 专有名词候选：按标点与空格取"光标所在的那个词"，实时给出游戏名称建议，点一下就替换；整段内容还能送去搜索或翻译。

## 在哪打开 {#where}
- 左侧导航「**小工具**」→「**快捷输入**」：弹出**独立工具窗口**（主窗口内容区不变，左侧导航的选中项也不停在工具上）。
- 固定到主页后，点主页磁贴打开同一个窗口；同一工具同时只有一个窗口，重复点只是激活它；关掉再开是全新实例。
- 窗口默认**置顶**（标题栏有图钉开关）、在屏幕居中打开；窗口可以缩小（有通用最小尺寸），缩到内容放不下时页面内滚动，不会裁掉内容。

## 前置条件 {#prereq}
- 名称建议与「搜索」走本地 SDE 数据库，不需要登录角色。
- 「翻译」：在「设置 → AI」配置了 AI 翻译源就用 AI（支持整句）；没配置则自动退回本地词库源，只认 SDE 专有名词。
- 两者都拿不到结果时，详情区会显示对应提示文案。

## 操作步骤 {#steps}

### 输入与联想
1. 在输入框输入或粘贴内容（支持多行）：应用按标点与空格分词，取光标所在的那个词去查游戏名称（角色 / 军团 / 联盟 / 物品 / 分组 / 星系 / 星域）。
2. 建议单行排列在输入框下方，最多 6 条；点建议即把**当前这个词**替换成候选名称。
3. 换词或继续输入会实时刷新建议；没有命中的词就不出建议。
4. 完整分词规则在输入框的悬停提示里。

### 复制 / 搜索 / 翻译
1. 「**复制**」把整段输入送进剪贴板，成功有「已复制到剪贴板」提示。
2. 「**搜索**」把结果放进详情区：逐行列出匹配项（名称 + 类别 + ID），查不到显示「无结果」。
3. 「**翻译**」把译文放进详情区：AI 源返回整句译文（可能附模型 / 缓存等补充信息），本地词库源逐行给「原文 → 译文」；中文输入翻成英文、英文输入翻成中文。
4. 输入框里有选中内容时，搜索 / 翻译只处理选中的那部分。
5. 详情区是只读富文本，可拖选复制；右下角返回按钮回到输入区。

## AI 能替你做什么 {#ai}
- 「翻译」按钮内部就用 AI 翻译源（在「设置 → AI」配置），与翻译页同一套服务商与术语表规则。
- **做不到**：AI 助手不能操作这个窗口——不能替你输入、点建议或替换文字；建议与「搜索」走的是本地 SDE 而不是 AI。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 无结果 | 本地库没有匹配，或翻译源没有返回条目 | 换关键词；专有名词用完整名称 |
| 翻译失败：{0} | AI 源请求失败或超时 | 检查「设置 → AI」的服务商配置与网络 |
| 没有可翻译的内容（AI 源没有返回译文） | AI 源成功但没有译文输出 | 重试；长句可拆短再试 |
| 建议一直不出现 | 光标不在词上，或词是纯数字等不取词形态 | 把光标移到词中间，或换个写法 |

## 限制与已知问题 {#limits}
- 建议与「搜索」只覆盖本地 SDE 里已有的名词；玩家 / 军团 / 联盟名同样只有库里有的才给得出。
- 搜索按类别逐个容错：某一类数据库没载入不会让整次搜索失败，但对应类别的结果会缺席。
- 输入框的占位提示是刻意的一行短句（控件占位符不换行），完整规则放在悬停提示里。
- 窗口缩到最小时内容自动填满、放不下才滚动，不会被裁掉。
