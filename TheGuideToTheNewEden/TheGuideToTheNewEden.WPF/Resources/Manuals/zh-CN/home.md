# 主页

## 一句话 {#tldr}
把常用功能固定成磁贴，点一下就打开；下方挂「我的钱包」「我的行情」两张速览卡，品牌条的快捷输入框能直跳物品价格 / KB / 星系，复杂问题自动转 AI 助手。

## 在哪打开 {#where}
- 左侧导航第一项「**主页**」（普通页面，在主窗口内容区显示，不是独立工具窗口）。
- 页面自上而下三块：
  - **品牌 / 状态条**：应用名与版本号、在线人数与游戏时间胶囊；右侧是快捷输入框和一排按钮：使用手册、关于、打开日志、打开配置目录、GitHub、QQ 群。检查到新版本时会出现胶囊提示，点击前往「设置 → 软件更新」。
  - **快捷方式**：磁贴网格，标题旁显示「共 n 个 · 上限 24」。
  - **我的钱包 / 我的行情**：两张数据卡并排显示（行情卡固定在右侧）。
- 磁贴的添加 / 排序 / 宽窄切换**不在主页**：唯一编辑入口是「**设置 → 主页**」；也可以在左侧导航任意条目上右键选「**固定到主页**」。

## 前置条件 {#prereq}
- 磁贴本身无需任何条件；一块都没有时卡片内会显示引导文案。
- 「我的钱包」需要已添加角色（ESI 授权）；没有角色时显示引导和「去添加角色」按钮。
- 「我的行情」来自「市场」页收藏（星标）的物品；收藏为空时显示引导。
- 「最近使用」默认关闭，在「设置 → 主页」里打开。

## 操作步骤 {#steps}

### 点磁贴打开功能
1. 磁贴单击即打开：功能页进主窗口内容区，小工具弹独立工具窗口。
2. 小磁贴是居中图标 + 名称，宽磁贴是左图标 + 名称与副标题；参数化磁贴（某个物品 / 星系 / 角色）显示固定时写好的显示名。
3. 部分磁贴右上角有小圆点角标：表示该功能正在运行或有内容，悬停看说明（如「××有 2 个在运行」）。
4. 打开「最近使用」后，磁贴上方会把最近打开过的功能排成一行胶囊，点它等于点对应磁贴；右侧橡皮擦按钮清空记录。

### 快捷输入直达
1. 在品牌条输入框里输入，回车或点发送按钮：
   - 物品价格（如「巨神兵级价格」）→ 打开市场页并选中该物品；
   - KB（如「某某的KB」）→ 打开该实体的统计；
   - 星系定位（如「定位吉他」）→ 定位星图；
   - 角色全名 → 打开角色工作区。
2. 唯一命中才跳转（右下角有结果提示）；查不到、命中多个或复杂问题，会自动转给 AI 助手并代发提问。
3. 转助手的提问会**新开一个对话**（不续在旧对话里），默认显示在独立的助手窗口。

### 看钱包卡
1. 头部下拉切换统计区间（近 7 天 / 近 30 天 / 全部），改动即保存。
2. 卡内显示总余额、收入 / 支出与两张构成表（分类见下），底部一行是统计口径。
3. 右上角刷新按钮**绕过全部缓存**重取；平时自动装载走缓存。

### 看行情卡
1. 每张小卡显示收藏物品的最近一日历史均价、涨跌与销量（口径见卡底说明）。
2. 点小卡跳到市场页并选中该物品，看实时订单。
3. 收藏多于 6 个时其余显示为「还有 n 个」。

## 字段与口径 {#fields}

| 元素 | 含义 | 口径 |
|---|---|---|
| 总余额 | 全部已添加角色的钱包余额合计 | 汇总缓存约 5 分钟；「刷新」绕过缓存 |
| 收入 / 支出 | 区间内 ESI 钱包流水的分类合计 | 每角色最多统计最近 400 条流水 |
| 收支构成 | 贸易 / 任务 / 赏金 / 合同 / 转账 / 税 / 其他 | ESI 流水按类型归并；占比条按金额比例 |
| 行情小卡 | 收藏物品的最近一日历史均价与销量 | 历史统计走磁盘缓存，不是实时订单 |
| 状态角标 | 预警 / 监控 / 多开 / 击杀流 / 收藏的运行态 | 只在主页可见期间刷新 |
| 在线人数 / 游戏时间 | EVE 服务器在线人数与 UTC 游戏时间 | 来自 ESI 公开接口 |

## AI 能替你做什么 {#ai}
- 快捷输入的复杂问题会转给 AI 助手（新开对话、自动发送）；助手也可以用导航类工具打开与磁贴等价的页面（如 `market_navigate` / `character_navigate`）。
- **做不到**：AI 不能固定 / 移除磁贴、改卡片显示开关、清空最近使用或编辑快捷方式——这些都在「设置 → 主页」手工操作。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 还没有登录角色。添加角色后，这里会显示总余额与收支构成。 | 未添加角色 | 点「去添加角色」 |
| 所有角色都取数失败（可能是令牌失效或网络问题），稍后点右上角刷新重试。 | 钱包取数全部失败 | 稍后刷新；必要时重新授权角色 |
| {0} 个角色取数失败（已跳过） | 部分角色失败（逐角色容错） | 其余角色照常显示；失败角色稍后刷新 |
| 区间内没有钱包流水：角色长期未登录时 ESI 流水保留窗口（约 90 天）已过期，余额仍为实时值。 | 流水窗口已过 | 正常现象，余额不受影响 |
| 还没有收藏物品。在「市场」页点物品的星标，它就会出现在这里。 | 行情卡没有数据来源 | 去市场页给物品点星标 |
| 最多固定 24 个功能，请先移除一些再添加 | 磁贴达到上限 | 在「设置 → 主页」移除一些 |
| 找不到使用手册文件：{0} | 手册 PDF 缺失 | 按提示的路径检查程序目录 |

## 限制与已知问题 {#limits}
- 主页磁贴只有「点击打开」一种交互：增删 / 拖动排序 / 宽窄切换 / 恢复默认都在「设置 → 主页」，主页上的编辑模式与「⋯」菜单已按用户要求移除。
- 参数化磁贴只支持三类目标（物品 / 星系 / 角色）；创建入口在市场页物品头的图钉、星图顶栏的图钉（需先选中星系）与角色卡片的「⋯」菜单。
- 「最近使用」关闭期间不记录历史，重新打开后要等新使用才有内容。
- 行情卡是速览口径（最近一日历史均价与销量，伏尔戈）；实时订单点小卡去市场页看。
- ESI 钱包流水只保留约 90 天窗口，长期未登录的角色在旧区间里没有流水（余额不受影响）。
- 快捷方式与卡片开关保存在 `Configs/HomeShortcuts.json`，上限 24 个；被固定的功能若从程序里消失，加载时会自动丢弃。
