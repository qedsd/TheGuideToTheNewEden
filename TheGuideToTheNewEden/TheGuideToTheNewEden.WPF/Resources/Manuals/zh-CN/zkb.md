# Zkillboard

## 一句话 {#tldr}
订阅 zkillboard 的实时击杀流（KB流），用排除 / 包含名单过滤出关心的击杀，并查看任意角色 / 军团 / 联盟 / 舰船 / 星系的战斗统计与单条击杀详情。

## 在哪打开 {#where}
- 左侧导航「**Zkillboard**」。
- 页面是一个多标签宿主：「**KB流**」标签固定在最左；打开过的实体统计与 KB 详情各占一个标签，可关闭、可同时开多个。
- 标签行右端是常驻搜索框（占位「搜索角色、军团、联盟…」），输入即弹出结果下拉。
- 击杀流的设置不占页面：点卡片底部的「**设置**」以独立弹窗打开。

## 前置条件 {#prereq}
- 全部数据来自 zkillboard 第三方服务，**不需要登录 EVE 角色**；网络不通或服务限流时取不到数据。
- 击杀流连接配置存放在软件配置目录的 `ZKBStreamConfig.json`；「自动接收KB流」开启时会自动连接，无需手动点「连接」。

## 操作步骤 {#steps}

### 连接与接收
1. 未连接时内容区显示「未连接ZKB服务器，可以点击下方按钮连接服务器」，点底部「**连接**」。
2. 连接期间显示「连接服务器中...」；成功后卡片标题旁出现绿色状态点，右上角显示「过滤后 / 总数」两个计数（悬停见「过滤后KB数量」「总KB数量」）。
3. 通过过滤的新击杀进入「**筛选KB**」页签；被拦下的进入「**已过滤KB**」页签，可切换对照。
4. 底部按钮依次是：连接 / 断开 / 清除 / 设置。「**清除**」清空已收到的两个列表。

### 配置过滤
1. 点底部「**设置**」打开设置弹窗（重复点击只激活同一个窗口）。
2. 「**过滤**」页签分「**位置** / **舰船** / **受害者** / **攻击者**」四个子页签。每个子页签先选模式：
   - **不过滤**：该维度不限制；
   - **只保留匹配**：只保留列表内的击杀；
   - **排除匹配**：丢弃列表内的击杀。
   再在下方列表添加实体：位置可选星系 / 星域，受害者 / 攻击者选角色 / 军团 / 联盟。
   舰船使用分类树：**舰船 → 分组（护卫舰 / 巡洋舰等）→ MetaGroup（势力 / 科技 II 等）→ 具体舰船**。勾选任意父节点，会自动把它下面所有具体舰船 TypeID 加入过滤列表；仍可单独勾选具体舰船。配置里保存的是具体 TypeID。
   上方搜索框按舰船名称过滤；右侧列出所有已选具体舰船，可逐条删除；删除后对应父节点会自动变成半选/未选。
3. 规则：列表为空时不限制；同一列表内实体是 **OR**；四个子页签之间是 **AND**；位置里的星系与星域也是 OR；受害者身份（角色 / 军团 / 联盟）是 OR；攻击者只要任一名命中即可。例如「位置：只保留 Delve」+「攻击者：排除 Goonswarm」= Delve 内、攻击者不含 Goonswarm 的击杀。
4. 修改过滤即时生效，**不需要断开重连**；对之后收到的击杀生效。

### 收系统通知
1. 设置弹窗「通用」页签打开「**击杀系统通知**」；「**击杀通知最小价值**」设为 0 表示全部通知，否则只通知高于该价值的击杀。
2. 点系统通知会打开对应的 KB 详情标签并拉回主窗口。

### 搜索并打开实体统计
1. 右上角搜索框输入名称，下拉结果为「名称 + 类别」列表。
2. 点击结果打开该实体的统计标签；实体名解析完成后标签标题会自动更新。

### 看列表与详情
1. KB 列表的列：时间（本地时间，两行显示时刻与日期）、估价、飞船/建筑（图标 + 舰船名 + 舰船组）、位置（星系与安全等级 / 星域）、受害者（身份图 + 势力徽标 + 名称 / 势力名）、最后一击（同受害者格式，名称后附参与者人数）。
2. **单击行**打开 KB 详情；点行内的实体名（舰船 / 星系 / 星域 / 受害者 / 最后一击等）跳到对应实体统计；右键「**浏览器查看**」用系统浏览器打开该击杀的 zkillboard 页面。
3. KB 详情页：头部是受害者身份图与舰船图、名称与归属链接（角色 / 军团 / 联盟 / 舰船 / 星系 / 星域均可点击）以及价值面板（掉落 / 损毁 / 装配 / 总价、参与者人数、总伤害）；下方是「**攻击者**」「**货柜**」两个表；底部「**复制链接**」「**浏览器打开**」。

## 字段与口径 {#fields}

| 字段 | 含义 | 口径 |
|---|---|---|
| 估价（列表） | 单条击杀的总价值 | zkillboard 估价，按数值量级缩写显示 |
| 位置 | 星系 + 安全等级 / 星域 | 两行显示，均链接到对应实体统计 |
| 最后一击 (N) | 最后一击者名称后括号里的人数 | 该击杀的攻击者总数 |
| 掉落 / 损毁 / 装配 / 总价 | 详情页价值面板 | zkillboard 估算的 ISK 价值 |
| 筛选KB / 已过滤KB | 通过过滤 / 被过滤拦下 | 划分依据 = 设置弹窗里的过滤规则 |
| 最大显示KB数 | 击杀流列表的保留上限 | 列表最多保留该数量的条目 |

## AI 能替你做什么 {#ai}
- 工具：`zkb_entity`（只读、无需确认）——查角色 / 军团 / 联盟的危险系数（0–100）、抱团概率、击杀与损失次数、ISK 击毁与损失、单挑战绩，并附击杀/损失比与 ISK 效率；同名多实体时列出候选请你确认，不擅自选。
- 推荐问法：「XX 危险吗」「这个军团能打吗」「查一下 YY 的 ZKB 战绩」。
- **做不到**：不能替你连接 / 断开击杀流、修改过滤与通知设置、打开页面标签；也拿不到击杀流列表与单条 KB 详情（那些只能在页面上看）。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 未连接ZKB服务器，可以点击下方按钮连接服务器 | 尚未连接 | 点「连接」，或在设置弹窗开启「自动接收KB流」 |
| 连接服务器中... 迟迟不结束 | 网络不通或 zkillboard 不可达 | 检查网络后断开重连 |
| 未找到匹配的实体 | 搜索词没有命中 | 换更完整的实体名再搜 |
| 该类型不支持 ZKB 查询 | 所选类别没有 ZKB 统计 | 改搜角色 / 军团 / 联盟等有统计的实体 |
| 查询失败，详情请查看日志 | 网络异常、被限流或服务端错误 | 稍后重试；连续高频查询容易触发限流 |

## 限制与已知问题 {#limits}
- **通知点击是"最近一条获胜"**：系统通知的点击回调不区分具体条目，多条通知堆叠时点旧通知打开的也是最近一次通知对应的 KB 详情。
- **统计口径来自 zkillboard 服务端**：危险系数、抱团概率等数值直接取服务端返回，本地不二次计算；同一实体两次查询的数值可能不同（第三方按周期归零或波动）。
- **实体统计有短时内存缓存（约 2 分钟）**：刚查过的数字短时间内不变；AI 工具可用参数跳过缓存重新拉取。
- **列表顺序与上限**：击杀流按「列表显示顺序」（上传时间 / 发生时间）排序，最多保留「最大显示KB数」条。
- **高频查询可能被 zkillboard 限流**：表现为查询失败或明显变慢，稍等即可恢复；正常使用频率一般不会触发。
- **排序与筛选口径**沿用既有约定：「分类统计」按击杀数降序等细节见 [Zkillboard · 实体统计](zkb/entity)。
