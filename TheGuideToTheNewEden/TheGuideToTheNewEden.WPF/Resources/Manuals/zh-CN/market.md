# 商业 · 市场

## 一句话 {#tldr}
查某个物品在**指定市场**（星域 / 星系 / 建筑）的实时卖单与买单、历史成交与价格走势，并估算买入 / 卖出的成本与收入。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**市场**」。
- 页面分左右两栏：左栏是市场选择按钮 +「**列表** / **收藏**」两个页签（列表内含物品搜索框与市场分组树）；右栏是物品头 +「**卖单** / **买单** / **历史**」三个页签。
- 物品头的「**简介**」「**买入**」会打开**独立的工具窗口**（可置顶、可 Alt+Tab 切换，重复点击只会激活同一个窗口）。

## 前置条件 {#prereq}
- **星域 / 星系市场不需要登录**（订单走匿名 ESI 接口），没有角色也能查价。
- **建筑市场需要**：① 该建筑已加入「设置 → 玩家建筑」；② 有可用角色，且该角色对这座建筑**有市场访问权**（授权范围含 `esi-markets.structure_markets.v1`）。两者缺一，订单会取不到并给出提示。
- 历史统计走**本地磁盘缓存**（缓存时长取「设置 → 市场」的订单设置），首次查看某个物品的历史会稍慢，之后命中缓存。

## 操作步骤 {#steps}

### 选市场
1. 点左栏顶部的市场按钮（未选择时显示「未选择市场」，默认常为「伏尔戈」）。
2. 弹层有三个页签：**星域 / 星系 / 建筑**；各有搜索框，输入关键字后点选目标。
   - 建筑页签的列表**每次展开都重新读取**本地的玩家建筑列表，所以在「设置 → 玩家建筑」里增删建筑后不需要重开页面。
   - 建筑列表为空时页签内会显示引导文案（先去设置里添加建筑）。
3. 选中后弹层自动收起，按钮显示所选市场名。

### 查一个物品
1. 左栏「**列表**」页签：在「搜索市场物品」框里输入名称（如「巨神兵级」），或直接展开市场分组树逐级点选。
2. 点中物品后，右栏物品头显示图标、名称与统计，卖单 / 买单表开始加载（加载中状态显示「获取订单中...」）。
3. 已收藏的物品可以在「**收藏**」页签里快速取用；收藏按钮是物品头上的**星标**（「添加收藏 / 取消收藏」），收藏结果写进 `Configs/StaredMarketInvType.json`。

### 看订单与统计
1. 物品头第一行显示该物品的**卖单**与**买单**统计：`5%`（前 5% 订单均价）、`平均`（全部订单均价）、`数量`（订单条数）。
2. 「**卖单**」表按价格**升序**（最便宜的在最上面），「**买单**」表按价格**降序**。
3. 表格列见下方「字段与口径」；列宽超出可视区时用**表格下方 / 外层的滚动条**横向查看，右侧列（如过期时间、位置）不会被裁掉。

### 看历史与走势
1. 切到「**历史**」页签：顶部一行是区间指标（最低价 / 最高价 / 均价 / 累计成交 / 区间涨跌 / 价差）。
2. 图表有**价格**与**销量**两类；价格图可在「**高/低/平均**」（三条线）与「**箱体**」两种显示模式间切换。
3. 右上角时间范围：**最近 1 个月 / 最近 3 个月 / 最近半年 / 最近一年 / 全部**（默认最近 3 个月）。
4. 把鼠标停在图上会显示该点的详细数值。

### 估算买入成本 / 卖出收入
1. 点物品头的「**买入**」→ 打开计算器窗口。
2. 填「数量」，可选「**按实际数量计算价格**」（按逐档吃单算出真实成交均价，而不是只看最低价）。
3. 窗口实时显示「**买入价格** / **总花费**」与「**卖出价格** / **总收入**」，并可按「**销售税（%）**」「**中介税（%）**」估算税费；点「**立即卖出**」按当前最高买价计算卖出侧。
4. 「**计算明细**」逐档列出吃单过程。
5. 若卖单数量不足，会提示「卖单无法满足数量，剩余数量按卖单最低价格计算」。

### 刷新
- 物品头「**刷新**」重新取当前物品：**订单是实时的**（不缓存），**历史会强制刷新**磁盘缓存。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 价格 | 单个订单的单价 | 卖单升序、买单降序展示 |
| 数量 | 该下单的数量 | 原样显示 |
| 位置 | 下单地点（空间站 / 建筑名） | 本地数据库解析；**建筑名只查本地玩家建筑列表**，解析不到时显示原始 ID |
| 星系 / 安全等级 | 该位置所在星系与安等 | 建筑订单不含星系，按该建筑所在星系补齐 |
| 范围 | 订单可覆盖范围 | 原样显示 |
| 过期时间 | 订单剩余有效时间 | 形如 `dd.hh:mm:ss`（天数.时:分:秒） |
| 5%（卖单 / 买单） | 前 5% 订单的价格平均值 | 卖单取最便宜的 5%、买单取最贵的 5%；不足 2 条时取首条 |
| 平均 | 全部订单的算术平均价 | 卖单与买单各自计算 |
| 数量（统计） | 订单**条数**，不是物品数量 | — |
| 最小数量 | 计算器里的吃单下限 | 与游戏内「最小数量」一致的过滤条件 |
| 体积 | 物品单位体积 | 打包体积优先，缺省回落普通体积 |
| 区间指标 | 历史区间的低 / 高 / 均价、累计成交、涨跌、价差 | 由历史统计接口数据算出，区间 = 所选时间范围 |
| 箱体 | 按时间桶聚合成开高低收的箱体图 | 与「高/低/平均」线二选一显示 |

## AI 能替你做什么 {#ai}
- 工具：`market_orders`（实时卖单 / 买单 + 5% 均价 + 条数）、`market_history`（区间高 / 低 / 均价 + 现价分位 + 销量方向）、`market_trend`（实时最低卖 / 最高买 + 历史分位 / 销量方向）、`market_navigate`（跳到市场页并选中物品）、`market_favorite`（收藏 / 取消收藏，**写操作，需要你确认**）。
- 推荐问法：「巨神兵级在吉他多少钱」「因卡萨斯级最近一个月走势怎么样」「伏尔戈 XX 的 5% 均价是多少」「帮我把 XX 收藏起来」。
- **做不到**：不能替你在游戏里下单、改单或撤单；也读不到你游戏内的挂单（那属于「商业 → 订单」）。
- AI 回答里的价格一律来自上面的工具，**不要采信对话里的旧价格**。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 建筑订单获取失败：需要角色授权，且该角色对该建筑有市场访问权限 | 没有角色，或授权里没有建筑市场权限，或该角色无此建筑访问权 | 确认「设置 → 玩家建筑」里有这座建筑；确认已登录角色且授权角色对该建筑有市场访问权；否则改用星域市场 |
| 未选择市场 | 还没有选市场 | 点市场按钮选星域 / 星系 / 建筑 |
| 获取订单中... 一直不结束 | 该物品订单量很大，或建筑订单在整栋拉取 | 等待（建筑订单首次会很慢）；必要时换星域市场 |
| 获取历史记录中... 很慢 | 历史未命中缓存 | 首次会写入缓存，之后变快；可在「设置 → 市场」调整缓存时长 |
| 添加收藏失败 / 取消收藏失败 | 写 `Configs/StaredMarketInvType.json` 失败 | 检查配置目录可写（低完整性进程可能被拒绝），或换普通安装位置运行 |

## 限制与已知问题 {#limits}
- **建筑（结构）市场**：建筑订单是**整栋建筑全量拉取**（公共市场建筑可达数 MB），按缓存时长缓存，首次明显较慢；再点「刷新」会重新拉取。「历史」用的其实是**该建筑所在星域**的历史（与旧版一致）。
- **星域市场不合并建筑卖单**：星域视图只包含星域接口返回的订单，不会把该星域各建筑的订单合并进来。
- **表格未按安全等级着色**：安全等级列是普通数字（旧版有按安等上色）。
- **市场物品树的选中态**是 WPF 默认样式；左侧列表未做逐项自定义外观。
- **物品树是一次性全量构建**：首次进入市场页会短暂耗时（与旧版相同），节点按名称排序。
- **刷新语义**：星域订单实时（无缓存）；历史统计按「设置 → 市场」的缓存时长走磁盘缓存，「刷新」会强制刷新历史。
- **PLEX（类型 44992）**会自动切到全球星域。
- 物品「简介」里的 HTML 标签会被剥离后显示（离线与可读性取向），正文中的图片不加载。
