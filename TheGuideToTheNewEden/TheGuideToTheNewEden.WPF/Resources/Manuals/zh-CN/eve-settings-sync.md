# 配置同步

## 一句话 {#tldr}
把某个角色（或账户）的 EVE 客户端设置文件（core_char_\*.dat / core_user_\*.dat）整体覆盖到同类型的其他文件，并按配置文件做备份与还原——多角色共享总览、按键与 UI 布局用。

## 在哪打开 {#where}
- 左侧导航「**配置同步**」。
- 左栏：**服务器**列表 + **配置文件**下拉，下面一行图标按钮（新建 / 复制 / 重命名 / 删除，悬停显示名称）。
- 右栏四个页签：**角色文件 / 账户文件 / 未识别文件 / 备份**；各页签右上角是自己的动作图标（备份选中文件、打开配置文件目录等）。
- 页面右上角固定「**刷新**」「**设置**」两个图标按钮；所有按钮都是纯图标，悬停出文字提示。

## 前置条件 {#prereq}
- 本机已安装 EVE Online 并至少启动过一次（设置目录默认 `%LOCALAPPDATA%\CCP\EVE`）。找不到时页面提示「未找到 EVE 设置文件夹」，可在设置弹窗里「**选择文件夹…**」手动指定（选到服务器目录或 settings_\* 子目录会自动上溯到根目录）。
- 对该目录的写入需要相应权限：从受限位置（低完整性进程）运行本应用时，写操作可能被系统拒绝，页面会给出「操作失败：」加具体系统原因——请从普通安装位置运行。

## 操作步骤 {#steps}

### 选服务器与配置文件
1. 左栏「**服务器**」选一个服务器目录（目录名形如 `c_tranquility` / `c_serenity`）。
2. 「**配置文件**」下拉选一个——配置文件对应游戏里的 settings\_ 目录；同步与备份都只在当前配置文件内进行，不会跨配置文件、跨服务器或跨类型。
3. 配置文件一行的图标：**新建 / 复制 / 重命名 / 删除**。删除需确认（「将永久删除…及其所有设置文件，此操作无法撤销」）且最后一个配置文件不可删；复制会连带全部文件，名称默认加「- 副本」后缀。

### 同步设置到其他角色 / 账户
1. 「**角色文件**」页签列出 `core_char_角色ID.dat`（角色 / ID / 大小 / 修改时间 / 操作）；「**账户文件**」页签同理列出 `core_user_账户ID.dat`。角色文件保存角色级设置（总览、按键、UI 布局），账户文件保存账户级设置。
2. 点行尾「操作」列的同步图标（提示「同步到其他角色」/「同步到其他账户」），弹出「同步到…」对话框：列出同配置文件内的其他同类文件，默认全不选，可「全选」，显示「已选 x / y」。
3. 对话框明示：「勾选要覆盖的目标文件。此操作会用源文件的设置整体覆盖目标（没有合并），且不可撤销。」确认后默认**先自动备份当前配置文件**，再覆盖所选文件（可在设置弹窗关闭）。
4. 进行中显示「正在同步 x/y」，结束提示「同步完成：成功 N，失败 M」；部分失败会弹「部分目标未能同步」明细。
5. 「**未识别文件**」页签收容命名不规范的文件：可见、可备份，但不作为同步的源或目标。

### 备份与还原
1. 角色文件 / 账户文件页签先在表格里选中行，再点「**备份选中文件**」（未选提示「请先在列表里选择要备份的文件。」）；「备份」页签的「**备份当前配置文件**」备份整个配置文件目录。
2. 备份名自动带时间戳与来源，重名自动加序号；「备份」页签列表显示备份名称 / 来源 / 类型（整配置文件 / 单个文件）/ 文件数 / 大小 / 创建时间，页签顶部显示备份存放的实际路径。
3. 选中一行备份后可「**在文件夹中显示**」「**还原**」「**删除**」（未选中时置灰），均有确认。还原同样先覆盖当前配置文件；整配置文件还原会把备份内全部文件写回，当前档案里多出来的文件保留不删。

### 游戏运行中的保护
- 切到本页时若检测到 EVE 客户端在运行，会弹全局通知提醒（游戏退出时会把内存里的设置写回文件，先写的内容可能被覆盖），每次运行状态变化只提醒一次。
- 真正执行写操作前会再次检测并确认：「建议先完全退出游戏再操作。仍要继续吗？」

### 设置弹窗
- 右上角「**设置**」图标打开「配置同步设置」：**游戏设置目录**（路径框 + 选择文件夹… + 打开目录）、「**同步 / 还原前自动备份当前配置文件**」开关、「**游戏运行时先警告**」开关（关闭后写操作前只提示一次，不再要求确认）。

## 字段与口径 {#fields}

| 列 / 概念 | 含义 | 口径 |
|---|---|---|
| 角色 / 账户 / ID | 文件归属 | 由文件名（core_char\_ / core_user\_ + ID）解析，角色名异步解析回填 |
| 大小 / 修改时间 | 文件属性 | 文件系统的实际值 |
| 未识别文件 | 命名不符合 core_char\_角色ID.dat / core_user\_账户ID.dat 的文件 | 不参与同步，可备份 |
| 备份类型 | 整配置文件 / 单个文件 | 整配置文件 = 目录级备份；单个文件 = 单个 .dat |
| 文件数 / 大小 / 创建时间 | 备份的规模 | 备份创建时的实际值 |

## AI 能替你做什么 {#ai}
- **可以读 / 改同步设置**：`config_read` / `config_write`（name=`evesettings`）读写白名单里的 `EveSettingsSyncSetting.json`（游戏设置目录、自动备份开关、运行中警告开关），写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`evesettings`）在下次进入本页时生效。
- **做不到**：AI 不能读取、写入、同步或备份 EVE 客户端设置文件，不能新建 / 复制 / 重命名 / 删除配置文件，也不能替你还原备份——这些都是覆盖式的破坏性文件操作，没有开放给助手，只能在本页手动完成。助手至多能讲解本手册里的步骤与风险，不会替你动任何文件。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 未找到 EVE 设置文件夹 | 未安装 EVE，或装在非默认位置 | 安装并启动一次游戏；或在设置弹窗手动指定目录 |
| 该目录下没有识别到服务器子目录（形如 c_tranquility / c_serenity）。 | 选中的目录层级不对或为空 | 重新选择正确的根目录或上层目录 |
| 该服务器下没有配置文件（settings\_ 开头的目录） | 该服务器还没生成设置 | 先在游戏里登录一次 |
| 名称不能为空 / 已存在同名配置文件 / 名称不能包含 \ / : \* ? " < > \| 等字符 | 配置文件名校验未通过 | 换一个合法且不重复的名称 |
| 无法删除唯一的配置文件 | 只剩最后一个配置文件 | 先新建一个再删 |
| 没有其他可同步的文件。 | 当前配置文件内没有其他同类目标 | 换配置文件，或先用游戏生成更多设置文件 |
| 建议先完全退出游戏再操作。仍要继续吗？ | 检测到 EVE 客户端正在运行 | 先完全退出游戏再同步 / 还原；确有把握可继续 |
| 操作失败：{具体原因} | 权限被拒、文件被占用等 | 按提示的系统原因处理；受限位置请换普通安装位置运行 |

## 限制与已知问题 {#limits}
- **只做整体覆盖**：同一配置文件内、同类型文件之间，没有合并，不跨配置文件 / 服务器 / 类型；也不解析 .dat 内容（二进制格式），只做文件级覆盖。
- **不监听文件变化**：目录被外部（游戏等）改动后，需手动点「刷新」重新读取。
- **备份不压缩**；备份名自动生成，不能自定义。
- **未识别文件不参与同步**：避免把设置写进来路不明的文件。
- **部分服务器的角色名解析不到**：个别服务器没有公开的名称解析服务，列表会直接显示 ID。
- **游戏运行时写入可能被覆盖**：有检测、通知与二次确认，但不阻止执意继续的操作。
