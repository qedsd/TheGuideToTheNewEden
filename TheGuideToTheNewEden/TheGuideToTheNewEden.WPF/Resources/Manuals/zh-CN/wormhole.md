# 虫洞

## 一句话 {#tldr}
离线查虫洞资料：洞系（等级 / 天象 / 固定与漫游洞口 / 天体）、洞口库（通往何处、寿命、质量上限）、过洞计算器，外加按 zKillboard 数据分析洞系活跃度。

## 在哪打开 {#where}
- 左侧导航「**虫洞**」。
- 页面顶部右侧是「**洞系浏览** / **洞口库**」两个模式切换；默认洞系浏览：左卡是搜索 + 列表 + 洞系详情，右卡是 ZKB 分析。

## 前置条件 {#prereq}
- 洞系与洞口资料随程序内置在本地数据库里，无需登录角色、无需联网。
- ZKB 活跃度分析需要联网访问 zKillboard；不联网时右卡会给出获取失败提示，左侧资料不受影响。

## 操作步骤 {#steps}

### 浏览洞系
1. 左卡顶部搜索框（「搜索虫洞...」）输入洞系名，或用旁边的两个下拉按等级（全部等级 / c1-c6 / c12 希拉 / c13 破碎虫洞 / c14-c18 流浪者虫洞）与天象（全部天象 / 红巨星 / 激变变星 / 磁星 / 脉冲星 / 沃尔夫-拉叶星 / 黑洞）过滤。
2. 列表条目带等级徽章（按等级着色，越危险的等级越偏红）与天象名；列表底部显示当前条数（N 个星系）。
3. 点中洞系后右侧出现详情卡。

### 看洞系详情
1. 详情卡顶部是洞系名，右侧有**复制星系名**的图标按钮（复制成功有通知，游戏内输入洞名的高频操作）。
2. 等级徽章下有两段说明：该等级的玩法定位与该天象的定性效果（如磁星"全类武器伤害提升，但舰船机动与炮台追踪受罚"）。
3. 「**永联**」「**漫游**」两组按钮：每个按钮是洞口代号，下方直接显示通往摘要（如「通往 c3 · 高安」）；没有对应洞口时显示「无永联洞」「无漫游洞」。
4. 「**星球** / **月球** / **其他**」三个页签列出该洞系的天体。
5. 底部「**友链**」：Anoik / Dotlan / Ellatha / Zkillboard / Chruker 按钮，点击用浏览器打开该洞系的对应页面。

### 看活跃度（ZKB 分析）
1. 右卡在选中洞系后自动从 zKillboard 取数；顶部下拉选范围：最近 200 / 400 / 600 / 800 条击杀（默认 400）。
2. 成功后显示：概要三格（击杀数 / ISK 损失 / 时间跨度）、最活跃角色 / 军团 / 联盟（各取前三，带头像与最近活跃时间）、热门船型（被击毁，前五，可点击）、活跃时段分布图（星期 × 本地小时的击杀堆叠柱状图，用于判断敌方作息）。
3. 点角色 / 军团 / 联盟 / 船型行或「**查看详细**」按钮，进应用内的 Zkillboard 页看对应实体统计；「**刷新**」重新取数。

### 查洞口库
1. 顶栏切到「**洞口库**」：搜索框（「搜索洞口代号（如 B274）」）+「**全部通往**」下拉（高安 / 低安 / 00 / c1-c6 / c12 希拉 / c13 破碎虫洞）+「**全部再生**」下拉（固定 / 随机）。
2. 表格列出全部洞口：洞口代号、通往、位于、最大稳定时间、最大跳跃质量、最大稳定质量、再生质量、再生位置、备注；底部提示「双击行查看详情与过洞计算」。

### 过洞计算
1. 在洞口库双击一行（或在洞系详情点洞口按钮），打开独立的洞口详情窗口。
2. 窗口里有基础信息（通往 / 位于 / 最大稳定时间 / 再生质量）、质量数据（最大跳跃质量 / 最大稳定质量的完整数值与备注）与过洞计算器。
3. 计算器「**选择舰船**」：左边下拉选代表舰船档位（护卫舰到泰坦），右边搜索框可搜具体舰船（按游戏内船体质量面板值取数）；也可直接手输「舰船质量 (kg)」。
4. 「**已消耗质量 (kg)**」默认 0（新洞）；填入已消耗量即可按当前状态计算。
5. 结果区实时显示：单跳能否通过；按当前总质量池还能过几艘；质量池不足一跳时按每日再生量估算恢复天数。该洞口没有质量数据时会提示。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 洞口代号 | 洞口的名称代号 | 原样显示 |
| 通往 | 该洞口通往的空间类型 | 可同时通往多种（如 c3 · 高安） |
| 位于 | 该洞口出现在哪类空间 | 同上 |
| 最大稳定时间 | 洞口的最长存活时间 | 小时 |
| 最大跳跃质量 | 单次跳跃允许的最大船体质量 | kg；过洞判定用游戏内船体质量面板值 |
| 最大稳定质量 | 洞口的总质量池上限 | kg |
| 再生质量 | 洞口每天恢复的质量 | kg；部分洞口为 0 |
| 再生位置 | 固定 / 随机 | 固定 = 重生在同一位置 |
| 等级徽章 | 洞系等级 c1-c6 / c12-c18 | 列表用短名（c12-c18），详情用全名 |

## AI 能替你做什么 {#ai}
- 工具：`wormhole_info`（查洞系的等级 / 天象 / 固定与漫游洞口，或查洞口的通往、寿命、质量上限、再生与重生位置；唯一命中可带天体列表）。
- 推荐问法：「J244 是什么洞」「哪个洞能通高安」「B274 的质量上限是多少」。
- **做不到**：工具只给质量上限等数据，"这船过得去吗 / 还能过几艘"的过洞判定要本页计算器算；也取不到 zKillboard 活跃度统计。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| ZKB 数据获取失败 | 联网失败或 zKillboard 服务异常 | 稍后点「刷新」重试；左侧资料不受影响 |
| 该星系最近没有击杀记录 | 该洞系确实无近期击杀 | 属正常空态，不代表功能异常 |
| 该洞口缺少质量数据。 | 该洞口在库里没有质量字段 | 无法计算过洞，到友链站（如 Anoik）查询 |
| 虫洞数据加载失败 | 本地数据库读取异常 | 重启应用 |

## 限制与已知问题 {#limits}
- **ZKB 范围是"最近 N 条"**：zKillboard 接口没有时间过滤，"最近 400 条"指最近 400 个击杀记录，不是固定时间段。
- **ZKB 是第三方服务**：统计会波动，同一洞系两次取到的数据可能不同；取数失败会自动重试一次。
- **活跃时段分布图配色固定**：图表画笔不随深浅主题切换（用的是色盲友好色板）。
- **等级与天象只写定性效果**：内置说明不含具体数值，精确的星系效果数值请经友链（如 Chruker）查询。
- **数据库名称跟随本地库语言**：星球类型、舰船名等来自本地数据库，不随界面语言切换。
- **洞口库备注列**：由该洞口的两条质量备注去重拼出，不是独立的备注字段。
- **星图上找不到虫洞星系**：星图不绘制虫洞空间，出站跳转走详情卡的友链。
