# 设置

## 一句话 {#tldr}
所有应用级配置的集中入口：界面语言与主题、主页卡片与快捷方式、游戏日志、市场缓存、玩家建筑、ESI 权限、AI 助手参数、术语表、多开按键、更新等，都从这一页按分类点进去改。

## 在哪打开 {#where}
- 左侧导航「**设置**」。
- 首屏是**分类列表**：一列卡片，每行「图标 + 分类名 + 一行说明 + 右箭头」，点整行进入该分类的详情。
- 详情区顶部是面包屑「**设置 › 分类名**」；点面包屑里的「**设置**」返回分类列表。
- 「AI」分类里还有下一层：进入后再点一节（模型与翻译 / 行为 / ESI 全量访问 / 工具开关），面包屑变成三段（如「设置 › AI › 行为」）；点中间的分类名回到该页的上一层，点「设置」回到分类列表。
- 支持从其它页面**直达**：翻译 / 频道翻译等页的「去配置」类按钮、左侧导航功能项右键「**管理快捷方式…**」、主页快捷方式里的「设置 · XX」磁贴（在「添加功能」窗口里添加），都会跳进设置页并直接打开对应分类。

## 前置条件 {#prereq}
- **不需要登录角色**：绝大多数设置（外观、日志、缓存、托盘等）与授权无关。
- 个别分类与授权有关：「**玩家建筑**」需要已授权角色才能解析结构；「**权限选择**」决定下次授权时申请哪些范围。
- 设置保存在**数据目录**的 `Configs/settings.json`（默认 `%LocalAppData%\TheGuideToTheNewEden\V4\Configs`；路径可在「一般 → 数据目录」查看与更改）。默认按大版本隔离，不再自动与旧版 WinUI 共用；只有主动选「沿用旧目录」时才共用同一文件。

## 操作步骤 {#steps}

### 打开一个分类
1. 左侧导航「设置」→ 点分类列表里的目标行（如「一般」「游戏日志」）。
2. 详情区换成该分类的子页，面包屑显示「设置 › 分类名」；子页自上而下是一列设置卡片。
3. 点面包屑里的「设置」回到分类列表，再点别的分类。
4. 子页实例会被缓存：切走再切回来，页面保持你离开时的状态（已改未保存的编辑不会丢）。

### 在「AI」分类里下钻
1. 「AI」分类点进去后是**分节列表**，与设置首页同款的一列卡片：模型与翻译 / 行为 / ESI 全量访问 / 工具开关。
2. 点某节进入三级详情；面包屑变成「设置 › AI › 节名」（「模型与翻译」节改动即时保存，其余三节在详情里各自点「保存」）。
3. 点面包屑里的「AI」回到分节列表；每节首次进入才加载，返回再进不重新读取设置。

### 从别的页面直达
1. 在翻译 / 频道翻译等页点「去配置」类按钮 → 打开设置页并直接落到目标分类（AI 配置会直接钻到对应分节）。
2. 在左侧导航的功能项上右键「管理快捷方式…」→ 直接落到「设置 → 主页」分类。

## AI 能替你做什么 {#ai}
- 设置**可以部分交给 AI**：`config_read`（name=`settings`）能读 `settings.json`（密钥类键省略），`config_write` 只能改**已存在的非密钥键**（语言、主题、托盘、服务器、日志路径、市场缓存参数等，前提是该键已在文件里），写入前需你确认，旧内容自动备份、可用 `config_restore` 回滚。改完可用 `feature_restart`（name=`settings`）重读；主题 / 语言 / 快捷键等启动期设置仍需重启才完全生效。
- **不能改数据目录**：`datapath.json` 不在配置文件白名单里；选目录、复制旧配置与「立即重启」只能手动做。
- AI 的部分行为由「AI」分类决定（写操作确认、可用工具开关、ESI 网关与配额等），这些只能由你在该分类里手动改。
- 推荐问法：「怎么把界面换成英文」「游戏日志路径应该填什么」「现在的 ESI 查询线程数是多少」。
- **做不到**：替你点「更改…」「恢复默认」或重启软件；读写 `datapath.json` 与 API Key 等密钥；修改结构 / 权限勾选等不在白名单里的文件。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 从别的页面点「去配置」后没有落到目标分类 | 深链只记录一次"待办"，进入设置页时消费；目标分类已不存在时留在分类列表 | 手动在分类列表里点目标分类 |
| 改了设置但重启后没保留 | 数据目录只读或进程完整性过低被系统拒绝，界面不会单独报错 | 从普通安装位置运行（不要放在受限目录里跑），确认数据目录可写 |
| 改了数据目录但重启后没生效 | 只写选择记录、下次启动才切换；或目标目录不可写 | 重启软件；确认目标目录可写，必要时「恢复默认」 |
| 设置与另一版本（WinUI 版）互相覆盖 | 首次运行选了「沿用旧目录」，两版共用同一 `settings.json` | 改回按大版本隔离的 `…\V4` 数据目录；同一时间只运行一个版本 |

## 限制与已知问题 {#limits}
- **分类说明有旧文案**：「主页」分类的说明仍写"快捷方式的增删与分组在主页「编辑」模式进行"——主页编辑模式已删除，快捷方式编辑只在「设置 → 主页」里进行（见下一条）。
- **快捷方式编辑唯一入口**：主页磁贴的增删 / 排序 / 宽窄 / 恢复默认只能在「设置 → 主页」改；主页本体只剩点击打开磁贴（REFACTORING 阶段 101）。
- **没有「Zkillboard」分类**：ZKB 实时流的全部设置（连接 / 通知 / 上限 / 过滤）在 ZKB 页「击杀流」的设置弹窗里维护，旧设置子页已删除（REFACTORING §8-45、§8-48）。
- **「关于」不在分类列表里**：关于窗口从主页品牌条的「关于」按钮打开，是独立窗口。
- **受限运行位置写入静默失败**：数据目录不可写（只读目录、低完整性进程）时，多数设置改了不报错但也存不下来。
- **设置默认按大版本隔离**（REFACTORING 阶段 186）：默认数据目录是 `%LocalAppData%\TheGuideToTheNewEden\V4`；只有主动选「沿用旧目录」才与旧版共用 `Configs/settings.json`，届时两版同时运行会互相覆盖。
- **数据目录改动必须重启**：本次运行仍用旧目录；旧目录不会被删除或移动。
