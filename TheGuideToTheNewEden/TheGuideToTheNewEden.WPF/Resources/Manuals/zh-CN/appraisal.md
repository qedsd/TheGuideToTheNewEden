# 商业 · 估价

## 一句话 {#tldr}
把游戏里复制的一整份物品清单（货柜 / 机库 / 合同 / 资产）贴进来，按所选市场的订单或历史价估算总买价、总卖价、中间价与总体积，逐物品给出单价与小计——回答「这船东西值多少钱」。

## 在哪打开 {#where}
- 左侧导航「**商业**」→「**估价**」。
- 左栏自上而下：多行输入框、「**市场**」选择器、「**卖出估价方式** / **买入估价方式**」下拉与参数、底部「**估价**」「**复制结果**」按钮；右栏是汇总条（市场 / 体积 / 买价 / 中间价 / 卖价）、最多两条警告与明细表。
- 估价期间弹出**全局等待遮罩**（可点「**取消**」，文案「估价中（已完成/总数）」实时推进），完成 / 失败 / 取消走右下角通知。

## 前置条件 {#prereq}
- 星域 / 星系来源**不需要登录**（匿名 ESI 实时取订单）；**建筑来源**需要角色授权且对该建筑有市场访问权。
- 历史口径走**本地磁盘缓存**（与市场页同机制），首次会稍慢。
- 设置存在独立存档，默认：伏尔戈、卖 = 卖单最低价格 × 100%、买 = 买单最高价格 × 100%、历史 7 天、去极值开。价格参数**改动即保存**（不必点估价）；左侧粘贴的清单文本不保存。

## 操作步骤 {#steps}

### 粘贴清单
1. 左栏输入框粘贴多行文本（占位文案「**CTRL+V黏贴仓库、合同、货柜等...**」）。
2. 支持格式：Tab 分隔（货柜 / 机库全选复制）、`名称 x数量`、`数量x 名称`、行尾独立数字、整行纯名称；数量带千分位逗号也认；物品名里的 `*` 会被忽略；同一物品多行数量自动合并。
3. 输入为空时点「估价」提示「**请先粘贴物品清单**」。

### 选市场与口径
1. 「**市场**」选择器：星域 / 星系 / 建筑三选一；未选时点估价提示「**未选择市场**」。
2. 「**卖出估价方式**」「**买入估价方式**」是同构的 10 项下拉：六个订单口径（卖单前5%最低价格订单平均价格 / 卖单实际数量的相应价格 / 卖单最低价格 / 买单前5%最高价格订单平均价格 / 买单实际数量的相应价格 / 买单最高价格）+ 四个历史口径（历史最高价格 / 历史平均价格 / 历史最低价格 / 历史中位数）。
3. 「**卖出百分比（%）**」「**买入百分比（%）**」：单价 = 口径价 × 百分比 ÷ 100，两侧独立，默认 100；「**历史价格统计天数**」默认 7（历史口径用）；「**去极值**」默认勾选（去掉一个最值后求平均）。
4. **换市场不会自动重算**，改完要点「估价」。

### 估价与复制
1. 点「**估价**」：等待遮罩显示进度；完成提示「**估价完成：N个物品**」。
2. 右栏汇总条给出市场、总体积、总买价、中间价（总买价与总卖价的均值）、总卖价。
3. 明细表列出每个物品的图标 / 物品 / 数量 / 体积 / **买单价** / 买价 / **卖单价** / 卖价；物品图标联网加载。
4. 有解析不了或无报价的物品时，表格上方各出一条警告：「**未识别到物品：…**」「**所选市场无报价：…**」。
5. 点「**复制结果**」把汇总与明细（制表符分隔）复制成文本，提示「**已复制估价结果**」。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 买单价 / 卖单价 | 单个物品的单价 | 所选口径价 × 两侧百分比 ÷ 100 |
| 买价 / 卖价 | 该行小计 | 单价 × 数量 |
| 数量 | 同名行合并后的总量 | 按物品类型聚合 |
| 体积 | 该行体积 | 数量 × 物品打包体积（缺省回落普通体积） |
| 中间价 | 买卖均值 | （总买价 + 总卖价）÷ 2 |
| 前 5% 口径 | 订单密集侧均价 | 卖单取最便宜 5%、买单取最贵 5% 的平均；不足 2 条取首条 |
| 实际数量的相应价格 | 按量吃单的加权均价 | 以**清单里该物品的总量**逐档吃单（区别于倒货按日销量） |
| 历史口径 | 近 N 天的统计值 | 去极值 = 去掉一个最值后求平均；只剩 1 天不去极值 |
| 无报价回落 | 订单口径取不到价时 | 回落最近历史均价；仍无则该物品按 0 计入并进「所选市场无报价」 |
| 物品名解析 | 名称 → 物品 | 精确 → 本地化精确 → 模糊 → 本地化模糊，**唯一命中才采用**；多命中时只接受完全同名 |

## AI 能替你做什么 {#ai}
- `appraisal`（只读、无需确认）：把多行清单直接交给 AI 估价，返回总买价 / 中间价 / 总卖价 / 总体积与明细（最多前 15 行）、未识别与无报价的条数。参数：`text`（必填）、`regionName`（可选星域名，默认伏尔戈）。口径沿用估价页当前的设置。
- 推荐问法：「帮我估价这份清单」「这船东西在伏尔戈值多少」。
- **可以读 / 改估价设置**：`config_read` / `config_write`（name=`appraisal`）读写白名单里的 `AppraisalSetting.json`（价格来源、买卖口径与百分比、历史天数、去极值等），写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`appraisal`）在下次进入估价页时生效。
- **做不到**：工具只能按**星域**取价（不能指定星系 / 建筑）；不能替你点「估价」按钮；清单超过 200 件会拒绝并要求分批；明细超过 15 行只给前 15 行，全量请在页面复制。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先粘贴物品清单 | 输入为空 | 粘贴清单再估价 |
| 未选择市场 | 没选价格来源 | 在选择器里选星域 / 星系 / 建筑 |
| 未识别到物品：… | 名称对不上本地库（拼写、译名不一致等） | 检查物品名；解析不出的行不参与估价 |
| 所选市场无报价：… | 该市场没有这些物品的订单与历史 | 换市场 / 换口径，或确认物品在该地确有交易 |
| 建筑订单获取失败：需要角色授权，且该角色对该建筑有市场访问权限 | 建筑来源取数失败 | 确认「设置 → 玩家建筑」里有这座建筑且角色有访问权 |
| 估价失败：… | ESI 不可用或限流 | 稍后重试 |
| 已取消 | 等待遮罩里点了「取消」 | 属预期，重按「估价」即可 |

## 限制与已知问题 {#limits}
- **结果是当下快照**：估价不自动刷新；换市场、改口径都要手动重估。
- **建筑来源首次较慢**：整建筑全量拉取（有缓存），历史用的是该建筑所在星域的历史（REFACTORING §8-9）。
- **「实际数量的相应价格」按清单总量吃单**：与倒货里按日销量吃单的口径不同，同一口径的数字可能对不上。
- **解析有歧义的名称不会乱配**：多命中且无完全同名时该行进「未识别」。
- **估价用的是全局等待遮罩**：等待期间会挡住其它页面的操作（比价页是页内等待，市场页是页内文字提示）。
- **粘贴的清单不落盘**：重启后输入框是空的；价格参数则会自动恢复。
