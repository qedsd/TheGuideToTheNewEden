# 设置 · 玩家建筑

## 一句话 {#tldr}
维护一份「我关心的建筑（结构）」清单：按结构 ID 把建筑加入列表后，市场、估价、订单（以及倒货 / 比价的源与目的地）里的建筑市场选择和建筑位置名才有名字可显示。

## 在哪打开 {#where}
- 左侧导航「**设置**」→ 分类列表「**玩家建筑**」（说明：管理玩家建筑）。
- 页面左右两栏：左栏「**已添加建筑**」——名称 / ID / 星系三列的表格 + 「**删除所选**」按钮；右栏「**添加新建筑**」——「按结构 ID 添加」输入框 + 「**添加**」按钮，下方有一行说明文字。

## 前置条件 {#prereq}
- **查看与删除不需要角色**；**按 ID 添加需要解析**：已登录至少一个角色（解析用第一个角色的授权），且该角色授权时勾选了 `esi-universe.read_structures.v1`。
- 解析成功过的建筑会直接命中本地缓存，不需要再走 ESI；两者都不满足时会弹出「结构解析失败…」提示（见「常见失败与处置」）。

## 操作步骤 {#steps}

### 添加一座建筑
1. 右栏「按结构 ID 添加」输入框里填建筑的结构 ID（纯数字，占位示例 `eg: 1023456789`）。
2. 点「**添加**」：应用**先解析再入库**——本地缓存已有的直接返回，否则通过 ESI 查询名称与所在星系 / 星域；成功后左侧「已添加建筑」新增一行，输入框自动清空。
3. 输入为空或不是有效 ID 时不会添加，会弹出提示框（标题「按结构 ID 添加」）；列表里已有的 ID 再次点「添加」会被直接忽略，没有提示。
4. 「看到什么算成功」：左表出现该建筑的名称与星系；[商业 · 市场](market) 的建筑市场选择里也能选到它——建筑列表每次展开都重新读取，增删后不需要重开市场页。

### 删除建筑
1. 左栏表格选中一行或多行（支持多选）。
2. 点「**删除所选**」，选中行立即从列表移除。
3. 「看到什么算成功」：删除后市场页「建筑」页签里不再列出该建筑。

### 关于「按角色搜索」
- 右栏下方固定显示一行说明：「按角色搜索需要先完成账号授权，当前版本暂不可用。」——按角色权限搜索建筑列表的方式当前版本没有开放，只能用按结构 ID 添加。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 名称 | 建筑名称 | 解析成功才会入库；列表里不会出现解析失败的行 |
| ID | 结构 ID | 添加时填写的纯数字 |
| 星系 | 建筑所在星系 | 解析时一并取得；建筑订单的星系与安全等级等信息按它补齐 |

- 清单保存在配置目录的 `Configs/MarketStructures.json`；解析结果另有缓存 `Configs/Structures.json`。

## AI 能替你做什么 {#ai}
- 本页**没有专属 AI 工具**：AI 不能替你添加或删除建筑，也改不了这份清单。
- 可以问 AI「建筑市场为什么取不到订单」「怎么把建筑加进市场」，AI 能解释流程与提示含义，但操作仍要你手动完成。
- **做不到**：替你解析（解析失败只能按提示处理后重试）、绕过权限直接添加建筑。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 结构解析失败：请确认已有授权角色，且勾选了 esi-universe.read_structures.v1 权限。 | 没有已登录角色；或角色授权时没勾选该权限；或 ID 填错 / 该角色看不到这座建筑 | 到[设置 · 权限选择](settings/esi-scope)确认勾选 `esi-universe.read_structures.v1`，在「角色」页（重新）授权后重试；核对 ID |
| 点「添加」弹出提示框（标题「按结构 ID 添加」） | 输入为空或不是有效数字 | 填纯数字的结构 ID 再点「添加」 |

## 限制与已知问题 {#limits}
- **建筑位置名只认这份清单**：市场、估价、订单（以及倒货 / 比价的源 / 目的地）显示建筑位置时，名称只从本页的列表里查，查不到就显示原始 ID（REFACTORING §8-5）。
- **「按角色搜索建筑」未开放**：界面已说明当前版本暂不可用（REFACTORING §8「计划内未做」项）。
- **建筑订单量级**：选中某建筑市场时，订单是整栋建筑全量拉取、按「设置 → 市场」的缓存时长缓存，首次明显较慢——详见 [商业 · 市场](market)。
- **解析依赖角色与权限**：没有角色或权限不足时无法添加新建筑；已缓存过的建筑不受影响。
