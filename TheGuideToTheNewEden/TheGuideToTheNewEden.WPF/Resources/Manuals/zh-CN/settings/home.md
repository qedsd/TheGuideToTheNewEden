# 设置 · 主页

## 一句话 {#tldr}
控制主页三张数据卡（钱包 / 行情 / 最近使用）显不显示，并管理主页快捷方式磁贴：添加、移除、拖动排序、切换宽窄、恢复默认。这里是主页磁贴编辑的**唯一入口**——主页本体只剩"点击打开"磁贴一种交互。

## 在哪打开 {#where}
- 左侧导航「**设置**」→ 分类「**主页**」；或在左侧导航的功能项上**右键 →「管理快捷方式…」**，会直接跳进设置页并落到本分类。
- 子页分两段：
  - **卡片显示**：三张开关卡——显示钱包卡 / 显示行情卡 / 显示「最近使用」；
  - **快捷方式**：顶部一行（左侧计数「共 n 个 · 上限 24」，右侧「**恢复默认**」与「**添加功能**」按钮），下面是磁贴行列表，每行「图标 + 标题 + 副标题」+ 行尾「⤢ 宽窄切换」与「✕ 移除」按钮；列表为空时显示引导文字。
- 页内说明文字：「拖动行调整顺序，✕ 移除磁贴，⤢ 切换宽窄磁贴；改动立即生效并同步到主页，上限 24 个。」

## 前置条件 {#prereq}
- **不需要登录角色**；快捷方式与主页共用同一份数据，本页改动立即同步到主页（反之亦然）。
- 添加磁贴走独立的「添加功能」窗口：可添加的功能就是主页功能目录里的条目（含各「设置 · XX」分类磁贴）。

## 操作步骤 {#steps}

### 开关数据卡
1. 「卡片显示」里点对应开关：**显示钱包卡**（主页快捷方式下方的「我的钱包」卡片）、**显示行情卡**、**显示「最近使用」**。
2. 开关即拨即存，主页同帧显隐。
3. 关闭「显示「最近使用」」后，主页不再显示最近使用区，同时**不再记录**最近打开的功能。

### 添加磁贴
1. 点「**添加功能**」→ 打开「添加功能」窗口：左栏分组列表，右栏顶部搜索框（「搜索功能（名称 / 分组）」），下面是功能行。
2. 点功能行右侧「**添加**」加入主页，按钮变成「**已添加**」（再点一次移除）；底部实时显示「已添加 n / 总数 个功能」。
3. 满员（上限 24）时「添加功能」按钮变灰；继续从别的入口添加会提示「最多固定 24 个功能，请先移除一些再添加」。
4. 另一途径：在左侧导航的功能项上**右键 →「固定到主页」**（已固定的功能菜单里这一项会隐藏）；角色卡片、星图、市场页也有各自的固定入口，重复固定时提示「『XX』已经在主页上了」。

### 排序与移除
1. **拖动排序**：按住行的空白处拖动（按在按钮上不会触发拖动）；拖到某行**上半段插到它前面、下半段插到它后面**，拖到列表空白处移到末尾。
2. 列表超出一屏时，把行拖到视口上下边缘会**自动滚动**。
3. **移除**：点行尾「✕」（悬停提示「从主页移除」）。带参数的磁贴（指定物品 / 角色 / 星系）只移除这一块，不影响同功能的其它磁贴。

### 切换宽窄
- 点行尾「⤢」按钮：小磁贴扩为宽磁贴、宽磁贴缩为小磁贴；悬停提示随当前尺寸在「切换为宽磁贴 / 切换为小磁贴」间变化。

### 恢复默认
1. 点「**恢复默认**」→ 确认框：「**恢复为推荐组合？当前固定的功能与顺序会被覆盖。**」
2. 选「是」后磁贴回到推荐组合并同步到主页。

### 清空最近使用
- 「最近使用」的清空按钮在**主页**的最近使用区（悬停提示「清空最近使用」），不在本页；本页只能用「显示「最近使用」」开关整体关掉这块区域。

## 字段与口径 {#fields}

| 项目 | 取值 / 操作 | 口径 |
|---|---|---|
| 显示钱包卡 | 开 / 关 | 主页「我的钱包」卡片（总余额与收支构成）显隐 |
| 显示行情卡 | 开 / 关 | 主页「行情」卡片显隐 |
| 显示「最近使用」 | 开 / 关 | 最近使用磁贴区显隐；关闭后同时停止记录最近打开的功能 |
| 快捷方式列表 | 行列表 | 与主页磁贴同一份数据，行数 = 主页磁贴数 |
| 计数 | 「共 n 个 · 上限 24」 | 上限固定 24，本页没有调整入口 |
| 行副标题 | 所属分组 | 参数化磁贴显示「参数 + 功能」 |
| 宽窄 | ⤢ | 小磁贴与宽磁贴二选一，只影响主页上的占位宽度 |
| 最近使用 | 自动记录 | 按打开顺序展示、去重，最多保留 8 个 |

## AI 能替你做什么 {#ai}
- **可以读 / 改快捷方式配置**：`config_read` / `config_write` 读写白名单里的 `HomeShortcuts.json`（磁贴 id、顺序、显示策略、最近使用开关），写入需确认、旧内容自动备份、可用 `config_restore` 回滚；改完用 `feature_restart`（name=`home`）重读，页面未打开时下次进入生效。
- 固定磁贴的界面入口仍然更快：左侧导航右键「固定到主页」、角色卡片的「⋯」菜单、本页「添加功能」窗口。
- 推荐问法：「主页磁贴怎么加」「在哪里恢复默认磁贴」「读一下我的主页快捷方式」。
- **做不到**：替你点「添加功能 / 恢复默认」或拖动排序；不能保证按 JSON 手改的磁贴一定显示（写坏了用 `config_restore` 回滚）。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 「添加功能」按钮是灰的 | 快捷方式已满（上限 24） | 先移除一些磁贴再添加 |
| 提示「最多固定 24 个功能，请先移除一些再添加」 | 添加时已满员 | 同上 |
| 提示「『XX』已经在主页上了」 | 该功能已固定（含同功能的其它参数磁贴） | 直接用现有磁贴；或先移除再添加 |
| 拖动行没有反应 | 按在行尾按钮上不会启动拖动 | 按住行空白处再拖 |
| 主页磁贴顺序变了或消失 | 「恢复默认」覆盖了当前组合；或被其它入口（导航右键「从主页取消固定」等）改动 | 两边共用一份数据；需要时重新添加、重新拖动 |

## 限制与已知问题 {#limits}
- **编辑唯一入口**：主页编辑模式、「⋯」菜单与"磁贴按分组分段显示"已删除（REFACTORING 阶段 101），主页磁贴只剩点击打开；设置首页「主页」分类的副标题仍是提到"编辑模式"的旧文案。
- **导航右键「从主页取消固定」会移除该功能的全部磁贴**：同一功能有多块参数磁贴时会一起移除；本页行尾「✕」只移除单块。
- **上限固定 24**：没有调整上限的入口。
- **排序只能拖动**：本页没有上移 / 下移按钮；主页磁贴不可拖动。
- **最近使用只按打开顺序去重展示**（不统计频次），最多保留 8 个（REFACTORING §8「计划内未做」）。
- **参数化磁贴只支持三类目标**（物品 / 角色 / 星系），没有"从任意页面创建任意参数"的通用编辑器（REFACTORING §8「计划内未做」）。
