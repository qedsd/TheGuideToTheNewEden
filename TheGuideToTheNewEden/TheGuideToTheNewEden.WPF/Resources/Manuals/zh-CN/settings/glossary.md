# 设置 · 术语表

## 一句话 {#tldr}
维护翻译用的译名对照：给 SDE 术语库覆盖不到的名词固定译名（用户术语优先级最高），并人工确认 AI 翻译时发现的新词候选。确认过的术语同时约束 AI 翻译与 AI 助手的译文。

## 在哪打开 {#where}
- 左侧导航「**设置**」→ 分类列表「**术语表**」（说明文案：「维护用户自定义术语与 AI 发现的新词（用户术语优先级高于 SDE 术语库）」）。
- 页面自上而下三块：**用户术语表**（输入框 + 列表）、**AI 新词候选**、**术语库状态**。
- 也可在主页「添加功能」窗口里把「设置 · 术语表」加成磁贴，点了直达本页。

## 前置条件 {#prereq}
- 查看与编辑用户术语**不需要登录角色**。
- 「术语库状态」里的 SDE 条数来自本地数据库（主数据库英文 + 本地化数据库中文按 ID 配对）；本地化数据库没就绪时中文侧无从配对（开关在「设置 → 一般」）。
- 「AI 新词候选」只在**用 AI 翻译源翻译成功后**产生（翻译页 / 频道翻译 / 助手问翻译都算）；只查本地词库不会产生候选。

## 操作步骤 {#steps}

### 固定一条译名（用户术语表）
1. 在「**英文名**」（占位示例 Rifter）与「**中文名**」（占位示例 裂谷级）里填好，点「**添加**」。
2. 成功后输入框清空，显示「已保存术语：英文名 = 中文名」并弹右下角通知；术语**立即生效**（提示词注入、译名后校验、本地词库覆盖三条路径同时用它，AI 结果缓存自动失效），**不需要重启**。
3. 英文名**唯一且忽略大小写**：重复添加同一名等于更新译名。
4. 列表每行是「英文名 / 中文名 / 删除」；点行尾红色「**删除**」移除，显示「已删除术语：××」。
5. 没填就点「添加」会有对应提示：「请先填写英文名（可点候选行的「加入术语表」自动填入）」或「请填写中文译名」。

### 处理 AI 新词候选
1. 「**AI 新词候选**」列表每条是英文名 + 出现次数 + 原文/译文样例，按出现次数排序；底部显示「共 N 条候选」。
2. 点「**加入术语表**」→ 英文名回填进上面的输入框并聚焦中文名框，提示「已填入「××」，请补上中文译名后点「添加」」；补完按上一节「添加」保存。
3. 点「**忽略**」→ 这条进忽略名单，之后翻译再遇到也不再记录。
4. 「**清空候选**」一键清空，显示「已清空 AI 新词候选」。
5. 候选**永远不会自动写入术语表**——模型反推的对应关系不可靠，必须人工确认，避免把错译固化。

### 看术语库状态 / 重新载入
1. 「**术语库状态**」卡片显示「SDE X 条 · 用户 Y 条」，说明文案写明 SDE 术语的来源与用户术语的存放位置（`Configs/UserGlossary.json`）。
2. 点「**重新载入**」→ 状态变「正在载入…」，完成后显示条数与耗时；SDE 数据库更新过或怀疑术语过期时用它。

## 字段与口径 {#fields}

| 列 / 字段 | 含义 | 口径 |
|---|---|---|
| 英文名 | 术语原文（唯一键） | 忽略大小写；重复添加 = 覆盖译名 |
| 中文名 | 固定译名 | 优先级高于 SDE 术语库，翻译时要求原样使用 |
| 次数（候选） | 该词在翻译原文里出现的次数 | 候选列表按它排序 |
| 样例（候选） | 记录时的原文 / 译文片段 | 帮助判断该不该收录 |
| SDE 条数 | 内置术语库条目数 | 主数据库（英文）与本地化数据库（中文）按 ID 配对，中英相同的不算 |
| 用户条数 | 用户术语表条目数 | 存于配置目录 `Configs/UserGlossary.json` |

## AI 能替你做什么 {#ai}
- 工具：`glossary_write`（新增 / 覆盖 / 删除一条用户术语，**写操作，需要你确认**，一次只动一条）、`translate`（中英互译，本地词库优先、AI 源兜底，结果会附上命中的术语）。
- 术语表同时约束**两边的 AI**：AI 翻译（提示词注入 + 译名后校验）与 AI 助手的译文输出都按它来。
- 推荐问法：「以后把 Rifter 译成裂谷级」「记一下 XX 军团的中文名叫 XX」「Rifter 是什么」。
- **做不到**：不能处理 AI 新词候选（加入 / 忽略 / 清空只能在页面点）、不能批量导入导出、不能修改 SDE 内置术语（只能被用户术语覆盖）。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先填写英文名（可点候选行的「加入术语表」自动填入） | 英文名为空就点了「添加」 | 填英文名，或从候选行「加入术语表」自动回填 |
| 请填写中文译名 | 中文名为空 | 补上中文译名再点「添加」 |
| 已填入「××」，请补上中文译名后点「添加」 | 候选只回填了英文名 | 这是正常流程提示，补译名后「添加」 |
| SDE 条数为 0 / 重新载入报错 | 本地数据库未就绪（主数据库或本地化数据库缺失） | 检查「设置 → 一般」的本地化数据库设置后重试 |
| 候选里混着普通英文词（如 Warp） | 新词识别是启发式，会有误报 | 点「忽略」，之后不再出现 |

## 限制与已知问题 {#limits}
- **术语库只覆盖 SDE 里的名词**（REFACTORING §8-29）：物品 / 舰船 / 装备 / 星系 / 星域 / 空间站可约束；**结构（建筑）名**、玩家 / 军团 / 联盟名不在 SDE——这些靠用户术语表自己补。
- **AI 新词候选是启发式，会误报**（§8-35）：规则是"大写开头 + 术语库没有 + 译文里没原样出现"，普通英文词也可能进候选；所以只排队、由人确认，可「忽略」。
- **用户术语即时生效，但只对之后的请求**（§8-36）：改动立即反映到术语匹配与 AI 缓存键，不需要重启；已经在跑的那条翻译请求不受影响（下一条生效）。
- **SDE 术语库每进程重新抽取**（§8-32）：首次使用 AI 翻译或打开本页时才载入，之后常驻内存；没有落盘缓存，「重新载入」会显示实际耗时。
- **候选有条数上限**：到上限后不再无限累积，及时确认或清空。
- **候选收集默认开启，暂无界面开关**：目前没有界面能关掉收集；候选不自动入术语表，影响仅限列表本身。
