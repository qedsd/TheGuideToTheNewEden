# 设置 · AI

## 一句话 {#tldr}
AI 助手与 AI 翻译共用的全部配置，分五节钻取：**模型**（端点与生成参数）、**翻译**（术语库 / 分片 / 缓存 / 提示词）、**行为**（轮数 / 角色 / 确认 / 上下文预算 / 快捷键 / 提示词）、**ESI 全量访问**（网关与安全边界）、**工具开关**（按需声明 + 46 个工具启停）。

## 在哪打开 {#where}
- 左侧导航「**设置**」→「**AI**」→ 分节列表：每行是「图标 + 标题 + 一行说明 + 箭头」，点整行进入该节详情。
- 详情页不画自己的标题，位置由面包屑「**设置 › AI › 节名**」表示；点面包屑里的「AI」回分节列表。
- 分节列表底部是「**恢复默认**」按钮及其说明文字。
- 翻译 / 频道翻译等页的「去配置」类按钮会直达这里的「**模型**」节。

## 前置条件 {#prereq}
- 想用 [AI 助手](assistant)或 [AI 翻译](translation/ai)：先在「模型」节填好**服务地址、API Key、模型名**并保存，再用「测试连接」确认；三项缺一会提示「请先填写服务地址、API Key 与模型名」。
- AI 助手要用角色功能时，还要求已登录角色且角色具备相应 ESI 权限（见 [设置 · 权限选择](settings/esi-scope)）。

## 操作步骤 {#steps}

### 模型（助手与翻译共用）
1. **协议**：下拉选 OpenAI 兼容 / Azure OpenAI / Anthropic / Google Gemini；国内服务商与本地模型（Ollama / vLLM 等）多数选「OpenAI 兼容」。
2. **服务地址**：可填裸域名（自动补全路径）或完整的 chat/completions 地址；旁边的「**恢复默认**」恢复当前协议的默认地址（模型名为空时顺带填入该协议的默认模型名）。
3. **API Key**（密码框）、**模型名**（占位提示随协议变化，Azure 填部署名）、**api-version**（仅 Azure 需要）。
4. **生成参数**：温度（0 = 不下发该参数）/ 思考模式（仅 DeepSeek 系端点生效）/ 最大输出 token（0 = 交给服务端默认）/ 超时（秒）/ 流式输出。
5. 点「**保存**」；「**测试连接**」会先保存再真实发一次极短请求，把模型、耗时与 token 用量显示在按钮旁，成功另有右下角通知。

### 翻译
1. **术语库**：「注入术语表」开关、「单次注入条数上限」（0 = 不注入）；「术语库状态」显示已载入条数，可点「**重新载入**」。
2. **翻译行为**：「单次请求最大字符数」（超过就分片翻译再拼回，0 = 不分片）；「结果缓存」开关 + 当前条数与体积 +「**清空缓存**」。
3. **系统提示词**：留空用内置；「**恢复内置提示词**」清空并保存。
4. 改完点「保存」。模型端点不在这里——在「模型」节，两节共用同一份端点。

### 行为
1. 「**单次请求最大工具轮数**」（1–30，默认 8）：一次提问里助手最多连续调几轮工具。
2. 「**默认角色**」：问「我的钱包」这类问题时用哪个角色（填角色全名），留空用第一个角色。
3. 「**写操作需要确认**」：开启后写操作弹确认卡片；**关闭不是免确认**，助手会直接拒绝写操作并说明原因。
4. 「**在主窗口中显示 AI**」：默认不勾 = 所有入口都开独立窗口；勾上 = 助手页放进主窗口。
5. 「**上下文预算（字符）**」：同一个对话每次请求都会带上此前的完整记录（含工具调用与结果）；超过预算时先省略中间较早的轮次，**最早一轮与最新一轮优先保留**（最新一轮即使超预算也会压缩工具结果后保留）。默认 **200000**，**0 = 不限制**。记忆只存在于单个对话；接本地小窗口模型时请调小。
6. 「**全局快捷键**」：默认留空 = 不启用；想开启就填组合键（如 `Alt+Q` / `Ctrl+Alt+A`），在任意程序里按下即弹出 / 收起助手窗口。
7. 「**自定义系统提示词**」：留空用内置提示词，填写会整体替换内置规则。
8. 改完点「保存」。

### ESI 全量访问
1. 「**启用 ESI 通用网关**」：关闭后 4 个 `esi_*` 工具直接拒绝调用（专用工具不受影响）。
2. 「**允许 ESI 写操作**」：关闭后只允许只读端点；开启也不等于免确认，每次写操作仍弹确认卡片。
3. 「**把 ID 补成名称**」：开启后响应里的裸 ID 自动补成「名称 (id)」。
4. 「**一次最多取几页**」（1–10，默认 10）、「**单条结果字符上限**」（默认 3500，超长自动截断并注明）、「**错误配额阈值**」（默认 10，剩余配额低于它就停止调用；0 = 不检查）。
5. 「**禁止调用的路径**」：每行一条、支持 `*` 通配（如 `/characters/*/mail`）；命中的端点永远不会被调用，用户确认也绕不过；留空 = 不禁止。
6. 改完点「保存」。

### 工具开关
1. 「**按需声明（省 token）**」：开启后只把与本次提问相关的工具组发给模型；关闭则每次声明全部已启用工具。
2. 「**全部启用 / 全部禁用**」批量按钮，旁边计数「已关闭 X / 44 个工具」。
3. 分组列表（ESI 网关 / 角色 / 商业 / 星图 / 频道 / 通用与工具）逐个开关：关掉的工具不会下发给模型，模型硬要调也会被拒绝；新增工具默认开启。
4. 改完点「保存」。

### 恢复默认
- 分节列表底部的「**恢复默认**」**只重置助手参数**（轮数 / 提示词 / 确认 / 默认角色 / 快捷键 / 上下文预算 / ESI / 工具开关 / 按需声明 / 显示位置，快捷键复位为不启用），**不动模型端点与 API Key**，翻译节参数也不动；成功后通知「已恢复默认设置」。

## 字段与口径 {#fields}

| 设置 | 范围 / 口径 | 默认值 |
|---|---|---|
| 温度 | 0–2；0 = 不下发该参数 | 0.2 |
| 最大输出 token | 0 = 交给服务端默认 | 0 |
| 超时 | 约 5–600 秒 | 60 |
| 流式输出 | 开 / 关 | 开 |
| 思考模式 | 跟随服务端默认 / 关闭 / 低 / 高；仅 DeepSeek 系生效 | 关闭 |
| 单次请求最大工具轮数 | 1–30 | 8 |
| 上下文预算 | 0–400000；0 = 不限制 | 200000 |
| 一次最多取几页 | 1–10 | 10 |
| 单条结果字符上限 | 500–12000 | 3500 |
| 错误配额阈值 | 0–100；0 = 不检查 | 10 |
| 禁止调用的路径 | 每行一条，支持 `*` 通配 | 空 |
| 单次注入条数上限（翻译） | 0–200；0 = 不注入 | 30 |
| 单次请求最大字符数（翻译） | 0 = 不分片 | 12000 |

## AI 能替你做什么 {#ai}
- 工具：`esi_search`（按关键词 / 分组找端点）、`esi_describe`（看端点的参数与权限）、`esi_read`（调只读端点）、`esi_write`（调写端点，**需要你确认**）、`translate`（名词翻译）。前四个正是「ESI 全量访问」节的直接控制对象；`translate` 用「模型」节的端点与「翻译」节的术语库 / 缓存。
- 推荐问法：「OpenAI 兼容协议该填什么地址」「esi_write 是干什么的」「为什么 AI 调不了我的邮件」。
- **做不到**：设置本身没有开放任何 AI 工具——AI 不能替你改协议、填 Key、切开关、按「保存」或恢复默认；一切改动都要你手动完成。

## 常见失败与处置 {#errors}

| 界面提示 | 原因 | 处置 |
|---|---|---|
| 请先填写服务地址、API Key 与模型名 | 端点三项没填全就点「测试连接」 | 填好三项并保存后再测 |
| 测试失败：…（后跟具体原因） | 地址 / Key / 模型名不对，或网络 / 服务商问题 | 按原因排查；国内服务商优先试「OpenAI 兼容」协议 |
| 弹出「AI 设置」错误对话框（内含异常信息） | 保存时写盘等操作失败 | 检查配置目录可写（不要在受限目录里运行）后重试 |
| 角色「XX」缺少该端点所需的权限：… | 角色授权范围缺少所需 scope | 见 [设置 · 权限选择](settings/esi-scope) |

## 限制与已知问题 {#limits}
- **API Key 明文保存在本机**：存于配置目录的 `settings.json`（与其它设置同文件），日志不会输出 Key。
- **旧版本的模型设置不会被迁移或读取**：老版本把模型与翻译参数存在旧键里，现版本不读——升级后需在「模型」节重新填一次地址与 Key（旧值仍留在文件里但不生效）。
- **思考模式只对 DeepSeek 系生效**：按「模型名或地址含 deepseek」判断，其它服务商选了也不下发该参数，避免不认识的参数报错。
- **ESI 网关不是任意 HTTP 客户端**：只能调用索引里登记的 ESI 操作；错误配额低于阈值会主动拒绝调用（防封禁）；整星域订单那种量级请用市场 / 倒货页（REFACTORING §8-66）。
- **术语库只覆盖本地数据库里的名词**：物品 / 舰船 / 星系 / 星域 / 空间站可约束；结构（建筑）名与玩家 / 军团 / 联盟名不在其中（REFACTORING §8-29）。
- **分节首次点开才创建**：切走再切回不重新读取设置，未保存的编辑不会丢。
- **快捷键兼容旧设置**：旧版本默认的 `Alt+Q` 若已保存在设置里会继续生效；想关闭就清空该框并保存或按「恢复默认」。
