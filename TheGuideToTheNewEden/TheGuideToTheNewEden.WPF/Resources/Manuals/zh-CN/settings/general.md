# 设置 · 一般

## 一句话 {#tldr}
调整软件自身的外观与运行参数：界面语言、明暗主题、主题色、关闭到托盘，本地化数据库与游戏服务器，自动检查更新，以及数据目录（设置、登录令牌与缓存的保存位置）和日志入口。除数据目录外，改动即时写入；本页没有统一的「保存」按钮。

## 在哪打开 {#where}
- 左侧导航「**设置**」→ 分类列表「**一般**」（副标题「软件语言、主题颜色、服务器、数据库语言」）→ 点面包屑里的「设置」返回。
- 子页自上而下三组卡片：
  - **外观**：语言、主题、主题色、关闭窗口时最小化到托盘；
  - **数据**：本地化数据库语言（含「使用本地化数据库」勾选）、游戏服务器；
  - **其他**：APP更新（「自动检查更新」勾选）、App日志、**数据目录**（路径 +「打开 / 更改… / 恢复默认」）。
- 控件形态：语言 / 主题 / 游戏服务器是下拉框，主题色是色块弹层，托盘与自动更新是勾选框，本地化数据库是勾选 + 下拉，App日志是按钮，数据目录是路径文本加三个按钮。

## 前置条件 {#prereq}
- **不需要登录角色**。
- **本地化数据库**下拉列出软件数据库目录里的库文件：没有勾选「使用本地化数据库」时，物品 / 星系等名称按未本地化处理（口径见 [数据库](database)）。
- **游戏服务器**切换会重载该服务器的已授权角色：该服务器下还没有角色时，切过去后角色列表是空的（属预期，见 [角色](characters)）。
- **数据目录**的更改只在下次启动生效；当前运行的实例仍使用原目录。运行日志不随数据目录走（固定在 `%LocalAppData%\TheGuideToTheNewEden\Logs`）。

## 操作步骤 {#steps}

### 切换界面语言
1. 「外观 → 语言」下拉选「**中文**」或「**English**」。
2. **立即生效**：界面文字随切随变，不需要重启；个别已经显示的旧提示文字要等下次操作才刷新。
3. 卡片描述里"修改语言后，需要重启应用程序"是旧文案，以实际表现为准（见「限制与已知问题」）。

### 切换主题与主题色
1. 「主题」下拉在「**亮**」与「**暗**」之间切换，立即生效（只有这两档）。
2. 「主题色」点当前色块 → 弹出色板 → 点一个颜色立即应用，当前色上有对勾标记，应用后弹层自动收起。

### 托盘与更新
1. 打开「**关闭窗口时最小化到托盘**」：关主窗口后程序驻留后台，从托盘图标恢复（卡片描述原文如此）。
2. 「APP更新」卡片勾选「**自动检查更新**」；检查 / 下载 / 安装更新在「设置 → 软件更新」分类里做。

### 本地化数据库
1. 勾选「**使用本地化数据库**」，并在下拉里按文件名选一个库文件。
2. 卡片描述写明：本地化**物品**数据库显示语言，修改后需要重启软件。

### 切换游戏服务器
1. 「数据 → 游戏服务器」下拉选「**Tranquility**」（欧服 / 国际服）或「**Serenity**」（国服）。
2. 切换立即生效并弹出「**已切换游戏服务器**」提示，正文说明已切换到所选服务器、ESI 凭据与角色列表都已切换、无需重启。
3. 另一服务器已打开的角色标签会被关闭，角色页重载为新服务器的角色；两套服务器的角色与授权互相独立。

### 数据目录（设置、令牌与缓存放在哪）
1. 看「**其他 → 数据目录**」卡片：左侧是当前（或待生效）路径，右侧三个按钮；描述里显示模式：
   - `默认：按大版本隔离`：`%LocalAppData%\TheGuideToTheNewEden\V4`（`V4` = 主版本 4.x，将来 5.x 会自动变成 `V5`）；
   - `沿用旧版本目录（有冲突风险）`：`%LocalAppData%\TheGuideToTheNewEden`（旧版本一直用的目录）；
   - `自定义目录`：你选定的其它路径。
2. 「**打开**」直接打开当前数据目录；设置、登录令牌（`Auth.json` 等）、各功能配置和可重建缓存都在其 `Configs` 子目录里（主页的「打开配置目录」也指向这里）。
3. 「**更改…**」选一个文件夹后，弹三选一：**是** = 把当前目录的配置与登录信息复制到新目录；**否** = 使用空目录；**取消** = 不修改。
4. 改动**只写选择记录**（根目录的 `datapath.json`），本次运行仍用旧目录：卡片立即显示新路径并标注「下次启动生效」，随后询问是否立即重启；点「是」应用会退出并重新拉起。
5. 「**恢复默认**」回到 `…\V4`，同样下次启动生效。
6. **首次运行**：如果检测到旧版本留下的配置（根目录有 `Configs` / `settings.wpf.json` / `Auth.json`）且还没有选择记录，启动时会先弹「**选择配置保存位置**」：
   - 「**使用新目录（推荐）**」（默认）：新版本独占 `…\V4`，旧版本继续用原目录；可勾选「把旧版本的配置与登录信息复制到新目录（不复制缓存）」；
   - 「**沿用旧目录（与旧版本共用）**」：明确提示旧版本可能无法再使用、新旧版本可能互相冲突；
   - 直接点窗口关闭键：按推荐方案（新目录 + 复制）处理，不会卡在启动前。

### 打开日志
- 「**App日志**」卡片点「**查看**」打开软件日志文件夹：`%LocalAppData%\TheGuideToTheNewEden\Logs`，按日期一个 `.txt`。日志目录与数据目录无关，切换数据目录也不会搬走日志。

## 字段与口径 {#fields}

| 设置项 | 控件 | 取值 | 口径 |
|---|---|---|---|
| 语言 | 下拉 | 中文 / English | 界面显示语言，改后立即生效（描述文字仍是"需要重启"的旧文案） |
| 主题 | 下拉 | 亮 / 暗 | 应用明暗外观，立即生效；没有"跟随系统"档 |
| 主题色 | 色块弹层 | 一组预设颜色 | 应用窗口与控件的强调色，点选即用 |
| 关闭窗口时最小化到托盘 | 勾选 | 开 / 关 | 开 = 关闭主窗口后程序驻留托盘；托盘不可用时会退回"直接退出"，不会把窗口藏起来 |
| 使用本地化数据库 | 勾选 | 开 / 关 | 决定是否用本地库翻译物品等名称 |
| 本地化数据库语言 | 下拉 | 数据库目录里的库文件 | 按文件名显示；修改后需重启软件（描述原文） |
| 游戏服务器 | 下拉 | Tranquility / Serenity | 决定角色列表与 ESI 凭据用哪套；切换立即生效并弹窗确认 |
| 自动检查更新 | 勾选 | 开 / 关 | 是否自动检查新版本 |
| App日志 | 按钮「查看」 | — | 打开 `%LocalAppData%\TheGuideToTheNewEden\Logs`（说明「记录App异常信息」） |
| 数据目录 | 路径 + 打开 / 更改… / 恢复默认 | 默认 `…\TheGuideToTheNewEden\V4`，或旧目录 / 自定义目录 | 设置、登录令牌、各功能配置与缓存的根目录；更改重启后生效；旧目录不会被删除或移动 |
| 数据目录模式 | 描述文字 | 默认：按大版本隔离 / 沿用旧版本目录（有冲突风险）/ 自定义目录 | 只说明用途，不能直接点选；要换目录用「更改…」 |

## AI 能替你做什么 {#ai}
- **可以读 / 改一部分设置**：`config_read`（name=`settings`）能读 `settings.json`（密钥类键自动省略），`config_write` 只能改**已存在的非密钥键**（例如主题、界面语言、托盘、游戏服务器、本地化数据库、日志路径、市场缓存参数；前提是该键已在文件里）；写入前会弹确认，旧内容自动备份，改错可用 `config_restore` 回滚。
- 改完可用 `feature_restart`（name=`settings`）让应用重读 `settings.json`；但**主题 / 语言 / 快捷键、游戏日志路径等启动期缓存的值仍需重启应用**才完全生效。
- **不能改数据目录**：`datapath.json` 不在配置文件白名单里；选目录、复制旧配置和「立即重启」只能在本页手动完成。
- AI 能间接告诉你的：`character_list` 会列出**当前服务器**下已登录的角色——一个都没有时，通常说明还没在该服务器添加角色。
- **做不到**：替你点「更改…」「恢复默认」或重启软件；读写 `datapath.json`；读取 API Key 等密钥类键。

## 常见失败与处置 {#errors}

| 现象 | 原因 | 处置 |
|---|---|---|
| 切换语言后个别文字还是旧语言 | 该处文案在下次操作 / 重新上树时才重算 | 重开对应页面；设置子页每次进入都重建，不受影响 |
| 托盘里没有图标，关窗口后程序直接退出 | 当前运行位置的进程完整性过低，系统拒绝了托盘图标创建 | 从普通安装位置运行（REFACTORING §8-62）；此时软件会退回"直接退出"而不是把窗口藏起来 |
| 切服务器后角色列表为空 | 两套服务器的角色与授权互相独立 | 到角色页用对应服务器重新授权添加 |
| 设置改动重启后丢失 | 数据目录只读或写入被系统拒绝（界面不报错） | 换普通安装位置运行，确认数据目录可写 |
| 「无法使用该目录（可能没有写入权限）。」 | 目标目录不可写 / 不可创建 | 换一个有写权限的目录（不要选系统受保护目录），或点「恢复默认」 |
| 「该目录已经是当前数据目录。」 | 选到了当前正在使用的目录 | 换一个目录，或取消 |
| 数据目录已更改但没生效 | 设计为下次启动生效 | 重启软件；卡片显示「下次启动生效」时说明本次运行还没切 |
| 启动时弹「选择配置保存位置」 | 检测到旧版本配置且还没有 `datapath.json` | 按推荐选「使用新目录」并勾选复制；选一次后会记住 |

## 限制与已知问题 {#limits}
- **「语言」卡片描述是旧文案**：界面仍写"修改语言后，需要重启应用程序"，实际语言切换已即时生效（REFACTORING 阶段 70）。
- **主题只有亮 / 暗两档**：没有"跟随系统"选项（下拉里只有两项）。
- **游戏服务器描述与实际提示不一致**：卡片描述写"部分功能可能需要重启生效"，切换完成的弹窗则说明无需重启；若个别页面数据未刷新，重开该页面即可。
- **托盘不可用时自动退回**：低完整性进程里托盘创建会被系统拒绝，此时关闭窗口不再"最小化到托盘"，程序直接退出（REFACTORING §8-62）。
- **数据目录改动必须重启**：只写选择记录，不搬文件；旧目录不会被删除或移动，想清理需要自己删。
- **日志不跟数据目录走**：日志固定写在 `%LocalAppData%\TheGuideToTheNewEden\Logs`，多版本共写（REFACTORING 阶段 186）。
- **首次运行判定是启发式**：只能看根目录有没有旧配置，无法区分是旧版本还是本版本早期开发版写的；开发机上第一次运行也会看到选择框（选一次即记住）。
- **设置文件默认不再与旧版 WinUI 共用**：默认在按大版本隔离的 `V4` 目录；只有主动选「沿用旧目录」才共用，冲突风险由你承担。
- **本页没有统一的「保存」与「恢复默认」**：改动即时写入，误改只能手动改回；只有数据目录有「恢复默认」。
