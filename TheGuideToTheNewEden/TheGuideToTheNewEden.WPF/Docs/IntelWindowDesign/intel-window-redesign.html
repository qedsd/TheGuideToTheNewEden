星图布局：问题与处理

1信息层级

标题栏只保留品牌、角色名、预警/声音状态和窗口按钮；第二行固定显示本地星系、跳数范围、预警数量， 再把“重点 / 全量”和“频道内容”收进右侧，避免旧版底部一条按钮挤在一起。

2频道内容抽屉

  • 默认收起：只保留一条最新消息摘要，地图占满，满足“只看地图报警”。
  • 点标题或频道按钮展开：地图 + 可滚动消息列表；再点收起回到地图优先。
  • “仅地图”会完全隐藏抽屉，只留右下角“频道 12”浮动按钮，随时可恢复。
  • 列表按 全部 / 预警 / 解除 / 击杀 过滤；预警橙、解除绿、击杀红、MOTD 蓝，和地图节点颜色一致。
  • 消息来自 ChannelIntelSession.ChatContentEvent（已有事件），在窗口里追加到 IntelChatContent 列表，最多保留 200 条；ZKB 行单独标记。

3地图：范围不变 + 视觉分层

配置的 N 跳范围是唯一数据范围：范围内所有星系都绘制，绝不因为视图切换或“重点显示”删掉任何星系。 默认不再直接用全星图 X2/Y2 的 min/max，而是取范围内星系的 2%–98% 分位适配视口； 超出分位的尾部映射到外侧 4% 边带做软压缩（保留方向与先后顺序），而不是全部 clamp 成一条边。

  • 所有 N 跳内星系：安静星系画成低透明度密度点与细星门线，仍然可悬停、可右键、可点击。
  • 高亮与标签：只给本地、预警、已降级、击杀以及它们的直接相邻星系；这是标注优先级，不是范围过滤。
  • 几何离群点：跳数仍在 N 跳内、但 2D 坐标远离视野中心的星系，贴边显示为“几何离群”卡片；它仍属于当前范围，点击可定位。多个离群按方向分槽，最多展示 3 张，其余聚合为 +N。
  • 滚轮缩放 / 拖拽平移只改视口，不改变数据范围；缩回或切“全量”后全部 N 跳星系仍在。
  • 本稿星图是布局示意，实际渲染会包含 IntelJumps 内全部星系；安静星系只是降低亮度，不是删除。
范围红线 IntelJumps=N 决定地图数据集合；视觉分层、缩放手势、离群点贴边都不允许减少 N 跳内的星系。

4操作栏

保留旧版三个动作：清除预警、最新预警（前置游戏）、停止声音； 中间的最新预警卡显示星系、跳数、舰船与时间，点击仍前置 EVE；右侧增加“设置”入口， 不必再回主页面找预警配置。

5状态与不打扰

  • “必要时显示”全部解除后延迟隐藏、隐藏即停声的现有逻辑保持不变。
  • 自动解除 / 自动降级仍由 10 秒定时器驱动；降级节点变黄，解除后从地图与消息列表同步移除。
  • 窗口尺寸、位置、不透明度继续写回 IntelSettingService；新增“频道内容默认状态”与“地图视图模式”两项状态。

6WPF 落地建议

  • IntelWindow.xaml 改成标题 / 信息条 / 地图 / 抽屉 / 操作栏五段式；抽屉用 Grid 行高切换，不引入新窗口。
  • IntelMapView 增加 ViewportMode、HighlightIds、OutlierIds；数据集合始终是 IntelJumps 的 BFS 结果，HighlightIds 只影响标签/线条亮度，不能用于过滤。把 ResetXY 改成分位视口适配，全量坐标用于密度点。
  • 频道列表复用 IntelChatContent 与现有颜色语义；抽屉标题的“最新摘要”直接取最后一条预警。
  • 地图控件不新增第三方依赖；保持 500–640 宽度下可用，展开抽屉时只压缩地图高度，不改窗口宽度。
