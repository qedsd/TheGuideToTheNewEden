3主题适配策略与设计规范

横幅需要跟随软件亮 / 暗主题切换，设计上分三层解决，两层用于 SVG / 图片场景，第三层用于 WPF 内嵌场景。

层做法
构图一致亮 / 暗两版横幅共用同一套几何构图（星云位置、星野坐标、出血环、文字版式完全相同），切换主题时只有色彩在变，没有布局跳动。
双配色方案暗版 = 深空蓝底 + 白色星野；亮版 = 晨雾蓝底 + 灰蓝星点、星云透明度减半、品牌环加深保对比度。SVG / 图片场景按主题选文件。
WPF 主题感知BrandBanner.xaml 纯矢量版：底色与文字走 DynamicResource（随 ApplicationThemeManager 自动刷新），星云用固定半透明色（两主题下都成立），星点用主题文字色画刷，闪星跟随用户主题色 —— 零图片文件、零代码改动。
色彩令牌值用途
星云青 Teal#5EEAD4渐变起点、闪星（亮版加深为 #14B8A6）
星门蓝 Sky#38BDF8品牌渐变中点、星云主色

夜航文本（暗）#F5F8FF暗版主标题（副标题 #7C8DB5）

4交付物与接入步骤

全部位于 design/branding/ 目录。

logo.svg — Logo 彩色矢量版（建议导出 256/32 PNG 替换 Assets/logo_128.png / logo_32.png，再生成 app.ico）
logo_white.svg — Logo 单色白版（深色背景 / 反白场景）
banner_dark.svg — 主页横幅 · 深色主题（1200×200，可导出 PNG 供 WinUI 版 / README 使用）
banner_light.svg — 主页横幅 · 浅色主题（同构图）
BrandBanner.xaml — WPF 主页品牌条直接替换块（主题感知纯矢量，无需图片）
WPF 接入（推荐，P0）：用 BrandBanner.xaml 内的 Border 块整体替换 HomePage.xaml 现有品牌条， 删除旧的 Hero* 资源即可 —— 所有绑定与事件处理器沿用现状，亮 / 暗主题切换由 DynamicResource 自动完成，无需订阅 ThemeChanged。
图标替换（P1）：将 logo.svg 导出为 256×256 PNG → 生成多尺寸 app.ico，替换 Assets/app.ico 与标题栏 / 托盘用的 PNG。
宣传图（P2）：两版横幅可导出高清 PNG，用于 GitHub README 头图与发布页。
